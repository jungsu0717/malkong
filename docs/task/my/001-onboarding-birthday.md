# 001 온보딩 — 생일 입력과 월령 실계산

> 상태: 완료 (2026-10-01)
> 근거: SPEC-MY-01, SPEC-HOME-01, SPEC-MY-02

## 목표

처음 실행 시 아기 생일(이름 선택)을 받아 기기에 저장하고, 지금 하드코딩된 `BABY`(D+87 · 3개월)를
저장값 기반 실계산으로 바꾼다.

## 단계

1. expo-sqlite 도입 — `src/data/db.ts`(연결·마이그레이션)와 `baby` 테이블.
   스키마는 [backend](../../architecture/backend.md) 기기 DB 절 그대로 (record·chat_message 는
   이 task 범위가 아니다 — 기록 저장 task 에서)
2. 온보딩 화면 — 생일 날짜 선택 + 이름(선택) + 시작 버튼. 저장 전이면 탭 진입 시 이 화면 먼저
3. `src/data/baby.ts` — 저장·조회 + 생일 → { days, month } 계산 (만 나이 개월 계산 규칙 명시)
4. `BABY` 상수를 쓰는 화면 셋(홈·물어보기·성장)을 계산값으로 교체
5. 마이 탭 프로필에서 생일 수정 가능하게

## 완료 조건

- [x] (SPEC-MY-01) 생일 입력만으로 시작되고, 그 외 필수 입력이 없다
- [x] (SPEC-MY-01) 모든 화면의 월령·일수가 저장된 생일에서 계산된다
- [x] (SPEC-HOME-01) 홈 카드 월령이 하드코딩이 아니다
- [x] (SPEC-MY-02) 생일을 고치면 화면들이 따라 바뀐다
- [x] tsc · lint 통과

## 구현 결과

- 저장: `src/data/db.ts`(기기 sqlite) · `src/data/db.web.ts`(웹 미리보기 localStorage) ·
  `src/data/baby.ts`(월령 계산·저장 API) · `src/data/baby-context.tsx`(화면 공급)
- 화면: `src/app/onboarding.tsx` 신설, 라우트를 `(tabs)` 그룹으로 재배치하고 루트는 Stack + 온보딩 게이트
- 월령 정의: **만 월령**(생일과 같은 날짜가 되면 1개월 증가), 일수는 태어난 날이 D+0
- 날짜 입력은 네이티브 피커 대신 숫자 입력 — 웹 미리보기까지 같은 화면으로 확인하려고
- `BABY` 상수 제거, `getGaps()` 는 월령을 인자로 받는다

## 검증 (2026-10-01)

웹으로 내보낸 실제 앱을 브라우저에서 열어 단계별로 확인했다 — 스크린샷 `01~09`:

1. `/` 진입 → 저장된 생일이 없어 온보딩으로 자동 이동
2. 2026-07-06 · 이름 "말콩이" 입력 → 버튼 활성화 → 시작 → 홈 이동
3. 홈: "태어난 지 87일 · 만 2개월", 2개월 표준(첫 사회적 미소)·발달 포인트·차집합 추천 반영
4. 성장: 2개월 컬럼이 현재 월로 강조되고 "지금 · D+87"
5. 마이: 프로필 카드에 생일·일수·월령
6. 생일을 2026-04-06 으로 수정 → 마이·홈·물어보기 전부 "178일 · 만 5개월"과 5개월 표준으로 따라 바뀜
