# 005 마이와 온보딩을 시안 B 로 — 브리핑 알림 시각까지

> 상태: 완료 (2026-10-03) — 실기기 확인은 몰아 시험에서
> 근거: SPEC-MY-01·02·03·06 · SPEC-HOME-06(알림 시각은 온보딩에서, 기본 8시) · [decisions/012](../../decisions/012-chat-first-three-tabs.md)

## 목표

마이·온보딩·약관 화면을 시안 B 로 다시 그리고, home/004 에서 만든 브리핑 알림을 사용자가 켜고 끄고 시각을 고를
자리를 만든다.

## 먼저 정한 것

1. **온보딩 두 걸음** — ① 생일·이름 → ② 「매일 아침, 말콩이가 먼저 챙길게요」 알림 시각(7·8·9·10시, 기본 8시).
   「알림 받기」면 허락을 묻고, 「나중에 할게요」여도 시각은 남긴다. 프로필 수정(`?edit=1`)에는 ②가 없다
2. **마이의 알림 칸** — 스위치 + 시각 칩. 휴대폰 설정에서 알림이 꺼져 있으면 그렇다고 말하고 「설정 열기」.
   꺼도 브리핑은 앱을 열면 생긴다는 말을 함께
3. 개인정보 처리방침에 알림 한 줄(서버로 보내는 것 없음, 알림 글에 아기 정보 없음), 자주 묻는 질문에 브리핑
4. 「구축 현황(임시)」 칸은 한 줄로 줄이고 개발 빌드에서만
