# 002 우리 아기 기록 보기·고치기

> 상태: 완료 (2026-10-03) — 화면 시험은 첫 출시판 개발을 마친 뒤 몰아서
> 근거: SPEC-MY-02

## 목표

마이 탭에서 저장된 L2 기록을 모두 보고, 문구를 고치거나 지우거나 직접 적을 수 있게 한다. 바뀐 기록은 홈
추천과 물어보기에 보내는 기록에 바로 반영된다. 생일·이름 고치기는 이미 있다(task my/001, `onboarding?edit=1`).

## 이 task 에서 하지 않는 것

- 사진 붙이기(SPEC-MY-02 「다음」) — 첫 출시 뒤
- covers(어떤 L1 항목을 완료 처리하는지) 고치기 — 홈에서 완료를 알리고 되돌리는 길로 충분하다. 잘못 닫힌
  항목은 그 기록을 지우면 다시 「챙길 것」에 나온다

## 단계

1. 저장소 — `record` 문구 고치기(`updated_at` 갱신, 낡음 표시 지움). sqlite 와 웹 판 둘 다
2. `src/app/records.tsx` — 최근 것부터 · 고치기 · 지우기(한 번 더 확인) · 대화 보기 · 직접 적기
3. 마이 탭에 「우리 아기 기록」 카드
