# 006 처음 실행 만화 — 온보딩 전에 다섯 컷

> 상태: 완료 (2026-10-05) — 폰에서 좌우 밀기 · 화면 읽기 확인은 몰아 시험에서
> 근거: SPEC-MY-07 · SPEC-MY-01 · [store-toon](../../product/store-toon.md)

## 목표

앱을 처음 연 사람에게 「아빠가 육아 앱을 만든 이유」 만화 다섯 컷을 한 컷씩 보여 주고, 마지막 컷이나
「건너뛰기」에서 지금의 온보딩(생일 → 알림 시각)으로 넘긴다. 한 번 보면 다시 안 뜬다.

## 먼저 정한 것

1. **흐름** — 아기 생일이 없을 때만 문지기(`_layout` 의 OnboardingGate)가 보낸다: 만화를 아직 안 봤으면 `/intro`,
   봤으면 `/onboarding`. 생일이 있는 사람(이미 쓰던 사람)에게는 만화를 띄우지 않는다
2. **본 표시** — 기기 settings `intro_seen = 'yes'`. 끝까지 보고 「시작하기」를 누르거나 「건너뛰기」를 누르면 남긴다.
   앱을 지우고 다시 깔면 다시 보인다(기기 안 저장이라)
3. **화면** — 위: 「1 / 5」와 「건너뛰기」, 가운데: 만화 한 컷(4:5, 화면 너비에 맞추고 키 작은 폰에서는 높이에 맞춘다),
   점 다섯, 아래: 「이전」 · 「다음」(마지막 컷은 「시작하기」). 좌우로 밀어도 넘어간다
4. **그림** — `marketing/toon/out/01~05.png` 를 `assets/images/intro/` 로 옮겨 쓴다(합 약 1.2MB).
   만화를 다시 그리면 `./render.sh app` 으로 다시 옮긴다
5. 화면 읽기 프로그램용 줄거리는 컷마다 한두 문장

## 단계

1. SPEC-MY-07 · 이 task
2. settings `intro_seen` — preferences-context 에 `introSeen` · `markIntroSeen`
3. `src/app/intro.tsx` 화면, `_layout` 문지기와 화면 등록
4. `render.sh app`, store-toon 「쓰는 곳」에 앱 첫 실행
5. tsc · lint · 웹에서 첫 실행 흐름 확인
