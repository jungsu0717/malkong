## 정한 것

- **탭에 남는 것(위에서부터)**: 머리(이름 · 태어난 지 · 월령 · 고치기) → 지식 지도(아는 정도 % · 단계, 높이를 줄인다) →
  지도 아래 한 줄 「함께한 지 N일째 · 질문 N번 · 기록 N개」 → 「알려 주면 더 정확해져요」(2~3줄) → 「하루 기록」(4줄, 적기) →
  「더 보기」 카드(줄 셋: 버디가 아는 것 · 한눈에 보는 아기 · 기록 전체) → 고지 한 줄
- **탭에서 빠지는 것**: 영역 칩 줄과 영역 막대 목록(같은 퍼센트가 지도 · 칩 · 막대에 세 번 나오던 것), 한눈에 보는 타일 여섯,
  「함께 쌓아 온 것」 숫자 셋과 그래프
- **상세 화면 둘**(루트 스택, 머리글 있음):
  - `/knowledge` 「버디가 아는 것」 — 영역 여섯 막대(누르면 고름) → 고른 영역의 사실 목록(알려 주기 · 고치기, 지금의 `DomainCard`)
    → 「알게 된 흐름」 그래프와 함께한 날 · 질문 · 기록. 지도의 행성을 누르면 그 영역으로 연다(`?domain=`)
  - `/profile` 「한눈에 보는 아기」 — 몸무게 · 키 · 먹기 · 잠 · 접종 · 검진 타일(지금 그대로 옮긴다)
- **SPEC-BABY-05 문구**: 「함께 쌓아 온 것」 → 「버디와 함께한 시간」. 숫자는 통계 칸이 아니라 한 문장으로
- 모델 호출 없음. 새 색 · 새 부품 없음(ListRow · Card · SectionHeader 그대로)
