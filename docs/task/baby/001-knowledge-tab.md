# 001 우리 아기 탭 — 버디가 아는 우리 아기(지식 지도)

> 상태: 진행 (2026-10-03) — 코드 완료. 지식 지도(3D)는 Julian 아이폰(Expo Go)에서 확인 남음
> 근거: SPEC-BABY-01~06 · [decisions/013](../../decisions/013-four-tabs-knowledge.md)

## 목표

Julian 요청: 탭 넷, 두 번째 탭에 우리 아기의 모든 정보와 지식이 쌓인 수준을 3D 로 — "두 번째 탭만 봐도 우리 아기를
엄청 잘 알고 있구나" 하는 와우와 아하.

## 먼저 정한 것

1. **탭 넷** — 말콩 · 우리 아기(새) · 성장(옛 우리 아기 탭의 일정·타임라인 = 「이번 달」·「타임라인」) · 마이.
   기록 보기는 `/records` 화면으로
2. **영역 여섯과 알아야 할 것 20개 안팎** — 먹기(수유 방식·간격·양·이유식) · 잠(밤잠·낮잠·재우는 방식) ·
   성장(몸무게·키·머리둘레) · 건강(접종·검진 완료 비율, 알레르기·피부, 아팠던 일) · 발달(몸 움직임·소리 표정·이) ·
   생활(기질·좋아하는 것·놀이 목욕, 생활 안전 확인 비율). 월령에 안 맞는 것(4개월 전 이유식·이)은 세지 않는다
3. **점수는 기록에서만** — 문구 규칙에 맞는 기록이 있으면 1, 표준 완료는 비율. 영역은 평균, 전체는 영역 평균
4. **단계 다섯** — 처음 만났어요 · 알아 가는 중 · 꽤 잘 알아요 · 단짝이에요 · ○○ 박사
5. **3D 지식 지도는 Skia** — 가운데 아기(쪽쪽이 얼굴) · 영역 행성(점수만큼 크고 밝게, 빛 번짐, 구 그라디언트) · 사실 점
   (아는 것은 빛나는 점, 모르는 것은 빈 고리, 행성 둘레를 돈다) · 별 · 궤도 고리. 저절로 돌고 끌어서 돌린다, 행성을 누르면
   그 영역 목록. 탭에 올 때마다 가운데서 퍼져 나오고 %가 0 에서 올라간다
6. **알려 주기** — 모르는 것을 누르면 버디 탭 입력창에 말머리(「요즘 낮잠은 」)가 담긴다(바로 보내지 않음).
   입력창 글은 `draft-context` 로 탭끼리 나눈다
7. 지식 지도 카드는 밝은 모드에서도 우주처럼 어둡다(`space` 토큰)

## 시험

- 웹(390px): 기록 0개 → 0% · Lv.1, 직접 적은 기록 10개 → 58% · Lv.4 단짝이에요. 한눈에 보는 칸 · 제안 · 함께 쌓아 온 것 보임
- 지식 지도 그림은 웹 시험에서 확인하지 못했다 — 시험용 headless Chrome 에 WebGL 이 없어 CanvasKit 이 그릴 판을 못 만든다
  (`failed to create webgl context`). 그리기 코드는 판 만들기 직전까지 돈다. 실제 확인은 Expo Go(아이폰)에서

## 아이폰에서 앱이 꺼진 것 (2026-10-03)

Julian 이 Expo Go 에서 우리 아기 탭에 들어가자 앱이 꺼졌다. 기록(로그)은 없어서 의심 가는 두 곳을 고쳤다.

- 탭에 올 때마다 지도를 `key` 로 지웠다 새로 만들었다 — 처음 열 때도 한 프레임 안에 두 번. UI 스레드가 그리는 도중에 그림판이
  지워지면 꺼질 수 있다 → 그림판은 그대로 두고 `replay` 값으로 등장 모션만 다시
- 빛 번짐을 흐림 필터(`MaskFilter.MakeBlur`)로 매 프레임 30개 가까이 새로 만들었다 — GPU 메모리를 크게 쓴다 →
  가장자리가 투명해지는 원 그라디언트로 바꿨다
- 함께: 탭이 안 보이면 프레임마다 그리지 않는다(`useFrameCallback` 을 멈춤), JS 오류는 지도 자리만 「그리지 못했어요」로(경계)

그래도 꺼져서 이 맥에 기록용 개발 서버를 따로 띄우고 아이폰을 붙여 그리는 단계마다 기록을 남겼다.
**지도 그림은 끝까지 그려졌고, 글꼴(`useFont`)을 다 읽어 행성 이름을 그림판에 쓰기 시작한 직후 꺼졌다.**
→ 그림판(Skia)에 글씨를 쓰지 않고, 행성 이름과 %는 앱 글씨(`Text`)를 같은 투영 계산으로 UI 스레드에서 따라다니게 했다
(`PlanetLabel`, `useAnimatedStyle`). 그리다 오류가 나면 빈 그림을 내고 개발 중에만 한 번 알린다.
고친 판은 아이폰에서 약 3,400장면(1분 남짓) 이어 그리다가 다른 탭으로 옮기자 멈췄다 — 꺼지지 않았다.
