# 009 주간 · 월간 브리핑

> 상태: 완료 (2026-10-04) — 웹 확인

## 정한 것

1. 주간 — 그 주 월요일 이후 처음 열 때 하나. 그 주(월~일)에 무렵인 접종·검진 + 지금 기간 안인데 안 한 것 + 놓친 것(물어보기)
2. 월간 — 월령이 바뀐 날 이후 처음 열 때 하나. 이번 달 챙길 것(접종·검진·생활, 지금 달이면 지난 달에서 남은 것도) + 발달 포인트 + 다음 달 미리 보기
3. 알림함에 줄 하나(요약), 일정 탭 그날에 카드(달력에 테두리 점). 대화 요약 카드에 그날 온 「이번 주 일정이 도착했어요」 · 「3개월 일정이 도착했어요」 줄 — 누르면 그날로
5. 데일리의 ⑤는 「다가오는 일정 — 7일 안」으로 바꿨다(이번 주 정리는 주간의 몫)
4. 내용은 저장하지 않고 볼 때마다 기록으로 다시 센다(데일리와 같은 방식) — 저장하는 것은 알림함 줄뿐
