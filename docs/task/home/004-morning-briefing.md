# 004 아침 브리핑 — 대화의 첫 메시지 · 보관함 · 알림

> 상태: 진행 (2026-10-03) — 코드 완료. 온보딩의 알림 시각 묻기와 마이 설정은 my/005
> 근거: SPEC-HOME-06(2026-10-03 다시 씀) · [decisions/012](../../decisions/012-chat-first-three-tabs.md)

## 목표

앱을 열면 말콩이가 먼저 말을 건다. Julian 요청: "오늘의 브리핑은 맨 위에 뜨고 사라지지 않게 첫 대화에서 뜨되,
오른쪽 위 보관함에도 남아서 다시 볼 수 있게".

## 먼저 정한 것

1. **기기 안에서 만든다** — 모델을 부르지 않는다. 무료 할당량을 쓰지 않고, 기록이 기기 밖으로 나가지 않는다
2. **대화 타임라인에 저장** — `chat_message` 의 `meta.type = 'briefing'`. 스키마를 바꾸지 않는다. 하루 하나
3. **저장하는 것은 그날 고른 줄** — 했는지는 볼 때마다 기록으로 센다. 브리핑·우리 아기 탭 어디서 완료해도 같다
4. **상태 확인은 몸무게 하나부터** — 기록이 없거나 14일 넘으면. 누르면 입력창에 「오늘 몸무게는 」. 보내면 답과 함께
   기록이 생긴다(대화가 곧 기록)
5. **그날의 한 줄** — 태어난 지 N일 · 100일 앞(91~99일째) · 100일(태어난 날을 1일로) · 첫돌·생일
6. **알림은 로컬** — 매일 정한 시각, 기본 8시. 본문에 아기 정보 없음. 꺼도 브리핑은 생긴다
7. 지난 날의 브리핑은 대화에서 작게(날짜 머리), 오늘 것만 큰 인사와 함께
