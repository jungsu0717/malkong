# 005 브리핑 두 묶음 · 하루 기록 · 브리핑함 배지

> 상태: 진행 (2026-10-04) — 코드 완료, 아이폰 확인 남음
> 근거: SPEC-HOME-06(2026-10-04 갱신)

## 목표

Julian 요청(2026-10-04): 브리핑함에 쌓을 거면 배지 개수를 보여 주고, 브리핑 종류를 카테고리로 묶자 —
접종처럼 해야 할 일 묶음과, 매일 받아 두면 좋은 기록 묶음(어제 총 수유량 · 평균 수유 텀 · 몸무게 · 특이사항).
필수는 아니지만 반필수로, 안 적으면 대화 중에 부족한 것을 되묻는다.

## 정한 것

1. **두 묶음** — ① 챙길 것(예전 그대로, 앞 3줄) ② 하루 기록 넷. 「몸무게를 알려 주세요」 줄은 ②의 몸무게가 맡는다
2. **하루 기록은 저장하지 않는다** — 날마다 같은 넷이라 브리핑에는 ①만 남기고 ②는 그릴 때 만든다. 그래서 이미 만들어진
   오늘 브리핑에도 바로 붙는다(옮길 데이터 없음). 예전 브리핑의 몸무게 줄(`kind: 'check'`)은 그리지 않는다
3. **적기는 시트 하나** — 숫자 + 단위(ml · 시간 · kg), 수유 간격과 특이사항은 자주 쓰는 값 칩. 기록 문구에 날짜를 붙인다
   (「10월 3일 하루 수유량 820ml」 · 「몸무게 6.4kg (10월 4일)」) — 다음 답에서 언제 일인지 알 수 있게. 적은 줄을 다시 누르면 고친다
4. **했는지는 기록으로 센다** — 그날 생긴 기록에 같은 말이 들었으면(몸무게는 일주일 안). 대화에서 말해 생긴 기록도 센다
5. **배지 = 오늘 아직 안 한 것의 수** — 챙길 것 가운데 다가오는 일정(D-day)은 빼고 + 하루 기록. 앱 안에서만(홈 화면 아이콘 배지는
   독촉이라 쓰지 않는다 — SPEC-HOME-06 「독촉하지 않는다」)
6. **이름** — 보관함 → 브리핑함. 맨 위 오늘 브리핑에서도 완료하고 적을 수 있다
7. **질문에 실어 보내는 기록** — 최근 30개를 그대로 자르면 하루 기록이 일주일 만에 한 번 알려 준 사실을 밀어낸다.
   하루 기록은 종류마다 최근 2~3개만 남기고 나머지 자리를 다른 기록에 준다(`recordsForQuestion`)
