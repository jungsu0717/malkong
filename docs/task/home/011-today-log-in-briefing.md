# 011 오늘의 기록을 브리핑으로 — 우리 아기 탭의 적는 메뉴를 걷어 낸다

> 상태: 완료 (2026-10-06)
> 근거: SPEC-HOME-06 ④(이 task 에서 「오늘의 기록」으로 정의를 고친다) · SPEC-BABY-04 · 07(정의를 고친다) · SPEC-ASK-03

## 목표

Julian(2026-10-06): 「우리 아기 탭의 「알려 주면 더 정확해져요」와 「하루 기록」이 겹친다. 알려 주기는 관련 질문이 올 때
대화에서 저절로 모으면 되고, 오늘 브리핑에 「알려 주는 것」과 「오늘의 기록」 둘이 오면 좋겠다. 거기서 하루 기록을 받고,
안 적으면 대화에서 물어 저절로 익히게. 우리 아기 탭에 수동으로 적는 메뉴가 많다」.

## 정한 것

- **오늘 브리핑 = 알려 주는 것 + 오늘의 기록.** 상세 카드(`BriefingCard`)의 「기록하면 좋을 것」이 「오늘의 기록」 섹션이 된다 —
  안부와 이어지는 기록(체온 등)이 있으면 맨 앞, 그 아래 하루 기록 넷(「적기」). 섹션 머리에 「안 적어도 괜찮아요. 필요하면
  대화에서 버디가 물어봐요」. 홈 요약 카드에는 「오늘의 기록」 한 줄(누르면 상세)
- **우리 아기 탭에서 뺀다**: 「알려 주면 더 정확해져요」 목록, 「하루 기록」 칸. 탭은 지도 · 함께한 시간 · 더 보기만
- **그래도 언제든 적을 곳**: 「한눈에 보는 아기」 상세 아래 「하루 기록」 칸. 「버디가 아는 것」 상세의 사실마다 「알려 주기」
- **저절로 모으는 길은 이미 있다**: 답하기 전 되묻기(SPEC-ASK-03, 되묻기 칩이 기록이 된다) · 하루 기록이 사흘 비면 묻는 카드와
  알림(SPEC-BABY-07 요청). 새로 만들지 않는다
