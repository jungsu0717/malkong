# 001 완료 알리기 — 「챙길 것」에서 기록 만들기

> 상태: 완료 (2026-10-01)
> 근거: SPEC-HOME-02(완료 알림 · 저장 표시) · SPEC-GROW-02 · SPEC-GROW-03 —
> 규칙 정본: [knowledge-layers](../../architecture/knowledge-layers.md) 연결·정정·저장
> 횡단: 기록 저장소는 성장 타임라인과 (나중에) 물어보기가 함께 쓴다. 주 메뉴는 홈이다

## 목표

홈 「챙길 것」에서 완료를 알리면 기기에 L2-기록이 생기고, 추천에서 사라지고, 성장 타임라인에 보이게 한다.
지금의 목업 기록을 걷어내고 실제 기록으로 바꾼다.

## 단계

1. 기록 저장소 — `record` 테이블(스키마는 [backend](../../architecture/backend.md) 기기 DB 절).
   `covers` 는 L1 id 목록(JSON 배열)이다. 기기는 `db.ts`(sqlite), 웹 미리보기는 `db.web.ts`(localStorage)
2. `src/data/records.ts`(읽기·추가·지우기) + `records-context.tsx`(화면 공급)
3. `timeline.ts` — 목업 기록을 걷어내고, 차집합과 타임라인이 저장된 기록을 받게 한다.
   기록은 완료 처리한 항목이 시작하는 월의 컬럼에 놓는다(covers 가 없으면 기록한 날의 월령)
4. 홈 — 줄을 누르면 항목 고르기 시트, 「완료했어요」 → 기록 저장 → 「…완료로 기록했어요 · 되돌리기」
5. 성장 — 우리 아기 트랙이 저장된 기록을 보여준다

범위 밖: 마이 탭에서 기록 전체를 보고 고치기(SPEC-MY-02 기록 정정) — 다음 task.

## 검증 (2026-10-01)

웹 미리보기(생일 2026-06-25 · D+98 · 3개월, 기록 없음)에서 흐름을 끝까지 돌렸다 — 스크린샷 `flow-1~4`:

1. 「3건 더 보기」 → 2개월 접종 묶음 줄 누름 → 시트에 다섯 항목이 모두 골라진 채 열림
2. 하나를 끄니 버튼이 「4건 완료했어요」 → 저장 → 「…완료」로 기록했어요 · 되돌리기」 표시,
   네 항목은 사라지고 끈 Hib 1차만 「2개월 차 항목인데 기록이 없어요」로 남음
3. 저장된 기록: covers 4개 · whenLabel "D+98에 알림". 새로고침 뒤에도 그대로
4. 성장 2개월 컬럼 우리 아기 트랙에 「기록 · …1차 완료 · D+98에 알림」. 3개월은 「기록 없음」,
   4개월은 「앞으로 채워질 기록」
5. B형간염 2차 완료 → 되돌리기 → 줄이 다시 돌아옴

기기(sqlite) 쪽은 같은 함수 서명이라 코드만 맞췄고, 실기기 확인은 다음 개발 빌드 때 한다.
