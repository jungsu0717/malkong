## 한 것

- 계약에 `LlmUnavailable`(401 · 403 · 429)을 더했다. Gemini · Anthropic 어댑터가 상태 코드로 나눠 던지고,
  서비스는 다시 부르지 않고 곧바로 503 MODEL_UNAVAILABLE("지금은 답변을 만들 수 없어요…")
- 그 밖의 Interactions API 오류는 `LlmError` 로 바꿔 서비스의 재시도 한 번 → 503 흐름을 탄다
- Gemini SDK 재시도는 5xx 에만 한 번(0 으로는 끌 수 없다 — SDK 가 0 을 1 로 바꾼다)
- 테스트: 어댑터 상태 코드 나누기 · SDK 재시도 범위 · 서비스가 한 번만 부르고 503
