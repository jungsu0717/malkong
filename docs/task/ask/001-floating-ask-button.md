# 001 플로팅 질문 버튼 — 어디서든 말콩이 부르기

> 상태: 완료 (2026-10-01)
> 근거: SPEC-ASK-07

## 목표

물어보기 밖 세 탭(홈·성장·마이)의 우하단에 플로팅 버튼을 두고, 누르면 그 자리에서 입력창이
열리고, 전송하면 물어보기 탭으로 이동해 그 질문으로 대화가 시작되게 한다.

## 단계

1. `src/components/ask-fab.tsx` — 버튼(쪽쪽이 아이콘, accent 원형) + 눌렀을 때 키보드 위 입력 시트
2. 전송 → `router.push('/ask?q=…')` — ask 화면이 `q` 파라미터를 받으면 그 질문으로 대화 시작
   (지금은 시연 응답 그대로, agent 연결 후에도 같은 경로를 쓴다)
3. 세 탭에 배치 — 배너 광고·주요 버튼과 겹치지 않게 (BottomTabInset 고려)

## 완료 조건

- [x] (SPEC-ASK-07) 물어보기 밖 모든 탭 우하단에 플로팅 질문 버튼이 있다
- [x] (SPEC-ASK-07) 그 자리에서 입력해 전송하면 물어보기 탭으로 이동해 그 질문의 대화가 이어진다
- [x] (SPEC-ASK-07) 버튼이 배너 광고나 화면의 주요 행동을 가리지 않는다
- [x] tsc · lint 통과

## 구현 결과

- 부품: `src/components/ask-fab.tsx` — 버튼(쪽쪽이 아이콘) + 바닥에서 올라오는 입력 시트.
  홈·성장·마이에 두고 물어보기에는 두지 않는다.
- 전달: `/ask?q=<질문>&t=<전송 시각>`. 물어보기 화면은 **효과 없이** 파라미터의 시각과 화면 안에서
  보낸 시각을 견줘 더 나중 것을 보여준다 — `useEffect` 안의 setState 는 린트 규칙이 막는다.
- 성장 탭은 바닥에 배너가 고정돼 있어 `bottom` 을 배너 위로 올린다(`AD_FOOTER_HEIGHT`).

## 검증 (2026-10-01)

내보낸 웹 앱을 브라우저에서 열어 확인했다 — 스크린샷 `10~14`:

1. 홈 우하단에 버튼이 뜨고, 눌러서 바닥 입력 시트가 열림
2. "이유식은 언제 시작하나요?" 전송 → 물어보기 탭으로 이동, 질문 버블 → 처리 현황 재생 →
   "3단계 확인했어요"로 접힌 뒤 답변
3. 물어보기 탭에는 버튼이 없음
4. 성장 탭에서 버튼이 배너 광고 위에 떠서 광고를 가리지 않음
5. 마이 탭에도 버튼 있음
