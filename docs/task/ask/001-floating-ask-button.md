# 001 플로팅 질문 버튼 — 어디서든 말콩이 부르기

> 상태: 대기
> 근거: SPEC-ASK-07

## 목표

물어보기 밖 세 탭(홈·성장·마이)의 우하단에 플로팅 버튼을 두고, 누르면 그 자리에서 입력창이
열리고, 전송하면 물어보기 탭으로 이동해 그 질문으로 대화가 시작되게 한다.

## 단계

1. `src/components/ask-fab.tsx` — 버튼(쪽쪽이 아이콘, accent 원형) + 눌렀을 때 키보드 위 입력 시트
2. 전송 → `router.push('/ask?q=…')` — ask 화면이 `q` 파라미터를 받으면 그 질문으로 대화 시작
   (지금은 시연 응답 그대로, agent 연결 후에도 같은 경로를 쓴다)
3. 세 탭에 배치 — 배너 광고·주요 버튼과 겹치지 않게 (BottomTabInset 고려)

- [ ] (SPEC-ASK-07) 버튼이 배너 광고나 화면의 주요 행동을 가리지 않는다
