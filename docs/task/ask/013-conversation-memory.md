## 목표

에어컨 · 창문 질문에 「분유를 먹이고 있으니」로 시작한 답, 「분유 먹이는 거랑 무슨 상관이야?」에 또 엉뚱하게 한 답(Julian, 2026-10-12)을
고친다. 땜질이 아니라 큰 서비스가 대화 기억을 다루는 방식(지금 대화 원문 · 요약 · 오래 가는 사실은 맞을 때만)으로 바꾼다.
Julian: 「테스트는 내가 할 거고 넌 시험 비용 쓰지 마, 바꾸기만 하고 실측은 내가」 — 실제 모델 호출 0.

## 정한 것

- **대화 요약**: 모델 출력에 `summary` 한 칸(이번 질문과 답까지, 2~4문장 300자 안, 부모가 바로잡은 것은 빼지 않음). 서버는
  `conversationSummary` 로 돌려주고(답 · 되묻기), 폰은 그 말풍선 meta(`summary`)에 둔다. 다음 질문에 하루 안의 가장 최근 것을
  `conversationSummary` 로 붙인다. 서버는 600자에서 자르고 user 메시지의 「이전 대화 요약」 줄로 넣는다
- **기록은 주제에 닿는 것만**: 폰 `src/data/ask-context.ts` 가 질문의 주제(`ask-trace.ts` 의 주제 — 건강 · 접종 · 검진 · 먹기 · 잠 · 변 ·
  피부 · 발달 · 키와 몸무게 · 울음 · 안전)에 닿는 기록만 고른다. 열을 물으면 접종 기록도(접종 뒤 열인지). 되묻기에 막 고른 답은 늘.
  주제가 없으면 보내지 않는다. 「우리 아기 기록 N개 봤어요」는 보낸 수 그대로라 맞다
- **주제를 정할 글**: 반박이면 원래 질문, 주제 말이 없고 앞 말을 가리키면(그렇게 · 그건 · 그럼 · 아까 …) 앞 질문, 그 밖에는 질문 자신.
  서버 `server/app/domain/ask/memory.py` 도 같은 규칙으로 지식을 찾는다 — 반박이면 원래 질문으로, 지식이 안 잡혔을 때 앞 질문으로
  다시 찾는 것은 가리키는 말이 있을 때만(전에는 모든 질문이 그랬다)
- **반박**: 「무슨 상관」 「그게 아니라」 「엉뚱」 「딴소리」 「잘못 알아들」 「왜 갑자기 ~ 얘기」 같은 말이고 앞에 버디의 답이 있을 때.
  「상관없어요?」는 보통 질문이라 넣지 않았다. 서버는 user 메시지에 「(이번 말은 바로 앞 버디의 답을 두고 하는 말이다. 원래 질문: …)」을
  붙이고, 모델이 되물으면 한 번 더 답으로 받는다
- **프롬프트**(`system_prompt.txt`): 「첫 두 문장 안에서 기록을 짚어라」를 「답을 바꾸는 기록만, 다른 주제를 억지로 잇지 않는다(에어컨에 분유 X)」로.
  「대화 이어 가기」 절 — 요약 · 앞 말 가리키기 · 반박(상관 있으면 설명, 없으면 짧게 인정하고 다시 답) · summary 쓰는 법
- **「열」**: 열이 · 열나 · 고열 · 해열 · 38도처럼 열을 뜻할 때만 — 서버 분류(`retrieval.py` 대응)와 앱 주제(건강) 둘 다

## 가벼운 실측 (2026-10-12, Julian 「가볍게 실측」, revision 00016)

운영 서버에 새 기기 키로 질문 6개(모델 호출 약 6회, 아기 데이터는 지어낸 것). 장치는 `server` 밖 임시 스크립트.

| 장면 | 결과 |
|---|---|
| 에어컨 · 창문 질문에 옛 앱처럼 분유 기록을 통째로 보냄(프롬프트만으로 버티는지) | 분유 이야기 없음. 에어컨 · 바람 방향 · 환기로 답함. 다만 「습도 50~60도」라고 단위를 틀림 |
| 분유로 시작한 나쁜 답 뒤 「분유 먹이는 거랑 에어컨이 무슨 상관이야?」 | 「분유 이야기는 이 질문과 상관없었어요」 한 문장으로 인정하고 에어컨 질문에 다시 답함. 되묻지 않음. 요약에 지적과 인정이 남음 |
| 이어서 「그럼 에어컨은 몇 도로?」 + 앞 요약 | 에어컨 주제로 이어 답함(24~26도). **그런데 새 요약이 이번 마디만 담고 앞 내용과 「분유는 상관없다」를 잃음** |
| 6마디 밖의 목욕 이야기를 요약으로만 주고 「아까 목욕 물 온도 몇 도라고 했죠?」 | 요약에서 38도 · 5~10분을 찾아 답함 |
| 변비 이야기 뒤 「분유랑 변비가 무슨 상관이 있어요?」(진짜 상관을 묻는 질문) | 사과하지 않고 분유가 변을 되직하게 만들 수 있다고 이유를 설명함 |
| 「창문 열어두고 재워도 돼요?」 | 발열 · 위험 신호로 가지 않음. 다만 「찬바람에 감기」라는 근거 없는 말로 닫으라고 함 |

요약이 앞 내용을 잃던 것은 프롬프트를 「이전 요약을 먼저 그대로 옮기고 이번 질문과 답을 한 문장 덧붙인다, 바로잡은 것은 지우지 않는다」로
고쳤다. 무료 키 로컬 서버로 같은 「몇 도로?」 한 마디만 다시 재니(호출 1회) 새 요약이 앞 내용 · 「분유 이야기가 상관없었다」 · 이번 답을
모두 담았다. 이 보강은 revision 00017 로 나갔다.

기억과 상관없는 답 내용 두 가지(습도 단위, 창문 · 감기)는 일반 답의 품질 문제라 이 task 에서 고치지 않고 Julian 판단에 맡긴다.
