## 목표

Julian(2026-10-12): 「앱 안에서 애매하게 적힌 문구들을 최종적으로 정리하고 가자. 일반적으로 쓰는 문장이나 단어가 아닌
기계적으로 쓰인 부분이 있는지 1차 판단을 해 달라. 엄청 많을 것 같다」.

앱 안 글 전부(83개 파일, 약 650줄)를 읽고 골랐다. 약관 · 개인정보 · 의학 고지(`legal.ts`)는 격식 글이라 여기서 빼고
출시 전 검토 때 따로 본다. 만화(`intro.tsx`)는 홍보 글이라 뺐다(정본 store-toon).

★ 는 분명히 기계적인 것, ○ 는 그대로 둬도 되지만 고치면 더 사람 말인 것.

## 괜찮다고 본 것(참고)

안부 묻는 말(「어제 ○○가 열이 났다고 하셨죠. 오늘은 좀 어때요?」), 부모 안부 답(「오늘은 ○○ 잘 때 같이 눈 붙여요」),
챙길 것 여정 · 정류장 말, 기록 카드(「요 며칠 기록이 비었어요 · 생각나는 것만 적어 주세요」), 온보딩 첫 줄(「매일 아침, 버디가 먼저 챙길게요」),
알림함 빈 화면 글, 광고 없이 쓰기 글은 사람 말로 읽힌다.

Julian: 「우선 바꿀 수 있는 건 초안대로 다 바꾸고, 문구는 내가 확인하고 디테일하게 바꾸는 걸 말할게」. A~F 전부 초안대로 넣었다(94곳).

D+N 은 기록이 생긴 날짜(「10월 8일 대화에서」)로 바꿨고, 생활 항목의 「확인」은 해낸 일이 아니라 알아 둔 것이라 그대로다.
설계 문서(ask · home · baby · my 의 문구 예시, backend 의 when_label 예시)도 같이 맞췄다. 서버 문서의 「정밀 답변 · 절약 모드」는
내부 이름이라 그대로 두고, ask.md 에 화면 이름과의 대응을 적었다.

## 2차 (2026-10-12, Julian 이 폰에서 보고)

- 버디 탭 바닥 고지: 「답변은 참고용이에요 · 응급 상황은 119 또는 병원으로」 → **「급할 땐 버디 말고 119 · 소아청소년과로」**.
  「참고용」은 답마다 붙이지 않고 의학 정보 고지 · 약관에 둔다 — constitution 2 와 SPEC-ASK-02 를 같이 고쳤다.
  법적 경계는 약관 · 고지가 지고, 답 화면의 한 줄은 응급만 가리킨다. 출시 전 법률 검토 때 한 번 더 본다
- 우리 아기 탭: 「이 숫자는 이 폰에 저장된 기록으로만 세요. 서버로 보내지 않아요」 두 곳 삭제(개인정보 처리방침에 있다)
- 일정 탭: 「날짜는 생일로 어림한 거예요 …」 두 곳 삭제 — 날짜 뒤의 「무렵」이 어림이라는 뜻을 이미 전한다(SPEC-GROW-01 시점)
- 마이: 알림 세 줄 + 시간 칩 + 설정 열기를 **한 줄 요약**(「아침 브리핑 오전 8시 · 기록 요청 받음」)으로 줄이고, 상세 화면
  `src/app/notifications.tsx` 로 옮겼다(한눈 요약 + 상세 뎁스). 마이의 긴 문장도 줄였다 — 기록 줄은 「N개」, 생활 팁은 「끄면 접종 · 검진만」,
  가족 공유 카드는 「가족 공유가 생기면 로그인이 같이 들어와요. 지금은 로그인 없이 다 써요」
- 대안을 물은 둘은 Julian 이 골랐다 — 「알게 된 내용 · 아직 모르는 내용」, 일정 탭은 1번(「개월별 챙길 것」 · 「다 했어요 · 지났어요 · 이번 달 · 다음」)
- 3차(2026-10-12): 바닥 고지는 Julian 의 문장대로 「버디의 답은 응급 상황을 대신할 수 없어요 · 급할 땐 119 나 응급실로」. 「이 폰 안에만 저장돼요」 약속은 온보딩 · 기록 화면에서 뺐다 —
  가족 공유가 빨리 올 수 있어서. 개인정보 처리방침의 「기기 안에만」은 지금 실제 동작이라 그대로 두고 가족 공유 때 바꾼다
