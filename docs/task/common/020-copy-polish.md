## 목표

Julian(2026-10-12): 「앱 안에서 애매하게 적힌 문구들을 최종적으로 정리하고 가자. 일반적으로 쓰는 문장이나 단어가 아닌
기계적으로 쓰인 부분이 있는지 1차 판단을 해 달라. 엄청 많을 것 같다」.

앱 안 글 전부(83개 파일, 약 650줄)를 읽고 골랐다. 약관 · 개인정보 · 의학 고지(`legal.ts`)는 격식 글이라 여기서 빼고
출시 전 검토 때 따로 본다. 만화(`intro.tsx`)는 홍보 글이라 뺐다(정본 store-toon).

★ 는 분명히 기계적인 것, ○ 는 그대로 둬도 되지만 고치면 더 사람 말인 것.

## A. 앱 전체에 걸친 말버릇 — 한 번 정하면 여러 화면이 같이 바뀐다

| 번호 | 지금 | 왜 | 제안 |
|---|---|---|---|
| A1 ★ | 「정밀 답변」 · 「일반 기준 답」 | 내부 개념어(기록 있는 답 / 없는 답). 사용자는 「정밀」이 뭔지 모른다 | 「우리 아기 맞춤 답」 · 「일반 답」 |
| A2 ★ | 기록 출처 「D+120 질문에서」 · 「D+120에 알림」 · 「D+120에 적음」 | 개발자 말. D+ 를 아는 부모도 날짜가 더 편하다 | 「10월 8일 대화에서」 · 「10월 8일 알림에서」 · 「10월 8일에 적음」 |
| A3 ★ | 「기록 3건」(마이 · 기록 화면 · 답 꼬리표 · 처리 현황) | 「건」은 서류 말. 우리 아기 탭은 이미 「개」 | 「기록 3개」로 통일 |
| A4 ★ | 「특이사항」(하루 기록 칸 · 기록 이름) | 보고서 말 | 칸 제목 「평소와 달랐던 것」, 기록은 「달랐던 것: …」 |
| A5 ★ | 알림함 카드 「오늘의 브리핑이 도착했어요」 · 「이번 주 일정이 도착했어요」 · 「5개월 일정이 도착했어요」 | 전에 지적한 「도착했어요」 문구가 남아 있다 | 「오늘 브리핑」 · 「이번 주 일정」 · 「5개월 일정」 |
| A6 ○ | 「내일 0시에」 · 「0시에 채워져요」 | 0시는 시스템 말 | 「자정이 지나면」 · 「자정에 다시」 |
| A7 ○ | 지식층 이름이 화면마다 다르다 — 「표준 육아 지식」 · 「표준 지식」 · 「공공 지식」 · 「공공 기준」 | 같은 것을 네 이름으로 부른다 | 한 말로 「공공 지식」. 출처 있는 답 꼬리표는 「출처 있음」 |
| A8 ○ | 「대조」 · 「반영」 · 「계산」 | 사무 말 | 「살피다 · 확인하다」 · 「쓰다」 · 「세다」 |
| A9 ○ | 「기기」와 「폰」이 섞여 있다 | — | 화면은 「폰」, 약관은 「기기」 그대로 |
| A10 ○ | 「발달 포인트」(월간 브리핑 · 일정 탭) | 포인트는 사무 말 | 「이달의 발달」 |
| A11 ○ | 「완료」(했어요 시트 제목 · 단추) | 시스템 말 | 「했어요」 |

## B. 버디 탭

| 번호 | 지금 | 제안 |
|---|---|---|
| B1 ★ | 한도 다 썼을 때: 「오늘은 버디가 답할 수 있는 양을 다 썼어요. 내일 0시에 다시 답해 드릴게요. 위험해 보이는 증상을 말씀하시면 그 안내는 지금도 바로 드려요.」 | 「오늘 질문은 여기까지예요. 자정이 지나면 다시 답할 수 있어요. 아기가 위험해 보이면 지금도 바로 알려 드려요.」 |
| B2 ★ | 광고 충전 말풍선: 「광고 1편을 보면 우리 아기 기록을 반영한 답변 5회가 채워져요(하루 2편까지). 지금 바로 일반 기준으로 답해 드릴 수도 있어요.」 제목 「오늘 정밀 답변 10회를 다 썼어요」 단추 「광고 보고 정밀 답변」 · 「일반 기준으로 바로 답변」 | 「광고 한 편을 보면 맞춤 답 5개를 더 할 수 있어요(하루 2편까지). 기록 없이 일반 답으로는 지금 바로 들을 수 있어요.」 제목 「오늘 맞춤 답 10개를 다 썼어요」 단추 「광고 보고 맞춤 답 더 받기」 · 「일반 답으로 바로 듣기」 |
| B3 ○ | 머리말 「정밀 답변 7회 남음」 · 「오늘 정밀 답변 끝 · 0시에 채워져요」 | 「맞춤 답 7개 남았어요」 · 「오늘 맞춤 답은 다 썼어요 · 자정에 다시」 |
| B4 ○ | 첫 인사 「만 5개월 ○○ 기준으로 답해요. 이야기해 주신 건 기록해 두고, 다음 답에 반영할게요.」 | 「만 5개월 ○○에 맞춰 답해요. 알려 주신 건 기억해 뒀다가 다음 답에 써요.」 |
| B5 ○ | 「버디가 지금 답을 만들지 못했어요」 | 「버디가 지금은 답하지 못했어요」 |
| B6 ○ | 입력창 「답을 입력하거나 위에서 골라 주세요」 | 「위에서 고르거나 직접 적어 주세요」 |
| B7 ○ | 처리 현황 「위험 신호 기준부터 대조하고 있어요…」 · 「출처를 대조하고 있어요…」, 펼친 단계 「위험 신호 기준 대조 / 고열 · 숨쉬기 · 경련 같은 신호 기준과 먼저 맞춰 봤어요」, 접힌 줄 「4단계 확인했어요」 | 「위험 신호부터 살피고 있어요…」 · 「출처를 확인하고 있어요…」, 「위험 신호 확인 / 고열 · 숨쉬기 · 경련 같은 신호가 있는지 먼저 봤어요」, 「확인 4가지 마쳤어요」 |
| B8 ○ | 답 꼬리표 「우리 아기 기록 3건 참고」 · 「공공 기준」 · 「일반 기준 · 기록 없이」 | 「우리 아기 기록 3개 봤어요」 · 「출처 있음」 · 「일반 답 · 기록 없이」 |
| B9 ○ | 「충전을 확인하지 못했어요. 광고를 끝까지 봤다면 잠시 뒤 다시 눌러 주세요」 | 「광고 본 것을 확인하지 못했어요. 끝까지 봤다면 잠시 뒤 다시 눌러 주세요」 |

## 괜찮다고 본 것(참고)

안부 묻는 말(「어제 ○○가 열이 났다고 하셨죠. 오늘은 좀 어때요?」), 부모 안부 답(「오늘은 ○○ 잘 때 같이 눈 붙여요」),
챙길 것 여정 · 정류장 말, 기록 카드(「요 며칠 기록이 비었어요 · 생각나는 것만 적어 주세요」), 온보딩 첫 줄(「매일 아침, 버디가 먼저 챙길게요」),
알림함 빈 화면 글, 광고 없이 쓰기 글은 사람 말로 읽힌다.
