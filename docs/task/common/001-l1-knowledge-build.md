# 001 L1 지식베이스 1차 구축 — 라이선스 확인부터

> 상태: 대기
> 근거: SPEC-ASK-01(출처 화이트리스트) · SPEC-HOME-02(추천의 재료) — 정본: [l1-knowledge-base](../../architecture/l1-knowledge-base.md)
> 횡단(common): 물어보기 답변·홈 추천·성장 타임라인이 모두 이 데이터를 소비한다

## 목표

0~12개월 × 6분류(접종·검진·발달·수유·수면·안전) 150~250항목의 L1 지식을 항목 스키마대로
구축한다. 1단계가 걸려 있는 미결(출처 라이선스)의 해소다.

## 단계

1. **출처 7곳 라이선스 확인** — 각 출처의 이용 조건(공공누리 유형 등)을 실제 페이지에서 확인해
   l1-knowledge-base.md 화이트리스트 표의 "미확인"을 결과와 근거 링크로 채운다.
   **이게 끝나기 전에는 어떤 출처도 본문 근거로 쓰지 않는다**
2. 저장 형식 확정 — `src/data/l1/` 항목 파일(YAML 또는 JSON) + 로더 + 판(version) 번호
3. 접종·검진부터 증류 — 홈 차집합 추천이 먼저 쓰는 분류. AI 초안 → **Julian 검토·승인(의료 게이트)**
4. 발달·수유·수면·안전 증류 — 같은 절차. red_flag 항목은 기준 수치가 출처와 일치하는지 검수 2회
5. `timeline.ts` 목업의 L1 부분을 실데이터로 교체

## 완료 조건

- [ ] 화이트리스트 표의 출처 7곳 전부에 라이선스 확인 결과와 근거 링크가 있다 (미결 해소)
- [ ] (SPEC-ASK-01) 모든 항목에 source(이름·URL·확인일)가 있고 본문이 재서술이다
- [ ] 접종·검진 항목으로 홈 챙길 것 추천이 실데이터로 동작한다
- [ ] red_flag 항목의 기준 수치가 출처와 일치함을 2회 검수했다
- [ ] Julian 승인 없이 배포 판에 들어간 항목이 0건이다
