# 016 승인된 지식은 모두 어딘가에 닿아야 한다 — 고아 항목 시험

## 목표

Julian(2026-10-08, 온톨로지 세미나 뒤): 「지식 77개 중 어떤 질문에도 쓰이지 않는 항목이 있어도 지금은 모른다. 자동 시험을 하나

있는 모양이다 — 승인만 돼 있고 검색이 한 번도 고르지 않는 항목.

## 정한 것

- **닿음의 정의** — 승인 항목은 셋 중 하나에는 닿아야 한다: ① 평가 질문 세트의 어느 질문에서든 L1 검색이 고른다 ② 서버 코드가
  id 를 직접 쓴다(위험 신호 규칙) ③ 앱 코드가 id 를 직접 쓴다(돌봄 신호). 시험은 `server/tests/test_l1_reach.py`
- **시험을 통과시키는 방법은 질문을 더하는 것**이지 검색을 넓히는 것이 아니다. 질문을 더하면 「그 질문에 그 항목이 나오는가」까지
  같이 확인된다(`test_retrieval.py` 의 사실 질문 시험). 억지 근거 금지 원칙은 그대로
- **평가 질문 세트가 역량 질문 목록이다**(세미나 3 · 4교시 「역량 질문을 합격 기준으로」). 모델 비교용으로 만든
  `server/eval/questions.json` 이 지식베이스의 합격 기준도 겸한다. 두 목록을 따로 두지 않는다

## 한 것

- 시험을 처음 돌렸을 때 승인 77개 중 **43개**가 평가 질문 30개의 검색에 안 닿았다. 그중 위험 신호 8개(`k-warn-*`)와 부모 돌봄
  4개(`k-parent-*`)는 규칙 · 돌봄 신호 코드가 직접 쓰므로 닿은 것으로 본다. 남은 **31개**(수유 14 · 안전 6 · 수면 3 · 발달 3 ·
  접종 4 · 검진 1)를 덮는 사실 질문 **26개**(q31~q56)를 평가 세트에 더했다 — 모두 부모가 실제로 물을 법한 말로
- 「머리를 덮지 않고, 너무 덥지 않게」(k-sleep-0004)만은 자연스러운 어떤 말로도 두 글자 겹침이 모자라 안 나왔다. 주제어 표에
  「덥게 · 덥지 · 더운 · 머리를 덮」을 더했다(꿀 · 이불 · 카시트와 같은 성격 — 뜻이 분명한 낱말)
- 평가 질문이 가리키는 id 가 승인 항목에 실제로 있는지도 같은 시험 파일에서 본다(항목을 지우거나 이름을 바꾸면 걸린다)
- 수면 분류 낱말에 「잘때」를 더했다 — 「잘 때 이불 · 잘 때 모자」처럼 잠자리 질문의 흔한 머리말인데 빠져 있었다
- **덤으로 찾은 오탐**: 새 질문 「아기 주변에서 담배 피우면 안 되죠?」가 위험 신호(피 섞인 변, k-warn-0008)로 잡혔다 —
  「주변」의 변과 「피우다」의 피가 규칙에 걸린 것. 담배를 묻는 부모가 응급실 안내를 받을 뻔했다. 규칙에서 둘을 빼고
  통과 시험 두 줄을 더했다. 잡아야 할 문장 표(`eval/redflag_phrases.json` · `test_redflag.py` MUST_CATCH)는 그대로 다 잡는다

## 확인
