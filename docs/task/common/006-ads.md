> api-contract `GET /v1/reward/ssv`

## 목표

홈·성장의 배너 자리에 실제 AdMob 배너를 붙이고, 하루 정밀 답변을 다 쓴 사람이 광고 1편을 보면 정밀 답변 1회가
충전되게 한다. 충전은 AdMob 이 서버로 알린 것(SSV)만 믿는다.

## 먼저 정한 것

1. **전면 광고는 넣지 않는다** — main-design 「다음」. `showInterstitial` 자리도 걷었다
2. **Expo Go·웹에서는 광고 모듈을 읽지 않는다** — 늦게 읽고(require) 없으면 자리 표시. 그래서 Expo Go 로도 앱을 계속 볼 수 있다
3. **광고 단위 id** — 개발 빌드는 Google 시험 단위, 출시 빌드는 `EXPO_PUBLIC_ADMOB_{BANNER,REWARDED}_{IOS,ANDROID}`.
   없으면 광고를 내지 않는다(시험 광고가 출시판에 나가지 않게). 앱 id(app.json)는 지금 Google 시험 앱 id — 출시 전에 바꾼다
4. **SSV 의 userId 는 기기 키의 SHA-256** — 서버가 이미 해시로 기기를 알아서 그대로 찾고, 키 원문은 광고 회사로 가지 않는다
5. **충전 확인** — 광고를 끝까지 보면 앱이 1.5초 간격으로 6번까지 자격을 다시 받아, 남은 수가 오르면 같은 질문을 정밀로 다시 보낸다
6. **광고 등급 PG**, 시작 순서는 유럽 동의 → iOS 추적 허용 → SDK 시작. 동의 메시지가 AdMob 에 없어도(국내) 그대로 시작

## 단계

1. 서버 — `domain/reward`(GET /reward/ssv, Google 키로 서명 검증, 거래 한 번만, 하루 3편) · 저장소에 `reward_tx`
2. 시험 — `tests/test_reward.py`(시험용 키로 서명)
3. 앱 — `src/data/ads.ts`·`ads.web.ts`, `ad-banner.tsx`(홈 인라인, 성장 바닥 고정), 한도 말풍선의 「광고 보고 정밀 답변」
4. 설정 — app.json 플러그인(시험 앱 id, 추적 허용 문구), `eas.json`, expo-dev-client
