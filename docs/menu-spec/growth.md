# 성장 — 시간축 전체의 타임라인

> 근거: [main-design](../architecture/main-design.md) · [knowledge-layers](../architecture/knowledge-layers.md)

0개월부터 가로로 흐르는 월령 시퀀스에서 표준(L1)과 우리 아기(L2)를 교차해 본다.
홈이 "지금"이라면 여기는 "전체 흐름"이다. 매거진·읽을거리는 두지 않는다.

## SPEC

### SPEC-GROW-01 가로 월령 시퀀스
```
평시 ▸ 0개월부터 월 단위 컬럼이 가로 스크롤로 이어져야 하며, 컬럼 단위로 스냅되어야 한다.
평시 ▸ 화면을 열면 현재 월령 위치에서 시작해야 하고, 현재 월은 눈에 띄게 구분되어야 한다.
```

### SPEC-GROW-02 두 지식층의 교차 표시
```
평시 ▸ 각 월 컬럼은 표준 트랙(L1)과 우리 아기 트랙(L2)을 함께 보여줘야 하며,
      두 층은 색으로 일관되게 구분되어야 한다(범례 제공).
평시 ▸ L2 항목에는 기록/요약 구분과 시점이 보여야 한다.
```

### SPEC-GROW-03 빈 자리의 의미
```
미래  ▸ 미래 월은 흐리게 표시하고 우리 아기 트랙에 "앞으로 채워질 기록"을 보여줘야 한다.
과거  ▸ 과거 월에 기록이 없으면 "기록 없음"으로 표시한다. 없음을 잘못으로 표현하지 않는다.
```

### SPEC-GROW-04 광고
```
평시 ▸ 타임라인 아래에 배너 광고 1개를 두고 광고임을 표시해야 한다.
```

### SPEC-GROW-05 또래 부모들의 질문 묶음
```
평시    ▸ 타임라인의 각 월 컬럼에, 그 월령 아이를 키우는 부모들이 자주 물은 질문 묶음을
         보여줘야 한다. 항목을 누르면 캐시된 답변을 바로 보여준다(LLM 재호출 없이 —
         backend 라우팅 ② 캐시).
미래 월  ▸ 아직 오지 않은 월에도 보여줘야 한다. 다가올 시기에 무엇이 궁금해지는지 미리 보는 것이
         이 기능의 값이고, 기록이 없어 비어 있던 미래 컬럼을 이것이 채운다.
익명    ▸ 묶음은 익명 집계로만 만든다. 질문 원문을 그대로 노출해서는 안 되고 대표 질문은 재서술한다.
         표본이 작은 구간(같은 생일 단위 등)은 주령·월령 밴드로 넓혀 묶는다.
```

## HOW (현재 구현)

- 화면: `src/app/(tabs)/growth.tsx` — View 기반 뼈대 완성(스냅 스크롤·현재월 자동 시작·두 트랙·범례).
  현재 월은 저장된 생일에서 계산한 월령으로 잡는다.
- **현재 월에서 시작하기**: `contentOffset` 은 iOS 에서만 먹으므로, 내용이 깔린 뒤(`onContentSizeChange`)
  한 번 `scrollTo` 로 옮긴다. 웹·안드로이드에서 0개월부터 열리던 문제를 이렇게 고쳤다(2026-10-01).
- 월 컬럼은 저마다 테두리를 둬서 한 달이 하나의 카드로 묶여 보이게 하고, 현재 월만 포인트 색으로 둔다.
- 미구현: 또래 질문 묶음(SPEC-GROW-05) — 서버 코호트 집계가 생긴 뒤에 붙는다.
- 데이터: `src/data/timeline.ts` 목업(0~6개월). 실데이터 전환 시 L1 은 지식베이스에서, L2 는 기기 저장소에서.
  미래 월 컬럼은 지금 "앞으로 채워질 기록"만 있는데, 그 자리를 또래 질문 묶음이 채우게 된다.
- 그래픽 업그레이드 경로: 하이브리드 구조 — 레이아웃·콘텐츠는 RN View 로 두고, 연결 곡선·스크롤 연동
  애니메이션 같은 커스텀 그래픽만 Skia 캔버스를 얹는다. 제스처·전환은 Reanimated(이미 설치됨).
  근거는 [app-design](../app-design/README.md)의 애니메이션 절.
