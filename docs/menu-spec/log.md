# 기록 탭 — 빠른 기록과 버디의 해석

> 첫 화면이다(decisions/023). 헌장 5조 「기록은 빨리 받고, 버디가 해석한다」의 메뉴.
> 위에 있는 것: [constitution](../constitution.md) · [main-design](../architecture/main-design.md)

## SPEC

### SPEC-LOG-01 빠른 기록
```
평시 ▸ 모유(왼쪽 · 오른쪽, 먹인 시간) · 분유(수유량, 5ml 단위) · 기저귀(소변 · 대변 · 둘 다, 대변이 있으면 변 색) · 잠(잠든 때 · 깬 때) ·
       체온 · 몸무게 · 키를 기록 탭에서 바로 남길 수 있어야 한다. 기저귀 소변은 두 번 눌러 끝나야 한다.
평시 ▸ 기록의 때는 「지금」이 기본이고, 몇 분 전으로 쉽게 바꾸고 1분 단위로 맞출 수 있어야 한다. 걸린 시간(모유 · 잠)도 1분 단위다.
조건 위반 ▸ 기록이 위험 신호 기준에 닿으면(3개월 미만 38℃ 이상 · 40℃ 이상 체온, 빨간 변) 그 L1 위험 신호 안내를 고정 문장으로 보여야 한다(헌장 2).
금지 ▸ 기록을 남기지 않았다고 탓하는 말을 쓰지 않는다(헌장 5).
```

### SPEC-LOG-02 재는 중
```
평시 ▸ 모유와 잠은 「시작」을 누르면 재기 시작하고, 앱을 닫았다 열어도 그대로 이어서 보여야 한다. 「끝」을 누르면 걸린 시간과 함께 기록된다.
평시 ▸ 재는 중인 것은 기록 탭 맨 위에 보이고, 거기서 바로 끝낼 수 있어야 한다.
```

### SPEC-LOG-03 오늘의 기록
```
평시 ▸ 오늘 남긴 기록이 시간 순서로 보여야 하고, 누르면 고치거나 지울 수 있어야 한다.
평시 ▸ 맨 위에 마지막 수유가 얼마 전인지, 오늘의 수유 · 기저귀 · 잠 합계를 한 줄로 보여야 한다.
```

### SPEC-LOG-04 그래프
```
평시 ▸ 최근 7일의 수유(횟수 · 분유 양) · 잠(시간) · 기저귀(횟수)를 날마다 보여야 하고, 몸무게 · 키는 기록한 날마다 이어서 보여야 한다.
평시 ▸ 숫자는 우리 아기의 평소(최근 7일 평균)와 나란히 보여 준다.
평시 ▸ 맨 위에 아기 월령의 기준표(수유 · 잠 · 기저귀)를 보여야 한다 — 승인된 L1 항목만, 출처와 함께. 그 월령의 공공 기준이 없으면 없다고 말한다.
금지 ▸ 숫자로 정상 · 이상을 판정하지 않는다(헌장 2). 평소와 다르다는 사실만 말한다.
```

### SPEC-LOG-05 기록 알림
```
평시 ▸ 수유: 마지막 수유(모유 · 분유)를 시작한 뒤 정한 시간(기본 3시간)이 지나도록 새 수유 기록이 없으면 알림을 한 번 보내야 한다.
평시 ▸ 기저귀: 마지막 기저귀 뒤 정한 시간(기본 3시간)이 지나면 한 번.
평시 ▸ 잠: 잠에서 깬 뒤 우리 아기가 평소 깨어 있던 시간(기록이 모자라면 월령에 맞춘 기본값)이 지나도록 잠 기록이 없으면 한 번.
평시 ▸ 체온: 매일 아침 · 저녁 한 번씩. 몸무게 · 키는 알림이 없다.
평시 ▸ 마이 → 알림에서 하나씩 끄거나 시간을 바꿀 수 있어야 한다.
금지 ▸ 알림 글에 아기 이름 · 기록 내용을 넣지 않는다(잠금 화면에 보인다).
```

### SPEC-LOG-06 버디와 이어지기
```
평시 ▸ 질문할 때 주제에 닿는 최근 기록 요약(최근 24시간의 수유 · 잠 · 기저귀, 최근 체온, 마지막 몸무게 · 키)이 맥락으로 함께 가야 한다(SPEC-ASK-01).
평시 ▸ 「우리 아기」 탭의 지식 지도(SPEC-BABY-01)도 기록 탭의 기록으로 채워져야 한다 — 수유 방식 · 간격 · 한 번 먹는 양 · 밤잠 · 낮잠 · 몸무게 · 키 · 아팠던 일.
다음 ▸ 아침 브리핑에 어제 기록을 한 줄로 요약한다.
```

### SPEC-LOG-07 가족과 함께
```
평시 ▸ 가족 공유(SPEC-MY-05)를 켜면 이 기록도 가족 폰끼리 맞춰져야 한다. 재는 중인 것도 보인다.
```

## HOW

- 저장: 기기 DB `care_event`(backend 「기기 DB 스키마」) — 종류 · 시작 · 끝 · 양 · 쪽 · 기저귀 · 메모 · 만든 때 · 고친 때.
  재는 중은 끝이 비어 있는 행이다(모유 · 잠 각각 하나까지). 코드는 `src/data/events.ts` · `events-context.tsx`
- 화면: `src/app/(tabs)/index.tsx`(기록 탭) · 입력 시트 `src/components/log/log-sheet.tsx` · 그래프 `src/app/log-stats.tsx`
- 요약과 평소 비교: `src/data/event-summary.ts` — 모델을 부르지 않는다
- 알림: 기기가 거는 로컬 알림(`src/data/notifications.ts`) — 수유 · 기저귀 · 잠은 기록이 바뀔 때마다 다시 걸고(`events-context.tsx`),
  체온은 매일 오전 8시 · 오후 8시. 잠 알림의 깨어 있던 시간은 최근 7일 잠 사이 틈의 가운데 값(셋 이상일 때), 아니면 월령 기본값(`defaultAwakeMinutes`)
- 기준표: `src/app/log-stats.tsx` `NORMS` — 승인 L1 만(초안은 나오지 않는다). 잠 그래프에는 기준 범위를 옅은 띠로
- 우리 아기 탭: `event-summary.ts` `eventFacts` 가 사실 칸 값을 만들고 `knowledge-profile.ts` 가 대화 기록과 비교해 늦게 안 쪽을 보인다
- 질문 맥락: `src/data/ask-context.ts` 가 기록 요약 줄을 만들어 주제에 닿는 것만 보낸다(decisions/022)
- 가족 맞추기: `POST /v1/family/sync` 의 `events`(api-contract)
