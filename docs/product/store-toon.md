스토어에는 만화만 따로 올릴 수 없다:

그래서 만화 영상은 SNS 용이고, 스토어 영상은 앱 화면 녹화에 아빠 목소리를 입힌다.

## 주인공

- **아빠(Julian)**: 덥수룩한 머리에 둥근 안경을 쓴 캐리커처다. 잘생길 필요 없이 공감 가고 웃기기만 하면 된다(Julian).
  - 개발자이고 첫아이 아빠다. 준비성은 넘치는데 새벽 3시에 무너진다.
  - 표정이 웃음의 중심이다: 자신만만, 멘붕, 곁눈질, 분노, 감동의 눈물, 좀비.
- **말콩이**: 아기. 대사는 없고 울음과 웃음만 있다
- **버디**: 쪽쪽이 문 아기 캐릭터([decisions/015](../decisions/015-character-buddy.md)). 이미 있는 그림(`assets/images/mascot/`)을 그대로 쓰고 3막에만 나온다

## 규칙

- **진짜 서비스 이름과 로고를 쓰지 않는다**: 「블로그 검색」「해외 검색」「AI 챗봇」처럼 부른다.
  - 앱스토어는 다른 회사의 상표와 앱 이름을 막는다(5.2.1 · 2.3.7). 구글 플레이도 허락 없는 남의 상표와 로고를 막는다.
  - 표시광고법은 근거 없이 경쟁사를 깎아내리는 광고를 금지한다. 이름을 안 밝혀도 누군지 알 수 있으면 해당된다.
  - 그래서 웃음은 특정 회사가 아니라 누구나 겪은 「상황」에서 만든다: 체험단 글, 번역투, 광고 팝업, 최악부터 나오는 검색.
  - 검색 결과의 주소는 `.example` 처럼 실제로 없는 주소만 쓴다.
- **광고 문구는 실제 동작과 맞춘다**: 공공 출처 지식은 지금 77건이라 출처가 없는 답도 많다. 그래서 「모든 답에 출처」라고 쓰지 않는다.
  - 출처 장면은 출처가 실제로 붙는 질문으로 찍는다(접종 → 질병관리청).
- **「앱 여러 개를 하나로」는 「찾기와 묻기」로 말한다(Julian 승인)**: 「앱 11개 뒤지던 걸, 이제 버디에게 물으면 끝」.
  - 수유 타이머나 기저귀 기록 앱을 대신한다고 하지 않는다. constitution 5(기록 앱과 경쟁하지 않는다)와 실제 기능에 맞춘 것이다.
- **그림체는 빌리지 않는다**: 참고한 육아툰(@DDa_rabba)의 그림체와 캐릭터는 따라 그리지 않는다. 빌리는 것은 연출 문법까지다.

## 「해외 검색」이 왜 문제인가 — 2막의 근거

1. **나라 기준이 섞인다**
   - 체온은 화씨(100.4°F = 38°C), 분유는 온스(oz), 몸무게는 파운드(lb)로 나온다.
   - 접종 일정도 나라마다 다르다. 예를 들어 BCG 는 한국에서는 생후 4주 안에 맞지만 미국에서는 기본 접종이 아니다.
   - 해열제 용량도 그 나라 제품 기준이라 그대로 따르면 위험할 수 있다.
2. **번역 짜깁기 글**: 한국어 결과는 해외 글을 기계 번역해 광고를 잔뜩 붙인 수익형 블로그가 많다. 7컷이 이것이다.
3. **최악부터 보인다**: 증상을 검색하면 드물고 무서운 병부터 나와 불안만 커진다. 8컷이 이것이다.
4. **날짜가 없다**: 예전 권고가 지금은 바뀐 경우가 있다.
   - 엎드려 재우기는 지금은 하지 말라고 한다.
   - 신생아에게 보리차를 주던 권고도 지금은 6개월 전에는 물을 주지 말라고 바뀌었다.
   - 그런데 언제 쓴 글인지 안 보이는 경우가 많다.

## 만드는 법 (`marketing/toon/`)

| 파일 | 하는 일 |
|---|---|
| `draw.js` | 손그림 느낌의 선 그림 도구: 아빠 표정 13가지, 아기, 말풍선, 소품 |
| `panels.js` | 12컷 배치 — 글과 위치를 고치려면 여기 |
| `toon.html` | 한 컷을 1080×1350 으로 그리는 틀(`?p=번호`) |
| `reel.html` · `make-reel.swift` | 릴스 9:16 장면과 mp4. ffmpeg 없이 macOS 기본 기능으로 만든다 |
| `render.sh` | `./render.sh` 는 12컷 PNG, `./render.sh 3 6` 은 그 컷만, `./render.sh reel` 은 릴스 mp4 |

mp4 와 릴스 중간 장면은 용량이 커서 git 에 넣지 않는다. 필요하면 `./render.sh reel` 로 다시 만든다(1분 안쪽).
