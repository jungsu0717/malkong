# 출시 체크리스트 — 모든 앱 공통

앱을 스토어에 처음 올릴 때 거치는 순서다. 육아버디(apps/malkong)의 실제 진행 기록은
[apps/malkong task common/008](../../apps/malkong/docs/task/common/008-first-release-check.md) 에 있다.
가격과 스토어 규정은 자주 바뀌므로 진행할 때마다 검색해 다시 확인한다.

## 계정 — Julian 이 한 번만 만든다(모든 앱이 같이 쓴다)

| 계정 | 비용 | 메모 |
|---|---|---|
| Apple Developer Program(개인) | 1년 129,000원(2026-10 기준) | 한 계정으로 앱을 여러 개 올릴 수 있다 |
| Google Play Console(개인) | 25달러 한 번 | 새 개인 계정은 테스터 12명 이상이 14일 동안 비공개 테스트를 해야 정식 출시를 신청할 수 있다 |
| AdMob(개인) | 무료 | 앱마다 앱 등록과 광고 단위를 따로 만든다 |
| Expo(EAS) | 무료 범위 | 계정 `julian-malkong`. 앱마다 EAS 프로젝트가 따로 생긴다 |

광고로만 수익을 내면 두 스토어 모두 사업자등록과 통신판매업 신고가 필요 없다. 유료 앱이나 인앱 결제(구독 포함)를 넣는 순간 필요해진다.

## 앱마다 하는 것

1. **앱 식별자** — iOS 번들 ID 와 Android 패키지 이름. 스토어에 한 번 올리면 바꿀 수 없다.
2. **이름 확인** — 앱스토어 검색과 KIPRIS(특허청 상표 검색)에서 같은 이름이 없는지 확인한다.
3. **약관 · 개인정보 처리방침 웹 주소** — 운영자 이름, 문의 이메일, 시행일이 들어간다. 저장하는 데이터를 실제와 맞게 적는다.
4. **AdMob** — 앱 두 개(iOS, Android)와 광고 단위를 만든다. 광고 콘텐츠 등급을 앱에 맞게 고른다.
5. **출시 빌드** — `npx eas-cli@latest build --platform ios --profile production`(앱 폴더에서). 첫 iOS 빌드는 애플 로그인을 물어서 Julian 이 직접 친다.
6. **스토어 정보** — 제품 브리프의 스토어 문안, 스크린샷, 앱 개인정보 라벨, 연령 등급, 심사 메모. Play 는 데이터 보안, 콘텐츠 등급, 건강 앱 신고서까지.
7. **제출 전 전체 화면 확인** — 실제 빌드로 한 번 처음부터 끝까지 눌러 본다.
