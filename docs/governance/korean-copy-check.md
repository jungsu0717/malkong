# 화면 문구 점검표 — AI 가 쓴 티를 걷어 내기

Julian(2026-10-29): 「이 앱을 클로드를 통해 찍어내듯이 만들지 않았다가 중요해.」
루트 AGENTS.md 「하지 말 것 1순위」(어색한 말 금지)를 짧은 화면 문구에 맞게 항목으로 푼 것이다.
`epoko77-ai/im-not-ai`(Humanize KR, MIT)의 AI 티 분류 10 범주 85 패턴에서 단추 · 제목 · 한 줄 설명에 해당하는 것만 추렸다.
새 화면을 만들거나 문구를 고치면 이 표에 대 본다. 앱마다 `npm run copy-check` 로 기계가 먼저 찾고 사람이 판단한다.

## 바로 빼는 것

| 번호 | 티 | 예 | 고치기 |
|---|---|---|---|
| 1 | 느낌표 · 이모지 · 「~!」 응원 | 「잘했어요!」 「🎉 완료」 | 느낌표를 떼고 사실만. 칭찬 문구는 아예 두지 않는다(루틴 칸이 완료로 보이면 충분) |
| 2 | 광고 말 | 스마트한, 간편하게, 손쉽게, 효율적으로, 최적의, 완벽한, 솔루션, 혁신, 놀라운, 특별한, 소중한 | 무엇을 하는지만 쓴다(「접종 날짜를 미리 잡아요」) |
| 3 | 영어 추상어 직역 | 경험을 제공, 다양한 기능, 활용해 보세요, 관리하세요, 여정, 인사이트 | 사람이 하는 말로(「여기서 봐요」, 「고를 수 있어요」) |
| 4 | 이중 피동 · 번역투 | 되어지다, 보여지다, ~에 의해, ~을 통해, ~에 있어서, ~함으로써, ~을 바탕으로 | 능동 · 단일 피동(「보여요」), 조사로 바로 잇기(「생일로 계산해요」) |
| 5 | 형식 명사 결말 | 「~하는 것이 중요해요」 「필요한 것은 ~」 「~라는 점」 | 주어와 서술어를 바로(「~해야 해요」 「~이 필요해요」) |
| 6 | 상투 결산 · 열거 도입 | 결론적으로, 이를 통해, 다음과 같은, 크게 세 가지 | 삭제하고 본론부터 |
| 7 | 기계 같은 알림 · 통계 칸 이름 | 「도착했어요」 「함께 쌓아 온 것」 「알림은 약속이다」 | 내용 문장으로(「분유가 내일 와요」) — 루트 AGENTS.md 「화면은 한눈 요약과 상세 화면으로」 |
| 8 | 당연한 고지 · 구구절절 설명 | 「CDC 는 이 앱을 보증하지 않아요」 | 화면에서 빼고 약관 · 고지 문서에만(루트 AGENTS.md 「화면 문구는 최소로」) |
| 9 | 조사가 어긋난 압축 | 「육아의 챙길 것」 「루틴 완료 시 알림」 | 풀어서(「육아에서 챙길 것」 「루틴을 끝내면 알려요」) |
| 10 | 같은 어미 반복 | 「~해요. ~해요. ~해요.」 세 줄 | 한 줄로 줄이거나 어미를 바꾼다 |

## 고치지 않는 것

- 다른 앱에서 흔히 보는 말(추가, 편집, 삭제, 완료, 추천, 자동 분류, 숨김 해제)은 그대로 둔다 — 익숙한 말이 자연스러운 말이다.
- 「확인하세요」 「골라 주세요」처럼 사용자에게 행동을 묻는 보통 명령문은 광고 말이 아니다.
- 「~할 수 있어요」는 한 화면에 한 번이면 괜찮다. 네 번 넘게 반복될 때만 줄인다.
- 숫자 · 고유명사 · 공공 자료 제목(「영유아 건강검진」)은 손대지 않는다.

## 어떻게 돌리나

- 앱 폴더에서 `npm run copy-check` — `src/` 의 한국어 문자열을 모아 위 표의 낱말 · 기호를 찾아 파일과 줄 번호로 보여 준다. 찾은 것을 하나씩 보고 고치거나 둔다.
- 긴 글(스토어 설명 · 약관 · README)은 Claude Code 에 `/plugin marketplace add epoko77-ai/im-not-ai` → `/plugin install humanize-korean@im-not-ai` 를 설치하고 `/humanize-korean` 에 넣는다(Julian 이 직접).
