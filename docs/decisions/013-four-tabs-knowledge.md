# 013 탭 넷 — 두 번째 탭은 말콩이가 아는 우리 아기

> 상태: 확정 (2026-10-03, Julian 결정) — [012](012-chat-first-three-tabs.md)의 탭 구성(셋)을 대체한다. 대화가 첫 화면 · 시안 B 는 그대로

## 맥락

탭 셋으로 바꾼 뒤 Julian 이 말했다: "하단 메뉴 총 4개로 해서 새로 추가할 메뉴는 두 번째로 두고, 그 메뉴에 우리 아이에 대한
모든 정보가 아주 잘 들어가 있으면 좋겠다. 지식이 쌓인 수준도 3D 엔진 같은 멋진 그래프로 보여지고, 두 번째 탭만 보면
우리 아기를 엄청 잘 알고 있구나 느끼면서 와우 포인트와 아하 모먼트를 느낄 수 있게."

product-brief 의 차별점 「우리 아기를 아는 AI」를 대화 속 표시 한 줄(「기록 N건 참고」)이 아니라 **한 화면 전체**로 보여 달라는 뜻이다.

## 결정

1. **탭 넷** — 말콩(대화) · **우리 아기**(말콩이가 아는 것) · 성장(챙길 것 · 타임라인) · 마이.
   정의는 [main-design](../architecture/main-design.md) 「구조」, 새 탭의 SPEC 은 [baby](../menu-spec/baby.md)
2. **우리 아기 = 지식 지도** — 영역(먹기 · 잠 · 성장 · 건강 · 발달 · 생활)마다 말콩이가 아는 것과 모르는 것을 3D 로 돌려 보는
   그래프, 아는 정도(%)와 단계, 한눈에 보는 프로필, 알려 주면 좋아지는 것, 함께 쌓아 온 흐름
3. **아는 정도는 기록에서만 센다** — 기록(L2)과 완료 표시가 근거다. 점수를 꾸미거나 모델에게 추정시키지 않는다
4. **그래픽은 Skia**(`@shopify/react-native-skia`) — app-design 이 정한 커스텀 그래픽 자리. Expo Go 에 들어 있고, 웹은
   CanvasKit 을 불러 같은 코드로 그린다. 3D 는 원근 투영을 직접 계산해 UI 스레드에서 그린다(Reanimated)
5. 기록 보기·고치기는 우리 아기 탭에서 들어가는 화면(`/records`)으로 돌아간다

## 기각한 대안과 이유

- 탭 셋에 「우리 아기」 안에 지식 보기를 하나 더 — 일정·성장·기록·지식이 한 탭에 넷이 되어 첫 화면에서 지식이 안 보인다
- three.js(react-three-fiber + expo-gl) 로 진짜 3D — 번들이 크고(three 만 약 600KB) Expo Go·웹·새 아키텍처 조합의 위험이 크다.
  이 그래프에 필요한 것(구 · 빛 번짐 · 원근 · 회전)은 Skia 로 충분하다
- 아는 정도를 모델이 판단 — 근거 없는 숫자가 된다(constitution 원칙 1)
