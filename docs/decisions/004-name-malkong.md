# 004. 서비스 이름 = 말콩 (malkong)

- 날짜: 2026-10-01 · 상태: 확정
- 결정: 서비스명과 agent(캐릭터) 이름을 **말콩 / 말콩이**로 확정한다. 유래와 스토어 서사는
  [product-brief](../product/product-brief.md)의 「이름」 절이 정본.

## 왜

1. **탄생 서사가 이름 그 자체** — 창업자 아이의 실제 태명(말띠 해의 콩알이). "말콩이를 키우다
   직접 만든 앱"이라는 실화가 피칭·스토어 소개가 된다.
2. **타깃과의 동질감** — 사용자들이 바로 '콩' 계열 태명을 짓는 부모들이고, 태명은 임신기에
   생기는 이름이라 고도화 1순위(임신 준비~출산 확장)와 정확히 만난다.
3. **겹뜻** — '말'은 말띠이자 말(言): 말을 걸면 알아듣는 콩. 대화가 곧 기록인 제품 본질과 겹친다.
4. **변별** — 웹·스토어 검색상 "말콩" 선점 없음(2026-10-01 확인). KIPRIS 정식 검색은 출원 전 1회.

## 기각한 대안

- 부사형(성큼·부쩍·어느새·나란히) — 사용자 기각: 영유아 치우침·평이함
- 관용어형(안다·찰떡·있잖아) — 사용자 기각: 있는 단어 느낌
- 코인 1차(포그니·또또·아요 등) — 포그니는 기존 상호 존재로 탈락
- 캐릭터형 2차(아이비·티아·마니 등 10종) · 의태어형 3차(콩닥·윙벨·소곤 등 10종) — 콩닥이
  최종 후보였으나, 말콩이 콩닥의 장점(태명 콩·두근거림)을 품으면서 실화 서사를 더함
