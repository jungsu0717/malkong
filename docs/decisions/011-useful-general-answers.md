# 011 일반 답은 흔히 알려진 범위를 말하고, 판단 질문에도 쓸모 있게 답한다

> 상태: 확정 (2026-10-03, Julian 결정)

## 맥락

Julian 이 아이폰(Expo Go)으로 배포한 서버에 물어보니 답이 거의 다 "소아청소년과에 가 보세요"였다.
SPEC-ASK-08 보다 프롬프트가 더 세게 막고 있었다.

- 일반 수위에서 L1 에 없는 숫자(수유량·수면 시간)를 말하지 못하게 하고 "검진·진료 때 확인"으로 돌렸다
- "우리 아기"가 들어간 질문이 모두 판단 수위로 가서 진료 권유로 끝났다
- "아기마다 달라요"까지 안심 표현으로 잡아, 두 번 걸리면 고정 문장("판단해 드릴 수는 없어요")이 나갔다

L1 은 73건이고 대부분 접종·위험 신호라, 수유·수면·이유식 같은 일상 질문은 거의 다 여기에 걸렸다.

## 결정

정의는 [ask](../menu-spec/ask.md) 「답 검사」와 서버 `app/domain/ask/system_prompt.txt`.

1. **일반 수위는 흔히 알려진 기준을 범위로 말한다** — "일반적으로는 보통 120~160ml 정도"처럼. 한 숫자로
   못 박지 않고, 「일반 기준」 표시(SPEC-ASK-08)는 그대로 붙는다. 집에서 해 볼 방법을 구체적으로 알려 준다
2. **판단 수위는 "괜찮은가요·정상인가요"처럼 판정을 직접 구하는 질문만이다** — 방법·기준·시기를 묻는 질문은
   아기 이야기가 들어 있어도 일반이다
3. **판단 질문에도 쓸모 있게** — 괜찮다·정상이다·걱정 말라는 판정은 여전히 하지 않는다. 대신 이 월령에 흔한
   모습, 집에서 살펴볼 것, 진료가 필요한 기준을 알려 준다. "아기마다 차이가 있어요"는 사실이라 허용한다
4. **진료 권유는 진료가 필요한 기준을 말할 때 끝에 한 번만** — 모든 답을 진료 권유로 끝내지 않는다

constitution 원칙 1(근거 없는 답을 근거 있는 척 내보내지 않는다)은 그대로다 — 범위로 말한 일반 답에도
일반 정보 표시가 붙고 출처를 지어 달지 않는다. 진단·약 이름·용량 금지(원칙 2)도 그대로다.

## 기각한 대안과 이유

- 지금처럼 출처 없는 숫자 금지 — 안전하지만 일상 질문 대부분이 "진료 때 확인하세요"가 되어 앱을 쓸 이유가
  없어진다. 부모가 가장 많이 묻는 것이 바로 그 숫자다
- L1 을 넓힐 때까지 기다리기 — 국내 출처(중앙육아종합지원센터) 라이선스 확인이 남아 있어 언제 될지 모른다.
  L1 이 늘면 그 질문은 사실 수위로 올라가므로 이 결정과 부딪히지 않는다

## 남은 위험

  숫자는 L1 에 근거를 넣어 사실 수위로 올리는 것이 정답이다(common/001)
