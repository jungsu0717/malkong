# 014 서비스 이름 = 육아버디, AI 이름 = 버디

> 상태: 확정 (2026-10-03, Julian 결정) — [004](004-name-malkong.md)(말콩)를 대체한다. 말콩이는 마스코트로 남는다

## 맥락

Julian 이 앱을 써 보고 이름을 바꾸기로 했다. 따져 본 조건:

1. **마케팅비가 거의 없다** — 앱스토어 검색과 소셜 소액 광고로만 알린다. 이름만 보고 무슨 앱인지 알아야 한다
2. **임신 → 육아 → 교육으로 넓힌다**(product-brief 장기 비전) — 한 앱 안에 서비스를 나눠 넣는다. 아기 시기에 갇히면 안 된다
3. **대화하는 앱이라는 게 드러나야 한다** — 마미톡처럼
4. **영어 단어를 쓰면 영어권에서도 자연스러워야 한다**

## 결정

- 서비스(앱) 이름 **육아버디** — 영어로 그대로 옮기면 'Parenting Buddy', 실제로 쓰는 자연스러운 표현이다.
  영어의 parenting 도, 한국어의 육아도('초등 육아', '사춘기 육아') 임신 준비부터 10대까지 덮는다
- 대화하는 AI 의 이름 **버디** — "버디에게 물어보세요", "버디가 정리했어요". 대화 탭 이름도 「버디」
- 마스코트 **말콩이**(쪽쪽이 문 아기 · 붉은 말) — 아이콘 · 로딩 · 빈 화면의 그림으로 남는다. 이름의 유래(창업자 아이의 태명)는
  브랜드 이야기로 쓴다
- 앱 식별자 `com.yugabuddy.app`(iOS · Android), 딥링크 scheme `yugabuddy`. 주소는 `yugabuddy.com` · `yugabuddy.kr`(Julian 구입)
- 슬로건 — *모든 육아하는 부모의 마음을 헤아려 만들었어요* · *아이가 자라는 만큼, 아이를 아는 마음도 함께 자라요*
- **코드명은 malkong 그대로** — 저장소 · GCP 프로젝트 · Cloud Run 서비스 · EAS slug · 환경변수 접두어(`MALKONG_`)는 바꾸지 않는다.
  사용자에게 보이지 않고, 바꾸면 배포 · 비밀값 · 빌드 연결이 모두 끊긴다

## 확인한 것 (2026-10-03, 웹·앱스토어 훑기 — 상표 검색 아님)

- 'Parenting Buddy'는 영어권에 여럿(유니세프 Parent Buddy, 독일 ParentingBuddy, 미국 The Parent Buddy) — **영어 이름으로는 쓰지 않는다**

- `미결:` KIPRIS 상표 검색과 출원 — Julian(변리사 상담). '육아'가 설명하는 말이라 등록 가능성 확인이 필요하다
