L1 은 이 앱의 핵심 자산이다. 답변 품질의 상한이 여기서 정해진다.

## 항목 스키마

지식 1건 = 항목 1개. 저장은 저장소 안 YAML(빌드 시 앱 번들·서버 검색용으로 함께 나간다).

```yaml
- id: k-vacc-0401              # k-<분류>-<월령 2자리><순번>
  months: [4]                  # 해당 월령. 걸치면 [4, 5, 6]
  kind: 접종                    # 접종·검진·발달·수유·수면·생활·안전·대응
  title: DTaP 2차
  body: >                      # 원문을 복제하지 않은 재서술. 수치·기준은 출처 그대로
  source:
    name: 질병관리청 예방접종도우미
    url: https://...
    checked: 2026-09-30        # 원문을 마지막으로 확인한 날
  confidence: 표준              # 표준(일정·기준) · 권고(가이드라인) · 참고(일반 정보)
  red_flag: false              # 위험 신호 항목 여부 (true 면 검수 2회)
```

```
평시 ▸ source 가 없는 항목은 만들 수 없어야 한다. source.name 은 화이트리스트 안이어야 한다.
평시 ▸ body 는 재서술이어야 하며, 원문 문장의 복제나 특정 저작물의 목차 구조 복제를 해서는 안 된다.
평시 ▸ 항목에는 판 번호(version)가 붙고, 앱은 자기 판과 서버 최신 판을 비교해 갱신받는다.
```

## 출처 화이트리스트 — 1차

**채택 게이트**: 목록에 있어도 각 출처의 이용 조건(공공누리 유형 등)을 실제 페이지에서 확인하고
그 결과를 아래 표에 적기 전에는 본문 근거로 쓰지 않는다.

| 출처 | 영역 | 라이선스 확인 |
|---|---|---|
| 질병관리청 예방접종도우미 | 표준 예방접종 일정 | 미확인 |
| 질병관리청 국가건강정보포털 | 질환·증상·건강 정보 | 미확인 |
| 국민건강보험 영유아 건강검진 | 검진 일정·항목 | 미확인 |
| 보건복지부·중앙육아종합지원센터 | 발달·양육 정보 | 미확인 |
| 미국 CDC 발달 이정표 | 발달 (퍼블릭 도메인 성격) | 미확인 |
| WHO 수유·성장 가이드라인 | 수유·성장 | 미확인 |
| 대한소아청소년과학회 공개 자료 | 전문 견해 | 미확인 — 공개≠재사용 허용. 기본은 사실만 참조+링크 |

화이트리스트 밖 자료(서적·블로그·카페·병원 사이트)는 본문 근거로 쓰지 않는다. 구조를 잡을 때의
관점 참고까지만.

## 1차 구축 범위와 절차

- **범위**: 0~12개월 × 접종·검진·발달·수유·수면·안전 여섯 분류. 어림 150~250항목.
  13~24개월과 대응(질환·증상) 분류는 2차.
- **절차** (모든 항목 공통):
  1. 출처 원문 수집 (화이트리스트 + 라이선스 확인 완료분만)
  2. AI 가 스키마에 맞춰 증류 초안 (재서술 + 출처 + checked)
  3. **사람(Julian) 검토·승인 — 의료 게이트. 승인 없이 배포 판에 들어가지 않는다**
  4. red_flag 항목은 검수를 한 번 더 (기준 수치가 출처와 일치하는지)
- **갱신**: 분기마다 출처 개정 여부를 확인하고 checked 를 갱신한다. 출처가 바뀌면 항목을 고치고
  판을 올린다.

## 미결

- 각 출처의 라이선스 확인 결과 기입 (구축 첫 task 의 1단계)
- 위험 신호(red_flag) 항목의 기준 수치 확정 — 임의로 적지 않고 출처에서 가져온다
