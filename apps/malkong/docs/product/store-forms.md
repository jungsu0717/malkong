# 스토어 입력 칸 답안 — App Store Connect · Play Console

> 상태: 답안 (2026-10-22, task common/024). Julian 이 제출 화면에 옮겨 넣는다. 문항이 바뀌었으면 화면의 문항을 따르고 이 파일을 고친다.
> 근거: 앱이 실제로 하는 일(개인정보 처리방침 `src/data/legal.ts`), 서버가 저장하는 것([backend](../architecture/backend.md)),
> 광고 SDK 가 모으는 것(구글 공식 안내 — [Play 데이터 보안용](https://developers.google.com/admob/android/privacy/play-data-disclosure) ·
> [App Store 용](https://developers.google.com/admob/ios/privacy/data-disclosure), 2026-10-22 확인).

## 공통 사실

- 로그인이 없다. 이름 · 전화번호 · 이메일을 받지 않는다
- 기기 키: 앱을 처음 열 때 서버가 주는 무작위 값. 광고 면제 가족 기기 확인과 가족 공유에만 쓴다. 서버에는 해시만 둔다
- 가족 공유(선택, 따로 동의): 아기 이름 · 생일, 접종 · 검진 완료 기록, 할 일 · 장보기 · 루틴과 기록, 우리 아기 메모,
  「가족에게 보일 이름」을 서버(Neon, 싱가포르)에 저장한다. 마지막 구성원이 나가면 지운다
- 광고(AdMob 배너): 구글 SDK 가 IP 주소(대략의 위치), 앱 사용 기록(탭 · 실행), 진단 정보(실행 시간 · 멈춤), 광고 ID 를
  광고 · 분석 · 부정 방지에 모으고 구글과 나눈다. 전송은 모두 암호화(TLS)
- AI 로 내용을 분석하지 않는다. 결제가 없다. 위치 권한을 묻지 않는다

## App Store Connect

### 앱 개인정보(데이터 수집)

| 데이터 종류 | 쓰는 곳 | 사용자와 연결 | 추적에 사용 |
|---|---|---|---|
| 위치 > 대략적인 위치 (광고 SDK 가 IP 로 추정) | 제3자 광고 · 분석 | 아니요 | 예 |
| 식별자 > 기기 ID (광고 ID — 추적 허용을 한 경우) | 제3자 광고 | 아니요 | 예 |
| 사용 데이터 > 제품 상호작용 · 광고 데이터 | 제3자 광고 · 분석 | 아니요 | 예 |
| 진단 > 충돌 데이터 · 성능 데이터 | 분석(광고 SDK) | 아니요 | 아니요 |
| 건강 및 피트니스 > 건강 (가족 공유를 켠 경우 — 접종 · 검진 완료 기록, 메모) | 앱 기능 | 아니요 | 아니요 |
| 사용자 콘텐츠 > 기타 사용자 콘텐츠 (가족 공유를 켠 경우 — 할 일 · 루틴 · 메모) | 앱 기능 | 아니요 | 아니요 |
| 식별자 > 사용자 ID (기기 키) | 앱 기능 | 아니요 | 아니요 |

「사용자와 연결」을 아니요로 둔 까닭: 이름 · 연락처 · 계정이 없고, 기기 키는 무작위 값이라 사람과 묶이지 않는다.
「추적」 줄은 광고 SDK 때문이다 — 앱은 추적 허용(ATT)을 묻고, 허용하지 않아도 그대로 쓸 수 있다.

### 연령 등급

- 폭력 · 성적 · 도박 · 공포 · 욕설 · 약물: 모두 없음
- 의료 또는 건강 관련 내용: **드물게 · 가볍게** — 접종 · 검진 일정과 발달 정보를 안내한다(진단 · 치료는 하지 않음)
- 사용자 생성 콘텐츠 공유 · 채팅 · 웹 열람: 없음(가족 공유는 초대 코드로 묶인 가족끼리만)
- 광고: 있음
- 결과로 보통 4+ 가 나온다. 앱이 정한 최소 나이는 없다(부모가 쓰는 앱)

### 심사 메모(App Review 에게)

```
육아버디는 보호자가 아기 루틴 · 할 일 · 장보기를 챙기고, 아기 시기에 맞는 공공 기관 발달 정보를 보는 앱입니다.
로그인이 없어 심사용 계정이 필요 없습니다. 처음 실행하면 아기 생일만 넣으면 됩니다(아무 날짜나 괜찮습니다).
가족 공유(마이 → 가족과 함께 보기)는 기기 두 대가 필요합니다 — 한 기기에서 「가족 만들기」로 초대 코드를 받고, 다른 기기에서 그 코드로 참여합니다.
의료 진단 · 처방을 하지 않습니다. 발달 정보의 출처는 앱 안 「의학 정보 출처와 한계 고지」에 있습니다(미국 CDC, 질병관리청, 국민건강보험공단).
```

## Play Console

### 데이터 보안

- 데이터를 모으거나 공유하나요: **예**
- 전송 중 암호화: **예**
- 사용자가 삭제를 요청할 수 있나요: **예** — 앱을 지우면 기기 안 정보가 지워지고, 가족 공유 정보는 가족에서 나가면(마지막 구성원) 서버에서 지워진다.
  문의 이메일로도 요청을 받는다

| 데이터 종류 | 모음 / 공유 | 목적 | 선택 여부 |
|---|---|---|---|
| 위치 > 대략적인 위치 (광고 SDK, IP) | 모음 · 공유 | 광고, 분석, 부정 방지 | 필수 |
| 기기 또는 기타 ID (광고 ID · 앱 세트 ID, 기기 키) | 모음 · 공유(광고 ID) | 광고, 분석, 부정 방지, 앱 기능(기기 키) | 필수 |
| 앱 활동 > 앱 상호작용 (광고 SDK) | 모음 · 공유 | 광고, 분석, 부정 방지 | 필수 |
| 앱 정보 및 성능 > 비정상 종료 로그 · 진단 (광고 SDK) | 모음 · 공유 | 광고, 분석, 부정 방지 | 필수 |
| 건강 및 피트니스 > 건강 정보 (가족 공유 — 접종 · 검진 완료 기록, 메모) | 모음 | 앱 기능 | 선택 |
| 개인 정보 > 기타 정보 (가족 공유 — 아기 이름 · 생일) | 모음 | 앱 기능 | 선택 |
| 앱 활동 > 기타 사용자 생성 콘텐츠 (가족 공유 — 할 일 · 루틴 · 메모) | 모음 | 앱 기능 | 선택 |

가족 공유 정보는 같은 가족의 폰에만 가고 제3자에게 넘기지 않는다 — 「공유」가 아니다.
