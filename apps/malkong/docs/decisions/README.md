# decisions — 결정 기록 (ADR)

무게 있는 선택(대안을 기각한 결정)의 **왜**를 남긴다. 정의 자체는 architecture·app-design 이 소유하고,
여기는 그 결정에 이르게 된 이유와 기각한 대안만 담는다 — 같은 내용을 두 번 적지 않는다.

- 파일명: `NNN-<제목>.md`
- 결정을 뒤집을 때는 지우지 않고 상태를 「대체됨 → NNN」으로 바꾼다

## 양식

```markdown
# NNN 제목

> 상태: 확정 | 대체됨 → NNN (날짜)

## 맥락
무엇을 골라야 했나.

## 결정
무엇으로 정했나 (정의가 사는 문서 링크).

## 기각한 대안과 이유
- 대안 A — 왜 아닌가
```
