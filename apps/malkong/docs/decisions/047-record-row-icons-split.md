# 047 위쪽 기록 줄은 기록과 루틴 두 줄로, 기록은 처음부터 모두, 종류마다 다른 아이콘

> 상태: 구현함 (2026-11-11, Julian 「처음부터 넣진마 저건 그럼 루틴 추가로 해줘」) · 시안: https://claude.ai/artifact/4CMt2A8pGPqV1xhaAg3H8x 「13판 시안 — 기록마다 다른 아이콘, 기록과 루틴 나누기, 기록은 처음부터 모두 보이기」
> [046](046-record-bar-and-empty-draft.md)의 「기록 종류와 루틴이 한 줄」과 「처음에는 넷만 보이고 나머지는 넣어야 보인다」를 바꾼다. 「반복할까요?」를 묻는 것, 루틴 「반복 안 함」, 하루 초안은 그대로다.

## 맥락

- 빌드 19 를 본 Julian(2026-11-11): 「아이콘들 다 개성있게 바꿔주면 안되는거야? 그리고 편집이나 이런거 텍스트도 깨지고, 단추라는 표현이 뭐야? 기록으로 하면 되잖아.
  그리고 너가말한 저 단추들 기본으로 다 넣어두고 편집할수있게 하면되는거아니야? 루틴이랑 기록만 구분해서 보여줘」.
- 이유식과 비타민D가 같은 사과 아이콘, 유축 수유와 분유가 같은 젖병, 목욕과 기저귀가 같은 물방울이었다. 새 기록 종류는 모두 같은 옅은 코랄이었다.
- 칸 너비가 74로 고정이라 「유축 수유」, 「손톱 깎기」 같은 이름이 잘릴 수 있었다.
- 기록 11가지를 처음부터 모두 보이면 한 줄에서는 루틴이 옆으로 한참 밀어야 보인다.

## 결정

- **두 줄** (`record-panel.tsx`): 윗줄은 기록 11가지(모유, 분유, 기저귀, 잠, 체온, 이유식, 유축 수유, 유축, 우유, 물, 간식)이고 처음부터 모두 보인다. 끝에 「편집」.
  아랫줄은 「루틴」 이름표 뒤에 알약 모양 칸이다. 누르면 지금 완료, 길게 누르면 루틴 편집. 끝의 「추가」는 기록 편집의 「루틴 추가」로 바로 간다.
- **칸 너비는 글자에 맞춘다**: 기록 칸은 최소 64 에서 이름과 합계만큼 넓어진다. 이름이 잘리지 않는다.
- **기록 편집** (`record-bar-sheet.tsx`): 「기록」, 「숨긴 기록」, 「루틴」, 「숨긴 루틴」, 「루틴 추가」로 나눈다. 기록과 루틴은 각자 끌어서 순서를 바꾼다.
  「루틴 추가」의 목욕, 터미타임, 놀이, 병원, 투약, 기타는 처음부터 만들어 두지 않는다 — 누르면 「반복할까요?」를 묻고 루틴이 된다.
- **화면에서 「단추」라는 말을 뺐다**: 「기록 편집」, 「루틴 이름」, 「누를 때만 기록해요」.
- **아이콘** (`src/components/record-icons.tsx`): 종류마다 모양이 다른 선 아이콘 19개(기록 11, 루틴 추가 6, 손톱 깎기, 비타민). 24×24, 선 1.8 로 베이비 세트와 같은 규격이다.
  색은 묶어서 쓴다 — 모유와 분유는 코랄, 유축 수유와 유축은 옅은 코랄, 이유식과 간식은 살구색, 우유와 물은 청록, 기저귀는 노랑, 잠은 먹색, 체온은 빨강, 루틴은 모두 파랑.
  루틴 아이콘은 이름으로 고른다(목욕은 욕조, 손톱은 가위, 비타민은 캡슐, 병원은 구급 가방, 투약은 스포이트). 흐름 노드와 기록 목록도 같은 아이콘과 색을 쓴다.
- **설정값 `record.bar` 는 v 2**: 12판은 편집을 마치면 넣지 않은 기록 종류까지 뺀 것으로 저장했다. v 가 없는 설정은 처음 넷(모유, 분유, 기저귀, 잠)이 아닌 기록 종류를 다시 보이게 읽는다.

## 기각한 대안과 이유

- **한 줄에 기록과 루틴을 모두** — 기록이 11개라 루틴이 화면 밖으로 밀린다. Julian 도 둘을 구분해 달라고 했다.
- **목욕, 터미타임 같은 루틴도 처음부터 넣기** — 직접 만들지 않은 루틴 6개가 루틴 목록과 가족 폰에 생기고, 투약은 약을 권하지 않는다는 헌장 5 와 걸린다. Julian 이 「루틴 추가」로 두라고 했다.
- **기록마다 다른 색** — 색이 열 가지가 넘으면 조잡해진다(디자인 언어). 모양으로 구분하고 색은 먹는 것, 마시는 것처럼 묶었다.
