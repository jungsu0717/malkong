# 032 앱 아이콘 · 시작 화면을 먹색으로, 로고는 글자 + 별

> 상태: 확정 (2026-10-23) · 시안: https://claude.ai/artifact/4CMt2A8pGPqV1xhaAg3H8x 「제안 — 앱 아이콘 · 시작 화면 · 로고」

## 맥락

- Julian(2026-10-23): 「앱 아이콘이나 시작 화면이 너무 예전 스타일 아니냐」. 아이콘 · 시작 화면의 노란 바탕(decisions/015)은
  지금 앱(흰 바탕 · 먹색 머리 · 코랄 하나)의 어디에도 없는 색이 됐다. 버디 캐릭터는 성장 탭 · 로딩에도 쓰여 그대로 둔다
- Julian: 시작 화면에 루틴 · 할 일 · 성장을 배경으로 표현하고 싶다, 슬로건도 더 예쁘게, 로고가 필요하지 않나

## 결정

- **앱 아이콘** — 먹색(`#16161A`) 바탕에 버디 얼굴, 오른쪽 위에 노란 별(`#FDD686`). 시안의 「A2 먹색 + 별」(Julian 「귀엽다」)
- **기기 시작 화면** — 먹색 바탕 + 서 있는 버디(다크 모드도 같은 먹색). 기기가 그리는 화면은 바탕색과 가운데 그림 하나만 된다
- **이어지는 앱 화면(약 1.9초)** — 같은 자리의 버디 둘레에 성장 탭의 모빌(별 · 달 · 구름), 루틴 · 할 일 · 성장 카드 셋(탭 아이콘과 이름),
  은은한 코랄 빛, 아래에 로고와 슬로건. 단계별 움직임은 두지 않는다(Julian 「움직임은 없어도 될 것 같아」) — 둘레가 0.2초에 나타나 1.2초 머문 뒤 0.5초에 흐려진다.
  카드 내용(목욕 08:10 완료 · 산후 검진 예약 · D+25)은 앱을 보여 주는 그림이다
- **로고** — 글자 「육아버디」(IBM Plex Sans KR Bold) 오른쪽 위에 아이콘의 노란 별(`BrandLogo`). 새 그림을 만들지 않는다
- **슬로건 표기** — 「육아 할 일,」 / 「버디가 챙겨요」 두 줄, 「버디」만 코랄(`BrandSlogan`). 말은 product-brief 그대로
- 노랑은 아이콘 · 로고의 별과 성장 탭 모빌에만 남는다

## 기각한 대안과 이유

- **노랑 바탕 유지** — 앱 안에 없는 색이라 아이콘을 누른 뒤 먹색 루틴 탭으로 넘어갈 때 이어지지 않는다
- **흰 바탕 아이콘** — 홈 화면의 다른 흰 아이콘 사이에서 묻힌다
- **시작 화면의 이름표 · 궤도 안** — 무슨 앱인지가 카드(실제 화면 조각)보다 덜 보인다
- **로고 「아이콘 + 글자」 · 「쪽쪽이 웃는 선」** — 글자 + 별이 아이콘과 가장 짧게 이어지고 어떤 크기에서도 깔끔하다

## 결과

- 아이콘 · 시작 화면은 빌드에 들어간다 — 바꾼 뒤 첫 출시 빌드부터 보인다(Expo Go 는 자체 로딩 화면을 보여 기기 시작 화면은 빌드에서만 보인다)
- decisions/015 의 「색」(아이콘 · 시작 화면은 우주복 노랑)을 이 결정이 바꾼다
