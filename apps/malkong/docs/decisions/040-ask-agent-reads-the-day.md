# 040 물어보기를 에이전트로 — 보고 있는 날의 기록을 함께 읽고, 고칠 것은 변경 카드로

> 상태: 확정 (2026-11-09, Julian 「ㅇ 해줘」) · [039](039-ask-chat-and-feedback-5.md)의 「모델에는 문장만 보낸다」를 처음 한 번 동의를 받는 조건으로 바꾼다.
> 시안: https://claude.ai/artifact/4CMt2A8pGPqV1xhaAg3H8x 「물어보기 에이전트 6판 시안 (2026-11-09)」

## 맥락

- 5판 물어보기는 문장을 기록이나 찾을 조건으로만 바꿨다. 모델이 아기 기록을 못 보니 「이거」, 「그 수유」 같은 말을 알아듣지 못하고, 이미 적은 기록을 고치거나 지울 수 없었다.
- Julian(2026-11-09): 「내가 원하는 agent 는 linear 의 agent 와 비슷한 형상이었으면 좋겠어. 현재 화면에서 물어볼 거 물어보고 답변해주고, 기록이든 처리 결과든 반영해주는 그런 agent 까지」.
  보고 있는 날의 기록을 모델에 보내는 것(처음 한 번 동의)에 「ㅇㅇ」, 6판 시안에 「ㅇ 해줘」.

## 결정

- **처음 한 번 동의를 받는다.** 물어보기 창을 처음 열면 「지금 보는 날의 기록도 함께 읽을까요?」를 보인다. 보내는 것, 받는 곳(Google Gemini, 미국 등), 쓰는 곳, 보관을 한 줄씩 적는다.
  「동의하고 함께 읽기」를 고르면 보고 있는 날의 기록을 문장과 함께 보내고, 「문장만 읽기」를 고르면 지금처럼 문장만 보낸다. 마이 화면에서 언제든 바꾼다.
- **창 위에 맥락 칩을 붙인다.** 보고 있는 날(「11월 6일 하루」)과, 창을 연 채 흐름이나 목록에서 누른 기록(「선택 · 13:50 분유 120ml」, ×로 풀기).
  창이 열려 있을 때 기록을 누르면 입력 시트 대신 선택이 된다.
- **한 번 묻는 데 모델은 한 번 부른다.** 서버 `/v1/agent` 가 문장, 최근 대화 몇 줄, 그날 기록(동의했을 때만), 선택한 기록을 받아서 답 글과 바꿀 것 목록을 돌려준다.
  여러 번 오가는 도구 호출은 두지 않는다 — 하루치 기록이면 한 번에 충분하고, 비용과 기다리는 시간이 늘지 않는다.
- **바꿀 것은 앱이 보이고 사람이 누른다.** 새 기록만 있으면 039 처럼 바로 저장하고 「되돌리기」를 보인다.
  고치기, 지우기, 일정, 그리고 이것들이 섞인 처리는 변경 카드(「수정 분유 120ml 13:50 → 13:40」)로 보이고 「모두 적용」을 눌러야 반영한다. 적용한 뒤에도 「되돌리기」가 있다.
- **모델은 기록만 고르고, 숫자와 답 문장은 앱이 쓴다.** 「이거 앞 수유보다 많이 먹은 거야?」에는 모델이 두 기록을 고르고 앱이 차이를 센다.
  며칠에 걸친 합계와 평균(「이번 주 밤잠 평균」)은 지금처럼 찾을 조건으로 받아 앱이 기기 안 기록에서 센다.
  처음에는 모델이 답 글을 쓰게 했다. 그런데 실제 호출 24번(2026-11-09)에서 세 모델(3.1 Flash-Lite, 3.5 Flash-Lite, 3.8 Flash) 모두
  정해진 JSON 칸 안에 혼잣말을 쓰거나(「2개월 접종Parse error: … No, wait」) 같은 말을 되풀이했다(Julian 「ㅇㅇ」으로 이렇게 바꿈).
- **규칙이 먼저다.** 건강 질문은 정해 둔 한 줄, 「이전 수유 언제 했어?」 같은 말과 기록 하나는 앱 규칙이 바로 처리한다.
  「이거」, 「옮겨 줘」, 「지워 줘」처럼 화면을 가리키거나 고치는 말, 규칙으로 못 읽은 말만 모델로 보낸다.
- **보관하지 않는다.** 서버는 받은 문장과 기록, 모델 답을 저장하지도 로그에 남기지도 않는다. Gemini 에도 저장하지 않게(store=false) 보낸다. 기기마다 하루 호출 수에 상한을 둔다.
- 건강, 육아 조언, 의료 판단은 지금처럼 답하지 않는다(헌장 5).

## 기각한 대안과 이유

- 서버가 여러 번 도구를 부르며 스스로 찾고 고치는 방식 — 하루치 기록은 한 번에 보낼 수 있을 만큼 작다. 왕복이 늘면 느리고 비싸며, 앱이 모르는 사이에 바뀔 위험이 있다.
- 모든 기록(며칠, 몇 달 치)을 보내기 — 보내는 양이 크고 동의 범위가 넓어진다. 긴 기간의 숫자는 앱이 세는 편이 정확하다.
- 고치기도 바로 반영하고 되돌리기만 두기 — 잘못 고친 것을 사람이 알아채기 어렵다. 새 기록과 달리 원래 값이 사라진다.
- 동의 없이 기록을 보내기 — 아기 기록이 밖으로 나가는 일이라 처음 한 번은 꼭 묻는다.
