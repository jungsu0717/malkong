# 008 운영 모델은 Gemini 3.5 Flash-Lite — 가장 싼 모델부터 재서 기준을 넘은 첫 모델

> 상태: 확정 (2026-10-02)

## 맥락

backend 는 "어느 급의 모델을 고정할지 같은 질문 20~30개로 두 급을 비교해 정한다"고 미뤄 두었다. 비교 상대로
Claude Sonnet 5.5 를 잡았지만, Julian 에게 개인 Anthropic 계정이 없고 구글 클라우드(Vertex AI)로 쓰면
Marketplace 종량제라 무료 크레딧이 적용되지 않았다. Julian 은 비교 대신 "제일 싼 것으로 우선 가고, 답변 수준을
보고 모델을 바꾸자"고 정했다(task common/003). 모델은 설정값 한 줄로 바뀌므로(decisions/007) 이 방식이 성립한다.

## 결정

운영 모델은 **Gemini 3.5 Flash-Lite**(`gemini-3.5-flash-lite`)다. 정의와 고르는 방식은
[backend](../architecture/backend.md) 「어느 모델을 쓰는가」.

근거(질문 30개 × 4판, `server/eval/results/2026-10-02-*`):

| 판 | 프롬프트 | 규칙 통과 | 내용 점수 | 지어낸 출처 | 위험한 조언 |
|---|---|---|---|---|---|
| 1 | 처음 | 29/30 | 50/60 | 0 | 0 |
| 2 | 2차 | 29/30 | 52/60 | 0 | 0 |
| 3 | 3차(지금 쓰는 것) | 29/30 | 54/60 | 0 | 0 |
| 4 | 3차 다시 | 29/30 | 51/60 | 0 | 0 |

- 네 판 모두 통과 기준(형식 깨짐·지어낸 출처·진료 권유 빠짐·위험한 조언 0건, 나머지 규칙 90% 이상)을 넘었다
- 응답 시간 중앙값 1.5초, 90% 1.9초. 유료 티어 가격으로 1건 약 1원(입력 약 1,100토큰)
- 사실 조회(접종·검진)는 L1 을 그대로 전하고 받은 id 만 인용했다. 상관없는 L1 조각을 섞어 준 문항에서도
  엉뚱한 인용이 없었다

남은 약점과 다루는 곳:

- 판단 요구 중 발달 질문에서 "발달 속도는 다양하니 조급해하지 마세요" 같은 **안심 표현이 네 판 중 두 번** 나왔다
  (SPEC-ASK-08). 프롬프트만으로는 다 막히지 않으므로, common/004 에서 판단 수위 답변의 안심 표현을 서버가
  검사해 다시 생성하게 한다
- 일반 정보 답에 출처 없는 숫자(시간, 온도, 나이)가 남는다. "일반적으로는"은 밝히므로 위험하지는 않다
- 질문과 관련된 기록이 있어도 답에서 짚지 않을 때가 있다(q27)

## 기각한 대안과 이유

- **Gemini 2.5 Flash-Lite**(더 싸다) — 호출하니 "새 사용자에게는 더 이상 제공하지 않는다"(404)고 답했다.
  종료 일정표에는 없던 제한이다
- **Gemini 3.1 Flash-Lite** — 2027-05-07 종료 예정이라 올라갈 순서에서 뺐다
- **Gemini 3.8 Flash** — 3.5 Flash-Lite 가 기준을 넘어서 올라갈 필요가 없었다. 2027-01-01 부터 값이 두 배가 된다
- **Claude Sonnet 5.5** — 위 맥락의 계정·결제 이유로 이번에는 재지 않았다. 어댑터와 테스트는 있어서, 나중에
  같은 질문 세트로 재면 된다(backend 「모델은 갈아끼우는 부품이다」)
- **두 급을 나란히 비교** — Julian 결정으로 하지 않았다. 대신 같은 질문 세트가 남아 있어 모델을 바꾸거나
  프롬프트를 고칠 때마다 다시 잴 수 있다
