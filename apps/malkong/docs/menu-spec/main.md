# 오늘 탭 — 육아비서 첫 화면 (루틴 · 오늘 할 일)

> [decisions/028](../decisions/028-assistant-today-routines.md). 메뉴 코드 `MAIN` — 예전 `HOME`(보관)과 다르다

## SPEC

### SPEC-MAIN-01 오늘 한눈에
```
평시 ▸ 앱을 열면 「오늘」이 첫 화면이어야 한다. 맨 위에 날짜와 태어난 지 며칠, 그 아래 루틴, 오늘 할 일, 다가오는 날 한 줄 순으로 보인다.
평시 ▸ 루틴은 알림 시각으로 아침(11시 전) · 낮(17시 전) · 저녁 · 하루 중(시각 없음)으로 묶여 보여야 한다.
       오늘 차례가 아닌 N일마다 루틴은 아래 「다른 날 루틴 N개」에 접어 두고, 펼치면 「내일」 「3일 뒤」가 보인다.
평시 ▸ 오늘 할 일에는 기한이 오늘이거나 지난 할 일과 지금 기간인 접종 · 검진이 보인다(SPEC-TOPIC-02). 바닥 칸에 적으면 내 할 일 · 오늘로 들어간다.
평시 ▸ 다가오는 날 한 줄은 접종 · 검진, 50일 · 100일 · 돌, 사이즈 확인 중 가까운 둘을 D-day 로 보이고, 누르면 그 주제로 간다.
```

### SPEC-MAIN-02 루틴 체크 · 시간 재기
```
평시 ▸ 체크 루틴은 한 번 누르면 했어요가 되고 몇 시에 했는지 보여야 한다(「08:10 했어요」). 다시 누르면 오늘 것을 되돌린다.
평시 ▸ 시간 재기 루틴(터미타임 등)은 +5분 단추와 타이머로 오늘 누적 분을 보여야 한다(「오늘 15분 / 30분」). 타이머를 멈추면 걸린 분(1분 이상)이 쌓인다.
평시 ▸ N일마다 루틴은 지난번부터 며칠인지 보여야 한다(「7일마다 · 6일 만」).
금지 ▸ 루틴을 하지 않았다고 탓하는 말을 쓰지 않는다(헌장 4).
```

### SPEC-MAIN-03 루틴 추가 · 편집
```
평시 ▸ 「루틴 추가」에서 이름, 종류(체크 / 시간 재기), 반복(매일 · 이틀마다 · 사흘마다 · 일주일마다 · N일마다), 알림 시각(없어도 된다),
       하루 목표 분(시간 재기, 없어도 된다)을 정해 만든다. 위에 추천(목욕 · 터미타임 · 젖병 소독 · 산책 · 손톱 깎기 · 장난감 소독 · 아기 침구 빨래 ·
       가습기 청소 · 쪽쪽이 바꾸기)이 있어 누르면 칸이 채워진다. 루틴이 하나도 없을 때는 오늘 화면에 추천 다섯을 바로 추가하는 칩이 보인다.
평시 ▸ 루틴을 길게 누르면 편집 · 삭제할 수 있다. 삭제는 숨김이라 지난 기록은 남는다.
금지 ▸ 영양제 · 약 같은 건강 루틴을 추천하지 않는다(사용자가 직접 넣는 것만, 헌장 5). 시간 재기 루틴에 권장 시간을 미리 넣지 않는다.
```

### SPEC-MAIN-04 루틴 알림
```
평시 ▸ 알림 시각이 있는 루틴은 그 시각까지 오늘 아직 안 했으면 폰이 직접 알려야 한다(「목욕 시간이에요」 / 「저녁 루틴이에요」 ·
       「지난번에 한 지 6일 됐어요」 · 「오늘 15분 했어요」). 「했어요」 · 「1시간 뒤」 단추로 앱을 열지 않고 처리한다.
평시 ▸ 오늘부터 사흘 치를 날짜마다 걸어 두고, 루틴이나 기록이 바뀌거나 앱을 열 때마다 다시 건다. 이미 했으면 그날 알림은 지운다.
       가족이 먼저 했으면 내 폰의 알림도 지운다 — 가족 공유 task 에서.
금지 ▸ 알림 글에 아기 이름과 기록 내용을 넣지 않는다(SPEC-TOPIC-09).
```

## HOW

- 저장: 기기 DB `routine`(정의) · `routine_log`(한 번 할 때마다 한 줄 — 한 때 · 분)(backend 「기기 DB 스키마」). 오늘 했는지 · 오늘 몇 분 ·
  지난번부터 며칠 · 다음 차례는 저장하지 않고 볼 때마다 센다(헌장 3)
- 코드: `src/data/routine.ts`(계산 · 추천, `routine.test.ts`) · `routines-context.tsx`(함께 보는 목록 · 알림 · 알림 단추) ·
  화면 `src/app/(tabs)/index.tsx` · 시트 `src/components/routine/routine-sheet.tsx`
- 알림: iOS 는 걸어 두는 알림이 64개라 루틴은 사흘 치, 할 일 알림 20개, 전날 저녁 3일 치(notifications.ts 머리 주석)
- 「생활 루틴」 주제의 반복 할 일은 처음 열 때 한 번 루틴으로 옮긴다(todos-context, 설정값 `routines_moved_from_topic`)
- 시계는 `useNow`(상태) — 렌더 안에서 `new Date()` 를 바로 쓰면 React Compiler 가 기억해 둬 타이머가 멈춘다
