# 오늘 탭 — 육아비서 첫 화면 (루틴 · 오늘 할 일)

> 위에 있는 것: [constitution](../constitution.md) 1 · 3 · 4 · 5 · 6 · [main-design](../architecture/main-design.md) ·
> [decisions/028](../decisions/028-assistant-today-routines.md). 메뉴 코드 `MAIN` — 예전 `HOME`(보관)과 다르다

## SPEC

### SPEC-MAIN-01 오늘 한눈에
```
평시 ▸ 앱을 열면 「오늘」이 첫 화면이어야 한다. 맨 위에 날짜와 태어난 지 며칠, 그 아래 루틴, 오늘 할 일, 다가오는 날 한 줄 순으로 보인다.
평시 ▸ 루틴은 3열 버튼 모음으로 한눈에 다 보여야 한다(아이콘 · 이름 · 상태 한 줄). 오늘 할 것을 알림 시각 순으로 먼저, 오늘 할 날이 아닌
       N일마다 루틴은 뒤에 흐리게 「내일」 「3일 뒤」로. 누를 때마다 자리가 바뀌지 않게 완료 여부로는 옮기지 않는다. 마지막 칸은 「추가」.
평시 ▸ 오늘 할 일에는 기한이 오늘이거나 지난 할 일과 지금 기간인 접종 · 검진이 보인다(SPEC-TOPIC-02). 바닥 칸에 적으면 내 할 일 · 오늘로 들어간다.
평시 ▸ 다가오는 날 한 줄은 접종 · 검진, 50일 · 100일 · 돌, 사이즈 확인 중 가까운 둘을 D-day 로 보이고, 누르면 그 주제로 간다.
```

### SPEC-MAIN-02 루틴 체크 · 타이머
```
평시 ▸ 체크 루틴 버튼을 누르면 완료로 바뀌고(아이콘에 코랄 체크) 완료한 시각이 보여야 한다(「08:10 완료」, 가족 공유 이름이 있으면 「엄마 · 08:10」).
       다시 누르면 오늘 것을 되돌린다.
평시 ▸ 타이머 루틴(터미타임 등) 버튼을 누르면 타이머가 시작 · 멈춤되고, 오른쪽 위 「+5분」으로 바로 더할 수 있어야 한다. 상태는 「오늘 15분」
       (목표가 있으면 「15분 / 30분」). 타이머를 멈추면 걸린 분(1분 이상)이 쌓인다.
평시 ▸ N일마다 루틴은 마지막으로 한 지 며칠인지 보여야 한다(「마지막 7일 전」).
금지 ▸ 루틴을 하지 않았다고 탓하는 말을 쓰지 않는다(헌장 4).
```

### SPEC-MAIN-03 루틴 추가 · 편집
```
평시 ▸ 「루틴 추가」 위에는 추천(목욕 · 터미타임 · 젖병 소독 · 산책 · 손톱 깎기 · 장난감 소독 · 아기 침구 빨래 · 가습기 청소 · 쪽쪽이 바꾸기)이
       아이콘 버튼으로 다 보이고, 누르면 바로 추가된다(이미 있는 것은 체크 표시). 아래 「직접 추가」에서 이름, 종류(체크 / 타이머),
       반복(매일 · 2일마다 · 3일마다 · 매주 · N일마다), 알림 시각(없어도 된다), 하루 목표 분(타이머, 선택)을 정해 만든다.
       루틴이 하나도 없을 때는 오늘 화면에 추천 아홉 개가 버튼으로 보이고 누르면 바로 추가된다.
평시 ▸ 오늘 화면 루틴 위 「편집」을 누르거나 버튼을 길게 누르면 편집 · 삭제할 수 있다. 삭제는 숨김이라 지난 기록은 남는다.
금지 ▸ 영양제 · 약 같은 건강 루틴을 추천하지 않는다(사용자가 직접 넣는 것만, 헌장 5). 타이머 루틴에 권장 시간을 미리 넣지 않는다.
```

### SPEC-MAIN-04 루틴 알림
```
평시 ▸ 알림 시각이 있는 루틴은 그 시각까지 오늘 아직 안 했으면 폰이 직접 알려야 한다(「목욕 시간이에요」 / 「저녁에 챙길 루틴이에요」 ·
       「마지막으로 한 지 6일 지났어요」 · 「오늘 지금까지 15분」). 「완료」 · 「1시간 뒤」 단추로 앱을 열지 않고 처리한다.
평시 ▸ 오늘부터 사흘 치를 날짜마다 걸어 두고, 루틴이나 기록이 바뀌거나 앱을 열 때마다 다시 건다. 이미 했으면 그날 알림은 지운다.
       가족이 먼저 했으면 내 폰이 맞춰진 뒤 그날 알림을 지운다(SPEC-TOPIC-08 — 내 폰이 알림 시각 전에 앱을 한 번 열었을 때만).
금지 ▸ 알림 글에 아기 이름과 기록 내용을 넣지 않는다(SPEC-TOPIC-09).
```

## HOW

- 저장: 기기 DB `routine`(정의) · `routine_log`(한 번 할 때마다 한 줄 — 한 때 · 분)(backend 「기기 DB 스키마」). 오늘 했는지 · 오늘 몇 분 ·
  지난번부터 며칠 · 다음 차례는 저장하지 않고 볼 때마다 센다(헌장 3)
- 코드: `src/data/routine.ts`(계산 · 추천 · 버튼 상태 한 줄 `statusLine`, `routine.test.ts`) · `routines-context.tsx`(함께 보는 목록 · 알림 · 알림 단추) ·
  화면 `src/app/(tabs)/index.tsx` · 버튼 모음 `src/components/routine/routine-grid.tsx` · 아이콘(이름으로 고름) `routine-icon.tsx` ·
  시트 `routine-sheet.tsx`
- 알림: iOS 는 걸어 두는 알림이 64개라 루틴은 사흘 치, 할 일 알림 20개, 전날 저녁 3일 치(notifications.ts 머리 주석)
- 「생활 루틴」 주제의 반복 할 일은 처음 열 때 한 번 루틴으로 옮긴다(todos-context, 설정값 `routines_moved_from_topic`)
- 시계는 `useNow`(상태) — 렌더 안에서 `new Date()` 를 바로 쓰면 React Compiler 가 기억해 둬 타이머가 멈춘다
