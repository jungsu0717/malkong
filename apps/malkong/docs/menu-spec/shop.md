## SPEC

### SPEC-SHOP-01 살 것
```
평시 ▸ 장보기 카테고리에는 살 것만 있다. 재고 확인 루틴(SPEC-MAIN-06)이 있으면 맨 위에 「재고 확인」 한 줄(「다음 확인 일요일 · 지난번에 부족한 2개를 추가했어요」,
       아직 한 번도 확인하지 않았으면 「다음 확인 일요일」만)이 보이고, 누르면 재고 확인 시트가 열린다. 재고 확인에서 들어간 살 것에는 「재고 확인에서 추가」가 보인다.
평시 ▸ 살 것은 살 곳별로 묶여 보여야 한다 — 매장(사용자가 적은 곳, 최근 쓴 순) → 온라인 → 기타(살 곳을 안 정한 것). 묶음 머리에 개수.
평시 ▸ 바닥 칸 위의 칩(선택 안 함 · 마트 · 온라인 · 사용자가 전에 쓴 곳)으로 살 곳을 고르고 적는다. 고른 칩은 다음에 적을 때도 남는다.
       「다이소에서 수납함」처럼 적으면 살 곳 「다이소」를 읽는다. 한 번 적은 곳은 다음부터 칩으로 보인다.
평시 ▸ 살 것의 동그라미를 누르면 바로 완료다(매장에서 샀을 때). 길게 누르거나 「…」로 이름 · 살 곳을 고치거나 지울 수 있다.
금지 ▸ 처음 칩에 상호를 넣지 않는다(「마트」 「온라인」만, decisions/027).
```

### SPEC-SHOP-02 주문 완료 · 배송 중
```
평시 ▸ 온라인 묶음의 살 것에만 「주문 완료」가 있다. 누르면 주문한 곳(선택)과 도착 예정(오늘 · 내일 · 모레 · 모름, 또는 「10/20」 「금요일」처럼 적기)을 적고
       「배송 중」으로 옮겨야 한다. 배송 중 줄에는 「쿠팡 · 내일 도착 예정」처럼 어디서와 도착 예정이 보인다.
평시 ▸ 배송 중의 동그라미를 누르면 받은 것으로 완료다. 「…」로 주문 정보를 고치거나, 주문 취소(살 것으로 되돌림) · 삭제할 수 있다.
평시 ▸ 주문한 곳은 사용자가 전에 적은 이름을 칩으로 다시 보여 준다. 안 적으면 「온라인」으로 보인다.
금지 ▸ 앱이 쇼핑몰 이름을 미리 넣거나 쇼핑몰로 보내는 링크 · 가격을 보이지 않는다(헌장 8). 송장번호로 배송을 자동 조회하는 것은 첫 판에서 하지 않는다.
```

### SPEC-SHOP-03 다시 담기 · 완료
```
평시 ▸ 지난번에 산 것 중 지금 살 것 · 배송 중에 없는 것을 최근 순으로 열 개까지 「다시 담기」에 보이고, 한 번 누르면 그때의 살 곳으로 살 것에 들어가야 한다.
평시 ▸ 매장마다 마지막으로 장 본 날 함께 산 것(둘 이상)은 「마트 지난번 목록 5개」처럼 한 번에 다시 담을 수 있어야 한다(이유식 재료처럼 늘 같이 사는 묶음).
평시 ▸ 완료한 것은 지우지 않고 접어 두며(헌장 2), 누르면 되돌린다.
```

### SPEC-SHOP-04 배송 알림
```
평시 ▸ 도착 예정일 아침 알림 목록에 「기저귀 4단계 도착 예정」이 들어가야 한다(SPEC-TOPIC-09).
평시 ▸ 도착 예정일 저녁 7시까지 받음 체크가 없으면 「기저귀 4단계 받으셨나요?」를 한 번 알리고, 「수령 완료」 단추로 앱을 열지 않고 완료할 수 있어야 한다.
       받음 체크를 하거나 주문을 취소하면 그 알림은 지운다.
```

### SPEC-SHOP-05 날짜가 아니라 살 것 기준
```
평시 ▸ 날짜가 아니라 살 것 기준이다. 못 산 것은 체크하지 않으면 그대로 남아, 다음 날 다시 만들 필요가 없다.
       (준비할 것 — 외출 가방 · 여행 짐 같은 목록 — 은 할 일 탭 「준비 목록」으로 옮겼다, SPEC-TOPIC-02 · 12)
```

## HOW

- 장보기 줄은 할 일과 같은 `todo` 줄이고 장보기 주제(kind `shopping`)에 있다. 칸 `ordered_at`(주문한 때, 있으면 배송 중) · `arrive_at`(도착 예정일) ·
  `store`(살 곳 — 주문한 뒤에는 주문한 곳)(backend 「기기 DB 스키마」). 주문한 것의 살 곳은 늘 「온라인」으로 본다(`placeOf`)
- 계산: `shopLists` · `shopPlaces` · `toBuyGroups` · `buyAgain` · `lastTrips` · `recentStores`(`src/data/todos.ts`).
  화면 `src/app/(tabs)/shop.tsx`, 시트 `order-sheet.tsx` · `shop-item-sheet.tsx`
- 재고 확인에서 들어간 살 것은 `todo.source = 'stock'`
- 알림: `alert-plan.ts` `morningPlan` · `deliveryChecks`, `notifications.ts` `scheduleDeliveryChecks`(task topic/006)
