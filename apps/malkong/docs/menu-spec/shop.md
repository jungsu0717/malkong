## SPEC

### SPEC-SHOP-01 살 것
```
평시 ▸ 장보기 탭 바닥 칸에 적으면 「살 것」에 들어가야 한다. 살 것의 동그라미를 누르면 바로 완료다(매장에서 샀을 때).
평시 ▸ 살 것을 길게 누르면 이름을 고치거나 지울 수 있어야 한다.
```

### SPEC-SHOP-02 주문했어요 · 배송 중
```
평시 ▸ 살 것의 「주문했어요」를 누르면 어디서(선택)와 도착 예정(오늘 · 내일 · 모레 · 모름, 또는 「10/20」 「금요일」처럼 적기)을 적고
       「배송 중」으로 옮겨야 한다. 배송 중 줄에는 「쿠팡 · 내일 도착 예정」처럼 어디서와 도착 예정이 보인다.
평시 ▸ 배송 중의 동그라미를 누르면 받은 것으로 완료다. 「…」로 주문 정보를 고치거나, 주문 취소(살 것으로 되돌림) · 삭제할 수 있다.
평시 ▸ 어디서는 사용자가 전에 적은 이름을 칩으로 다시 보여 준다.
금지 ▸ 앱이 쇼핑몰 이름을 미리 넣거나 쇼핑몰로 보내는 링크 · 가격을 보이지 않는다(헌장 8). 송장번호로 배송을 자동 조회하는 것은 첫 판에서 하지 않는다.
```

### SPEC-SHOP-03 다시 담기 · 완료
```
평시 ▸ 지난번에 산 것 중 지금 살 것 · 배송 중에 없는 것을 최근 순으로 열 개까지 「다시 담기」에 보이고, 한 번 누르면 살 것에 들어가야 한다.
평시 ▸ 완료한 것은 지우지 않고 접어 두며(헌장 2), 누르면 되돌린다.
```

## HOW

- 장보기 줄은 할 일과 같은 `todo` 줄이고 장보기 주제(kind `shopping`)에 있다. 칸 `ordered_at`(주문한 때, 있으면 배송 중) · `arrive_at`(도착 예정일) ·
  `store`(어디서)(backend 「기기 DB 스키마」)
- 계산: `shopLists` · `buyAgain` · `recentStores`(`src/data/todos.ts`). 화면 `src/app/(tabs)/shop.tsx`, 시트 `src/components/todo/order-sheet.tsx`
- 도착 예정일 아침 알림 · 「받으셨나요?」는 알림 task 에서(SPEC-TOPIC-09 를 그때 갱신)
