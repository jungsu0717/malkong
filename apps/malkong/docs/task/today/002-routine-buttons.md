# 002 오늘 — 루틴을 버튼 모음으로, 어색한 문구 다듬기

> 상태: 구현 완료 (2026-10-16) — 웹에서 확인. 폰은 Julian
> 근거: [main](../../menu-spec/main.md) SPEC-MAIN-01 · 02 · 03 · 04 · 루트 AGENTS 「하지 말 것 1순위」

## 목표

Julian(2026-10-16): 「오늘 탭에서 첫번째, 루틴 추가는 babytime 처럼 버튼들이 다 보였으면 좋겠음. 그리고 루틴 추가 화면에서 한번 누르면 했어요.
이런 이상한문구들 쓰지말라니까? 좀 말들좀 잘 다듬어줘봐」

이 task 가 끝나면 오늘 탭의 루틴이 아이콘 버튼 모음으로 한눈에 다 보이고, 루틴 추가 화면에서도 추천 루틴이 버튼으로 다 보여 한 번 눌러 추가된다.
「했어요」 「7일 만이에요」 같은 어색한 문구가 앱에서 빠진다.

## 정한 것

- 오늘 탭 루틴 칸: 줄 목록 대신 3열 버튼 모음. 버튼마다 아이콘 · 이름 · 상태 한 줄
  - 체크: 누르면 완료(아이콘에 코랄 체크, 「08:10 완료」, 가족 공유 이름이 있으면 「엄마 · 08:10」), 다시 누르면 되돌림
  - 타이머: 누르면 타이머 시작 · 멈춤(「3:12」), 오른쪽 위 「+5분」, 상태는 「15분 / 30분」
  - N일마다 루틴 중 오늘 할 날이 아닌 것도 숨기지 않고 흐리게 「내일」 「3일 뒤」. 할 날이면 「마지막 7일 전」
  - 시간대(아침 · 낮 · 저녁) 묶음은 빼고 알림 시각 순으로. 오늘 할 것 먼저
  - 마지막에 「추가」 버튼. 위 오른쪽 「편집」을 누르면 버튼을 눌러 편집(길게 눌러도 편집)
  - 루틴이 하나도 없으면 추천 아홉 개가 버튼으로 다 보이고, 누르면 바로 추가된다
- 루틴 추가 화면: 추천을 칩 대신 아이콘 버튼 모음으로 다 보이고, 누르면 바로 추가(이미 있는 것은 체크 표시). 아래 「직접 추가」 칸.
  이름을 적지 않았으면 아래 단추가 「완료」(닫기), 적었으면 「추가」
- 아이콘은 이름으로 고른다(목욕 → 물방울, 젖병 → 젖병 …). 모르는 이름은 별, 타이머 루틴은 시계
- 문구
  - 종류: 「체크」 「시간 재기」 → 「체크」 「타이머」. 설명 「누르면 완료로 바뀌고, 완료한 시각이 기록돼요」 / 「타이머나 +5분 단추로 오늘 한 시간이 기록돼요」
  - 반복: 「이틀마다 · 사흘마다 · 일주일마다」 → 「2일마다 · 3일마다 · 매주」
  - 알림 시각 칸 「다른 시각: 20:30」 → 「직접 입력 (예: 20:30)」, 「하루 목표 (안 정해도 돼요)」 → 「하루 목표 (선택)」
  - 루틴 알림 글: 「저녁 루틴이에요」 → 「저녁에 챙길 루틴이에요」, 「지난번에 한 지 7일 됐어요」 → 「마지막으로 한 지 7일 지났어요」,
    「오늘 15분 했어요」 → 「오늘 지금까지 15분」. 단추 「했어요」 → 「완료」
  - 반복 할 일 알림 「7일 만이에요」 → 「마지막으로 한 지 7일 지났어요」, 목록 「손톱 깎기(7일 만)」 → 「손톱 깎기(마지막 7일 전)」
  - 접종 · 검진 단추 「했어요」 → 「완료」, 끝난 줄 「했어요」 「확인했어요」 → 「완료」 「확인 완료」, 확인 시트 제목 「했나요?」 → 「완료 표시」
  - 장보기 「주문했어요」 → 「주문 완료」, 배송 알림 단추 「받았어요」 → 「수령 완료」
  - 가족 공유 설명 「08:10 아빠 했어요처럼 보여요」 → 「누가 언제 했는지 가족 폰에 보여요」
  - 함께 고친 것: 가족 화면 「가족 안에서 부를 이름」 → 「가족에게 보일 이름」, 「맞추기 · 맞추는 중 · 마지막으로 맞춘 때」 → 「동기화」,
    「초대 코드로 들어가기」 → 「초대 코드로 참여」, 「서버에 닿지 못했어요」 → 「서버에 연결하지 못했어요」
  - 기록 알림 「배고플 때가 됐을 수 있어요」 「한번 살펴볼 때가 됐을 수 있어요」 「졸려할 때가 됐을 수 있어요」(1순위 금지 「때가 된」) →
    「수유할 시간인지 확인해 보세요」 「기저귀를 확인해 보세요」 「졸려하는지 살펴보세요」, 「요 며칠 기록이 비었어요」 → 「최근 며칠 기록이 없어요」
  - 기록 화면 「끝」 「깼어요」 「재는 중」 → 「종료」 「수면 종료」 「기록 중」, 첫 화면 「나머지는 대화하면서 채울게요」(옛 AI 상담) → 「아기 생일만 입력하면 시작할 수 있어요」
  - 「안 적어도 돼요」 「안 정해도 돼요」 → 「(선택)」, 「적어 주세요」 → 「입력해 주세요」

  - 비타민D 누르기 → 아이콘이 먹색으로 바뀌고 코랄 체크, 「15:07 완료」. 터미타임 「+5분」 → 「오늘 17분」(타이머는 켜지지 않음), 버튼 누르기 → 타이머 「0:04」
