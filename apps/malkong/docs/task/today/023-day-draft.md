## 목표

물어보기를 열어도 흐름이 가려지지 않고, 바꿀 것과 초안이 흐름에 먼저 보인다. 「오늘 하루 기록 초안으로 작성해 줘」라고 하면 하루 초안을 만들어 고치고 한 번에 저장한다.

## 정한 것

- 창 높이는 56%(`ask-sheet.tsx`). 단계 줄(`Steps`)은 점과 선으로 잇는다. 창이 열려 있는 동안 위쪽 기록 칸(모유 · 분유 · 기저귀 · 잠 단추)은 접는다(`index.tsx`) — 접지 않으면 흐름이 100px 만 보였다
- 초안과 변경 미리보기는 화면 상태(`index.tsx` `drafts` · `previews`)에 두고 물어보기 창과 하루 보기가 같이 본다. 초안은 보는 날(`ymd`)에 묶이고, 창을 닫아도 그대로 있다
- 하루 초안의 셈은 `src/data/day-draft.ts`(순수 함수) — `usualTimes`(평소 시각), `dayDrafts`(말한 것 + 채우기), `editDraft`(작은 창), `negatedDrafts`(「안 잤어」 규칙), `applyChangeToDrafts`(에이전트 답), `draftContext`(기록 뒤에 이어 보내기)
- 초안은 `draftFlow` 로 기록 · 루틴 완료 · 메모 모양이 되어 `dayFlow` 에 끼워진다 — 자리 계산(flow-layout)은 그대로 쓴다. id 는 `draft-N`, key 는 `draft-N` · `routine-draft-N` · `memo-draft-N`
- 노드(`flow-graph.tsx`): `draft`(흰 바탕에 그 기록 색 점선), `badge`(「초안」 코랄 · 「삭제」 경고색), `subFrom`(「~~13:50~~ 13:40」), `strike`. 목록 줄도 점선과 「초안」
- 초안 고치기 창 `draft-popover.tsx` — 노드 위(위가 모자라면 아래)에 뜨고, 시각 5분 · 양 10ml · 시간 5분, 「초안에서 빼기」 · 「확인」. 오늘이면 지금보다 뒤로 옮기지 못한다. 목록 보기에서는 위쪽 가운데
- 「오늘 하루 기록 초안으로 작성해 줘」: `asksDraft` → 나머지 문장(`stripDraftAsk`)을 규칙으로 읽고, 못 읽으면 문장만 에이전트에게 보낸다(기록은 보내지 않음). 그다음 `dayDrafts` 로 채운다 — 모델은 많아야 한 번 부른다
- 초안이 열린 동안: 「~ 안 잤어」는 `negatedDrafts` 규칙이 먼저 읽고, 못 정하면 에이전트에게(초안을 그날 기록 뒤 번호로 보낸다). 기록하는 말은 저장하지 않고 초안에 넣는다. 질문은 그대로 답한다
- 서버는 바꾸지 않는다 — 초안도 기록처럼 보내 지금 계약(update · delete)으로 고친다
