# 020 터미타임 — 시작과 끝, 하루에 여러 번

> 상태: 구현 완료 (2026-11-09) · 폰 확인은 빌드 13 에서

> 시안: https://claude.ai/artifact/4CMt2A8pGPqV1xhaAg3H8x 「빌드 12 피드백 5판 시안 (2026-11-09)」 · 결정: [039](../../decisions/039-ask-chat-and-feedback-5.md)

## 목표

터미타임을 한 번 더 할 수 없던 것(빌드 12 피드백 7번)을 고치고, 시작과 끝을 적게 한다.

## 정한 것

- 루틴에 `timed`(시간을 재는 루틴) 표시를 둔다. 추천의 터미타임과 이름이 「터미타임」인 루틴은 timed 로 본다
- 루틴 완료 줄(routineLog)에 `endAt` 을 더한다. 가족 맞추기는 줄 내용을 그대로 실어 나르므로 서버를 고치지 않는다
- 「지금 시작」은 루틴의 `runningSince` 를 쓴다. 재는 중이면 지금 묶음에 「터미타임」과 시계, 「종료」
- 흐름은 그날 timed 루틴의 완료 줄을 모두 노드로 보인다(다른 루틴은 첫 줄 하나)

## 완료 조건

- [x] (SPEC-MAIN-02) 터미타임 시트 — 지금 시작, 지난 것의 시작과 끝, 「오늘 2번, 25분」
- [x] (SPEC-MAIN-08) 흐름에 「터미타임 10분」 「08:30~08:40」, 한 뒤에도 「한 번 더」

## 확인

- 시간을 재는 루틴은 이름으로 가른다(`isTimed` — 「터미타임」). 따로 표시를 저장하지 않는다
- 루틴 완료 줄에 `endAt`(폰 DB `routine_log.end_at` 열을 더함, 가족 맞추기는 줄 내용을 그대로 싣는다 — 받는 쪽도 endAt 을 읽게 고침)
- 「지금 시작」은 이 폰 설정 `routine.timers` 에 시작한 때만 두고, 「종료」 때 시작부터 지금까지를 완료 한 줄로. 재는 중이면 예정 노드가 코랄 「14:05부터 재는 중」
- 웹: 「터미타임 한 번 더」를 눌러 저장 → 지금 묶음에 「터미타임 15분」 「14:05~14:20」 「+2시간 50분」, 예정 노드 「한 번 더」가 남음
