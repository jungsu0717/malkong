## 정한 것

- 위쪽 칸은 두 줄: 윗줄 기록 11가지(처음부터 모두, 끝에 「편집」), 아랫줄 「루틴」 알약 칸(누르면 완료, 길게 누르면 편집, 끝에 「추가」)
- 기록 칸 너비는 글자에 맞춘다(최소 64) — 이름이 잘리지 않는다
- 기록 편집: 「기록」, 「숨긴 기록」, 「루틴」, 「숨긴 루틴」, 「루틴 추가」. 기록과 루틴은 각자 끌어서 순서. 루틴 줄 「추가」로 열면 「루틴 추가」까지 내려 준다
- 목욕, 터미타임, 놀이, 병원, 투약, 기타는 처음부터 만들지 않고 「루틴 추가」에만 둔다
- 화면 문구에서 「단추」를 뺐다(「기록 편집」, 「루틴 이름」, 「누를 때만 기록해요」)
- 아이콘 19개를 새로 그렸다(`record-icons.tsx`). 색은 수유, 유축, 먹는 것, 마시는 것, 기저귀, 잠, 체온, 루틴으로 묶었다. 테마에 `meal*`, `drink*`, `accentLine` 을 더했다
- 흐름 노드, 기록 목록, 루틴 아이콘(목욕, 터미타임, 손톱, 비타민, 이유식, 간식, 병원, 투약, 기타)도 새 아이콘
- 설정값 `record.bar` v 2 — 12판에서 저장한 설정은 처음 넷이 아닌 기록 종류를 다시 보이게 읽는다
