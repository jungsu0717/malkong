# 009 홈 머리의 버디 — 루틴을 다 끝내면 뛰어오르기

> 상태: 완료 (2026-10-29)
> 근거: SPEC-MAIN-08 · decisions/035

## 목표

홈 먹색 머리 오른쪽에 버디 얼굴을 두고, 오늘 할 루틴을 마지막 하나까지 완료한 순간 한 번 뛰어오르게 한다. 버디를 누르면 한 번 뛴다.
Finch(새가 자라는 자기관리 앱)처럼 캐릭터가 반응하되, 못 한 날을 탓하는 것(스트릭 · 시든 모습)은 두지 않는다.

## 정한 것

- 그림은 `BuddyMark`(얼굴) 56pt — 성장 탭의 움직이는 버디와 다른 그림이라 홈이 무거워지지 않는다
- 움직임은 Reanimated 로 0.6초 — 위로 14pt 튀었다가 내려오고 작게 한 번 더(`withSequence`), 그때 살짝 커진다. 처음 열 때 이미 다 끝낸 상태면 뛰지 않는다(바뀌는 순간에만)
- 말풍선 · 「잘했어요」 같은 문구는 두지 않는다 — 루틴 칸이 이미 모두 완료로 보인다(같은 것을 두 번 그리지 않는다)
- 누르면 가벼운 진동과 한 번 뛰기. 접근성 이름 「버디」
