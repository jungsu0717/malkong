## 목표

물어보기 창이 지금 보는 화면을 알고 답하고, 이미 적은 기록까지 고친다. 처음 한 번 동의를 받고, 고치기와 지우기는 변경 카드를 눌러야 반영한다.

## 정한 것

- 동의는 이 폰의 설정 `ask.records`(`yes` · `no`). 처음 창을 열면 동의 화면, 마이에 「물어보기에서 기록 함께 읽기」 스위치
- 보내는 기록은 보는 날 하루치(`src/data/agent.ts` `dayContext`) — 그날 시작한 기록, 전날 밤에 잠들어 그날 깬 잠, 그날 완료한 루틴(단계 · 건너뛰기 줄 빼고), 사람이 쓴 메모. r1 부터 번호를 붙여 보내고, 서버 답의 번호를 흐름의 key 로 되돌린다
- 선택은 창이 열려 있고 함께 읽기로 했을 때만. 완료한 할 일 노드는 고칠 수 없어서 선택하지 않는다
- 규칙이 먼저: 건강 → 이어 묻기 · 찾기 → 기록 하나. 「이거」, 「옮겨 줘」 같은 말(`pointsOrEdits`)은 규칙을 건너뛰고 에이전트에게
- 변경 반영: 기록은 고친 칸만 바꾸고 원래 값을 기억해 되돌린다. 지운 기록은 같은 내용으로 다시 넣어 되돌린다(새 id). 루틴 완료 시각을 옮기면 끝도 함께 옮긴다(`moveLog` 가 이제 끝을 지키고 새 줄 id 를 돌려준다)
- 앱의 `/v1/parse` 호출은 `/v1/agent` 로 바꾼다. 빌드 13 을 위해 서버의 `/v1/parse` 는 남긴다
