## 정한 것

- 루틴 탭 위쪽은 먹색 머리: 날짜 · 제목 · 보기 전환, 코랄 진행 고리(「2/5」), 「3개 남았어요」, 「다음 · 목욕 오후 8:00」,
  큰 흰 단추 하나(다음 루틴 — 단계가 있으면 「목욕 시작하기」(단계 시트), 타이머면 「터미타임 타이머 시작」, 재고 확인이면 「재고 확인하기」,
  그 밖에는 「비타민D 완료」). 다 했으면 「오늘 루틴을 모두 완료했어요」와 단추 없음
- 완료한 버튼은 연한 코랄 바탕에 코랄 체크 동그라미, 「08:10 완료」는 코랄 글씨
- 광고 배너는 그대로 루틴 탭 맨 아래(시안에서 그리지 않았을 뿐)
- 루틴 추가: 추천 버튼을 다시 누르면 빠지고 「목욕을 뺐어요 · 되돌리기」가 잠깐 뜬다. 뺀 루틴을 다시 추가하면 지난 기록이 이어진다(숨긴 것을 되살린다).
  아래 두 줄 「직접 만들기 ›」 「시기별 추천 전체 보기 ›」, 바닥 「완료」
- 직접 만들기 · 편집은 새 화면(목록형): 취소 / 「새 루틴」(편집이면 「루틴 편집」), 이름, 종류 세 칸 선택 단추, 「반복 · 매일 ›」(반복 고르기 창),
  「알림」 스위치와 시각(폰의 시각 바퀴 — iOS 는 바로 아래 펼침, 안드로이드는 시계 창), 타이머면 「하루 목표 − 15분 +」, 「단계 · 없음 ›」 / 「확인할 물건 · 5개 ›」,
  바닥 「추가」 / 「저장」. 편집이면 「오늘은 건너뛰기」 「삭제」
- 반복 고르기 창: 매일 · 2일마다 · 3일마다 · 요일 지정(동그라미 일곱) · 며칠마다(− 7일마다 +)
- 웹 미리보기에는 시각 바퀴가 없어 브라우저의 시각 칸으로 대신한다
