# 011 홈 칸 나누기 — 오늘 할 루틴을 맨 위 가로 한 줄로, 칸마다 흰 카드

> 상태: 완료 (2026-10-29) · 폰 확인은 다음 TestFlight 빌드
> 근거: SPEC-MAIN-08 · 시안 https://claude.ai/artifact/4CMt2A8pGPqV1xhaAg3H8x 「홈 시안」(2026-10-29, Julian 「ㅇㅇ」)

## 목표

TestFlight 1.0.0 (7)을 써 본 Julian 의 말:
「홈 화면에 오늘 할 루틴이 위로 올라가고, 페이지 계속 늘어나는 것보다 가로 스크롤되게 고정 영역 쓰는 게 나을까? 장보기랑 다가오는 일도 영역 구분 제대로,
태어난 지 65일을 함께한 지로, 홈 글자는 지워도 될 것 같은데? 다가오는 일보다는 아기 일정으로」

## 정한 것

- **칸 순서** — 오늘 할 루틴 · 아기 일정 · 장보기
- **오늘 할 루틴은 옆으로 넘기는 한 줄** — 버튼 너비 104 로 고정, 줄은 화면 오른쪽 끝까지 닿아 넷째 버튼이 조금 보인다(넘길 수 있다는 표시).
  루틴이 늘어도 홈 길이가 그대로다. 버튼 순서는 루틴 화면과 같다(누를 때마다 자리가 바뀌지 않게 완료 여부로는 옮기지 않는다)
- **칸 구분** — 머리 아래 바탕을 옅은 회색(`page`)으로, 칸마다 이름 · 「전체 ›」 · 흰 카드(`card`, 선 없음 — `Card tone="raised"`)
- **장보기** — 칸 이름을 붙이고, 「살 것 2개」 대신 살 것 이름 둘까지(「기저귀 2단계, 물티슈 외 1개」), 그 아래 「배송 중 1개」
- **머리** — 제목 「홈」을 빼고(탭 이름과 같다), 「태어난 지」를 「함께한 지」로. 루틴 화면 머리와 위젯도 같은 말. 성장 탭은 아기 나이를 보여 주는 곳이라 「태어난 지」 그대로
- **「다가오는 일」 → 「아기 일정」** — 할 일 탭의 칸 이름과 같다
- 다크 모드는 바탕 `#0E0E11`, 카드 `#16161B`
