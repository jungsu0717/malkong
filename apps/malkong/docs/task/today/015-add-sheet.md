# 015 추가 — 한 줄로 적으면 할 일, 완료, 루틴, 기록

> 상태: 구현 완료 (2026-11-05) · 폰에서 쓰는 느낌은 TestFlight 빌드 11 에서
> 근거: [main](../../menu-spec/main.md) SPEC-MAIN-12 · [헌장 13](../../constitution.md) · [decisions/038](../../decisions/038-wide-core-baby-first.md)

## 목표

바닥 기록 줄의 「추가」에서 한 줄로 적으면, 앱이 규칙으로 읽어 할 일 · 완료 · 루틴 · 기록 중 맞는 카드를 보여 주고 누르면 저장한다.

## 정한 것

- 읽는 셈은 `src/data/add-parse.ts`(node 시험). 날짜 · 시각 · 반복은 지금 할 일 입력이 쓰던 `due-parse.ts` 를 그대로 쓰고, 기록 이름 · 양 · 쪽 · 지난 시각 읽기를 더한다
- 「완료로 기록」은 지금 완료한 할 일(내 할 일 주제)로 남긴다 — 흐름에서 체크 동그라미가 된다. 「오늘 할 일로 추가」는 시각 없는 오늘 할 일
- 반복은 루틴으로(매일 · 요일 · N일마다). 매달은 루틴에 없어서 반복 할 일로
- 시각 있는 내 할 일도 다시 알린다 — 할 일 알림이 아기 일정만 보던 것을 내 할 일까지로
- 모델 호출은 이번에 붙이지 않는다 — 규칙으로 못 읽은 말은 이름만 있는 말로 다룬다. 모델로 읽기는 서버 배포(Julian)와 함께 다음에
