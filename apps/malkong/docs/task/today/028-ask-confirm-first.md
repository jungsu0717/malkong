# 028 물어보기 11판 — 무엇이든 먼저 카드로 되묻기, 시작 화면을 지금 앱으로

## 목표

Julian(2026-11-11, 빌드 17 을 써 보고): 「메인 스플래시 화면도 바뀌어야 할 것 같고」, 「전체 기록 작성해줘 라고 했는데 완료로 기록 오늘할일로 추가 이렇게 떠」,
「되묻고 보기안에서 해결 되면 눌러서 진행하면되고, 원하는게 없으면 마지막 항목에 … 다시 입력할 수 있게」. 시안을 보고 「ㅇㅋ」(슬로건 바꾸기 포함).

## 정한 것

- 물어보기 창의 모든 길이 되묻는 카드(`type: 'offer'`)를 거친다 — 보기마다 `go` 를 들고 있고 누를 때만 실행한다(`src/components/flow/ask-sheet.tsx`)
  - 질문: 찾기, 이어 묻기, 이름 찾기, 깬 시각, 누가, 앞 기록과 비교, 하루 요약, 앱 기능(두 기간 견주기, 수유 간격), 못 읽은 질문의 보기 셋, 모델이 고른 기능과 기록
  - 할 일: 하루 기록 초안, 메모 쓰기 창, 할 일 · 루틴 추가, 완료로 기록, 모자란 기록의 입력 창
  - 기록: 「이렇게 기록할까요?」, 읽은 기록 목록, 「저장」 · 「모두 저장」. 모델이 읽은 새 기록도 같다
- 카드 머리 `offerHead`, 찾기 조건의 한 줄 `queryLabel`, 화면 동작 기능 `isActionCall`(`src/data/agent-tools.ts`). 깬 잠 고르기 `wakeWhich`(`src/data/ask-local.ts`)
- 「직접 입력」 줄(점선 테두리, 연필) — 누르면 그 카드는 닫히고 쓴 말이 입력 칸에 다시 들어간다. 모델을 부르지 않는다
- 「추가」 보기는 +, 「완료로 기록」은 ✓ 아이콘(할 일 이름으로 아이콘을 고르면 별이 나왔다)
- 「전체 기록 작성해줘」, 「오늘 기록 다 채워 줘」를 하루 기록 초안으로 읽는다(`asksDraft`, 커밋 2289f98)
- 시작 화면 카드 셋을 지금 앱으로(`src/components/splash-scene.tsx`) — 기록 한 줄(분유 160ml, 12:30 · 할머니), 물어보기(「마지막 수유 언제였지?」 → 「2시간 전, 160ml」),
  하루 24시간 고리(잠, 수유, 기저귀). 루틴, 할 일, 성장 카드는 뺐다. 버디와 모빌, 별, 움직임은 그대로
- 슬로건 「육아 할 일, 버디가 챙겨요」 → 「아기 하루, 버디가 챙겨요」(`BrandSlogan`). 구글 플레이 그래픽 이미지도 같은 말로 다시 찍었다(`marketing/store/out/feature.png`, 아래 줄은 「수유, 기저귀, 잠 기록을 가족과 함께 봐요」)
- AI 비서 아이콘을 `baby-icons.tsx` 로 옮겼다(시작 화면과 물어보기 단추가 같이 쓴다)

- 웹(2026-11-11, `/v1/agent` 는 가짜 답)
  - 「마지막 수유 언제였지?」 → 「이걸 알려 드릴까요?」, 「마지막 수유 / 언제였는지와 지난 시간」, 「직접 입력」 → 누르니 ✓ 와 「어제 17:20, 분유 120ml예요. 16시간 7분 전이에요.」, 「이 기록 보기」
  - 「기저귀 사기」 → 「어떤 걸 할까요?」, 「오늘 할 일로 추가 / 기저귀 사기, 오늘」, 「완료로 기록 / 기저귀 사기, 지금」 → 「직접 입력」을 누르니 입력 칸에 「기저귀 사기」
  - 「2시에 분유 120 먹고 소변 갈았어」 → 「이렇게 기록할까요?」, 분유 120ml 02:00, 소변 02:00, 「모두 저장」 → 누르기 전에는 저장되지 않고, 누르니 「2개 적었어요」와 흐름의 새 기록 비춤
  - 「전체 기록 작성해줘」 → 「이렇게 할까요?」, 「오늘 하루 기록 초안 / 평소 시각으로 채우고, 고친 뒤 저장해요」 → 누르니 단계 줄 둘과 「초안 1개」
  - 「낮잠 줄었어?」 → 보기 셋, 모델 호출 없음. 「그거 몇 ml였는지 알려 줘」(가리키는 말) → 모델 한 번, 가짜 답의 기능(마지막 분유)도 「이걸 알려 드릴까요?」부터
- 시작 화면: 웹 임시 화면으로 찍어 캔버스에 올렸다(시안 그림 = 지금 코드). 실제 폰에서는 빌드 뒤에 본다
