## 목표

돋보기(기록 찾기)와 「추가」 시트를 오른쪽 아래 「물어보기」 채팅 하나로 합친다. 문장으로 기록하면 바로 저장하고 되돌릴 수 있게, 물으면 답하고 흐름에서 그 기록을 비춘다.

## 정한 것

- 읽는 순서: 묻는 말인지 먼저 본다(?, 몇, 언제, 얼마, 마지막). 묻는 말이면 `find-parse`, 아니면 `add-parse`. 둘 다 못 읽거나 기록이 여럿으로 보이면(「~고」, 「하고」) 서버 `/v1/parse`(task common/031)
- 문장 기록은 바로 저장하고 카드에 「되돌리기」(지움) · 「수정」(그 입력 시트). 할 일 · 루틴 · 이름만 있는 말은 예전 「추가」 시트의 카드를 그대로 쓴다
- 하이라이트는 화면 상태(`highlight: { keys, label }`)로 흐름과 목록에 넘긴다. 창을 닫으면 지운다
- 이어 묻기는 앞 질문의 조건을 기억해 「그 전 수유는?」(앞 기록 하나 더 이전), 「어제는?」(기간만 바꿈)을 처리한다
- 건강 질문은 규칙(열, 발진, 토, 약, 괜찮아)과 모델의 health 로 걸러 고정 한 줄

- 화면 `ask-sheet.tsx`. 예전 `add-sheet.tsx` · `find-sheet.tsx` 는 지웠다. 비춘 기록으로 흐름이 스크롤된다(`onFocus`)
- 흐름에서는 위에 표시를 붙이면 묶음 제목을 가려서 테두리와 코랄 이름으로만 비춘다(목록은 짧은 표시까지) — SPEC-MAIN-13 문장도 맞췄다
