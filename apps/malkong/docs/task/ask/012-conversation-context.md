## 목표

Julian 이 아이폰으로 써 보니(2026-10-11) 둘이 걸렸다.
1. 「태열 예방하려면 얼마나 시원하게?」 뒤에 「몇 개월까지 그렇게 해야 해요?」를 물으니 수유 이야기로 샜다 —
   앱이 서버에 지금 질문 한 줄 · 월령 · 기록만 보내고 **앞 대화를 보내지 않아서**, 모델은 「그렇게」가 뭔지 알 수 없었고
   같이 온 수유 기록에 끌려갔다.
2. 거의 모든 답이 「일반적으로는」으로 시작했다 — 프롬프트와 서버(`GENERAL_PREFIX`)가 근거 없는 답마다 그 말을 넣게 했는데,
   L1 이 77건(대부분 접종 · 검진)이라 일상 질문은 거의 다 근거 없음이고, 화면에 「일반 정보」 배지가 이미 붙어 중복이었다.
   읽는 사람에게는 겸양이 아니라 「확신 없음」으로만 읽혔다.

## 먼저 정한 것

1. **앱이 바로 앞 대화를 보낸다** — 이번 질문 말풍선 앞의 메시지 가운데 24시간 안의 것, 최근 6턴(부모 · 버디 번갈아).
   되묻기 · 응급 안내 말풍선은 버디 턴으로 세고, **브리핑은 뺀다** — 기기가 아기 이름을 넣어 만든 글이라
   「이름은 서버로 보내지 않는다」(ask/011)에 걸린다(웹 확인에서 「말콩이는 오늘…」이 실려 가는 것을 보고 뺐다). 한 턴은 500자에서 자른다. 되묻기에 답한 재요청에서는
   [원래 질문, 되묻기] 가 앞 대화가 된다. 절약 모드에도 보낸다(질문 글과 같은 성격 — 기기 안 기록이 아니다)
2. **서버는 앞 대화를 모델에 「바로 앞 대화」로 넘기고**, 지금 질문으로 L1 이 하나도 안 잡히면 직전 부모 질문으로 한 번 더 찾는다
   (「다음 접종은요?」 → 앞 질문의 백신). 6턴 · 600자에서 자르고, 저장 · 로그에 남기지 않는다(원래 질문과 같은 취급)
3. **「일반적으로는」 강제를 걷는다** — 프롬프트의 지시와 서버의 접두어 붙이기 둘 다. 근거 없음 표시는 화면 배지(「일반 정보」)가
   맡는다. constitution 원칙 1(근거 없는 답을 근거 있는 척하지 않는다)은 배지 · 빈 sources · 지어낸 id 금지로 그대로 지켜진다
4. 개인정보 처리방침(`legal.ts`)의 「보내는 것」에 바로 앞 대화를 더한다
