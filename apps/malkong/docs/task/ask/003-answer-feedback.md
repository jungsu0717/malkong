## 목표

모든 답 아래에 좋아요/별로예요를 두고, 별로예요에는 선택 의견을 받는다. 서버는 기기 키와 떼어 저장한다.

## 먼저 정한 것

1. **서버는 답을 저장하지 않는다** — 그래서 품질을 고치는 데 쓸 정보(수위 · 인용한 L1 id · 절약 모드)를 앱이 함께 보낸다
2. **질문과 답 원문은 동의했을 때만** — 별로예요 칸의 「질문과 답도 함께 보내기」(기본 꺼짐). 개인정보 처리방침에도 적었다
3. **같은 답의 피드백은 마지막 것만** — 서버는 앱 말풍선 id 의 해시로 묶는다
4. 기기당 하루 50건(메모리에서 셈), 1년 보관
5. 저장소는 common/005 와 같은 Neon(없으면 메모리) — `infra/db/feedback_store.py`
