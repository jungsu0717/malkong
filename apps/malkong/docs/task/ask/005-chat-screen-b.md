# 005 대화 화면을 시안 B 로 — 첫 화면다운 말콩

> 상태: 완료 (2026-10-03) — 실기기 확인은 몰아 시험에서
> 근거: SPEC-ASK-01~06·08·10 · [decisions/012](../../decisions/012-chat-first-three-tabs.md) · app-design 「디자인 원칙」

## 목표

대화가 첫 탭이 됐다. 시안 B 처럼 단정하고, 말콩이 "우리 아기를 아는 비서"로 보이게 다시 그린다.
무엇을 보일지(SPEC)는 그대로이고 모양만 바뀐다.

## 먼저 정한 것

1. **질문은 오른쪽 회색 말풍선, 답은 말풍선 없는 본문** — 답 아래 한 줄에 표시(수위 · 기록 참고 · 출처 수),
   그 아래 출처 목록 · 「기록했어요」 줄 · 피드백. 답은 15pt, 줄 간격 넉넉히
2. **기록 참고 표시** — 정밀 답변이 우리 아기 기록을 보냈으면 붉은 말 색 「우리 아기 기록 N건 참고」. 일반 기준 답은
   회색 「일반 기준」. 차별점이 눈에 보이는 자리다(decisions/012)
3. **위험 신호 카드는 모양으로 갈린다** — 채운 경고 머리 + 119 단추. 포인트 색(붉은 말)과 헷갈리지 않게
4. **빠른 질문 칩은 입력창 바로 위** — 입력창이 비었고 기다리는 중이 아닐 때만. 대화가 비었으면 큰 인사와 함께
5. 플로팅 버튼이 없어졌으므로 `q`·`t` 주소 값으로 질문을 받던 길은 지운다. 기록의 「대화 보기」(`focus`)는 남긴다
6. 남은 정밀 답변은 지금처럼 3회 이하일 때만 머리 오른쪽에 작게(ask.md 한도 표시)
