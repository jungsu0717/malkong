# 007 처리 현황을 질문마다 다르게 — 무엇을 보고 답했는지

> 상태: 완료 (2026-10-04) — 웹 확인(가짜 응답, 모델 안 부름)
> 근거: SPEC-ASK-05(2026-10-04 갱신) · constitution 1(근거 없는 답 표시는 답 아래 「일반 정보」 표시가 맡는다)

## 목표

Julian(2026-10-04): 질문할 때마다 처리 현황이 늘 같은 3단계다. Claude · GPT · neuro 는 생각 · 출처 확인 문구가 매번 다르게
찍힌다. 「맞는 표준 지식이 없었어요」가 너무 자주 보여 거부감이 든다.

## 왜 그랬나

1. 서버는 답을 한 번에 돌려준다(스트리밍 없음) — 기다리는 동안 앱이 고정 문구 넷을 돌렸다
2. 끝난 뒤의 단계도 앱이 고정 제목 셋으로 만들었다 — 「3단계 확인했어요」가 늘 같다
3. 표준 지식(L1)이 77건이고 접종 · 위험 신호가 많아, 일상 질문은 대개 출처가 안 붙는다 → 부정 문구가 자주 보였다

## 정한 것 (앱만 — 서버 · 모델 호출 없음)

1. **기다리는 문구를 질문으로 만든다** — 질문의 주제(먹기 · 잠 · 열과 아픔 · 접종 · 검진 · 변 · 피부 · 발달 · 키와 몸무게 · 안전)와
   그 주제에 닿는 우리 아기 기록, 월령으로: 「콩이 먹기 기록 3건을 보고 있어요…」 「3개월 잠 기준을 찾고 있어요…」.
   아픈 이야기면 「바로 병원에 가야 하는 신호인지 먼저 보고 있어요…」(서버가 실제로 위험 신호 규칙을 먼저 본다)
2. **끝난 단계도 실제로 한 것만** — 닿은 기록(문구 그대로 둘까지) · 출처 이름 · 아픈 이야기면 위험 신호 기준 대조 · 수위에 맞는 정리.
   출처가 없으면 그 단계를 빼고 부정 문구를 쓰지 않는다(답 아래 「일반 정보」 표시는 그대로 — constitution 1)
3. **접힌 머리를 한 줄 요약으로** — 「콩이 기록 2건과 출처 1곳을 보고 답했어요」 · 「3개월 기준으로 답했어요」
4. 나중(서버 배포 필요): 서버가 단계를 실시간으로 보내기(SSE), L1 을 일상 주제로 넓혀 출처가 붙는 답 늘리기

## 완료 조건

- [x] tsc · lint · 웹(가짜 응답으로 — 모델 안 부름): 질문마다 다른 대기 문구 · 끝난 요약 · 출처 없을 때 부정 문구 없음
