# task — spec 을 코드로 만드는 단위

폴더는 메뉴 넷 + 횡단 하나: `home/` · `ask/` · `growth/` · `my/` · `common/`(특정 메뉴에 속하지 않는
기반 작업 — L1 지식베이스·서버·배포 등). 여러 메뉴에 걸치되 주 메뉴가 있으면 그 폴더에 두고 본문에 밝힌다.

## 규칙

- 파일명: `NNN-<주제>.md` — 번호는 메뉴 폴더 안에서 이어진다
- task 는 **근거 SPEC 없이 만들지 않는다.** 근거가 없으면 menu-spec 에 SPEC 을 먼저 쓴다(모호하면 묻는다)
- 완료 조건은 근거 SPEC 의 문장과 1:1 로 대응시킨다 — 조건을 코드에 맞춰 몰래 완화하지 않는다
- 끝나면 상태를 갱신하고 `npx tsc --noEmit` + `npx expo lint` 통과를 확인란에 남긴다
- 완료된 task 는 지우지 않는다 — 이력이다

## 양식

```markdown
# NNN 제목

> 상태: 대기 | 진행 | 완료 (날짜)
> 근거: SPEC-XXX-NN, SPEC-XXX-NN

## 목표
한두 문장.

## 단계
1. ...
2. ...

## 완료 조건
- [ ] (SPEC-XXX-NN) ...조건 그대로...
- [ ] tsc · lint 통과
```
