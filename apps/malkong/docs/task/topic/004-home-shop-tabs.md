## 정한 것

- 탭: 홈(`(tabs)/index.tsx`) · 할 일(`todo.tsx`) · 장보기(`shop.tsx`) · 기록(`log.tsx`) · 마이. 알림을 누르면 홈으로
- 홈: 아기 이름과 태어난 지 며칠, 행성 그림(높이 300), 아래 네 줄 — 오늘(제목 세 개까지) · 장보기(배송 중이 있으면 그것, 없으면 살 것) ·
  다가오는 날(접종 · 검진, 50일 · 100일 · 돌, 사이즈 확인 중 가까운 둘, D-day) · 루틴(반복 할 일과 지난번 완료한 날). 그림 위 숫자를 줄에서 다시 쓰지 않는다
- 할 일 탭: 그림을 빼고 오늘 · 예정 · 날짜 없음 · 반복 추천 · 주제 그리드. 장보기 주제는 그리드에서 뺀다(탭이 따로 있으니까)
- 장보기: 할 일과 같은 `todo` 줄로, 장보기 주제(kind shopping)에 둔다. 칸 셋을 더한다 — `ordered_at`(주문한 때) · `arrive_at`(도착 예정일) · `store`(어디서)
  - 살 것: 동그라미를 누르면 바로 완료(매장에서 샀을 때), 「주문했어요」를 누르면 어디서 · 언제 도착을 적는 시트
  - 배송 중: 「쿠팡 · 내일 도착 예정」처럼. 동그라미를 누르면 받음(완료). 「…」로 주문 정보 편집 · 주문 취소 · 삭제
  - 다시 담기: 지난번 산 것 중 지금 목록에 없는 것(최근 순 열 개)을 한 번 눌러 살 것으로
  - 완료: 접어 둔다
  - 어디서는 사용자가 적은 이름만 칩으로 다시 보인다 — 앱이 쇼핑몰 이름을 미리 넣지 않는다
- 신청 · 서류: 규칙을 지우고 주제를 예전 기본 주제로 돌려 숨긴다. 이미 생긴 할 일은 「내 할 일」로
- 장보기 주제는 topic/003 에서 예전 기본 주제로 숨겼다 — 한 번만 숨김을 푼다(설정값 `shop_tab_ready`)
- 메뉴 코드: 홈은 `MAIN`(예전 `HOME` 은 보관이라 다시 쓰지 않는다), 장보기는 `SHOP`
