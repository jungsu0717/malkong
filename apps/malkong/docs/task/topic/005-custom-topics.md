## 목표

Julian(2026-10-15): 「주제로 묶어서 커스텀 todo 만들 수도 있으면 좋겠어」, 「공공에서 처리 안 해 주는 어린이집 준비나 여행 짐 이런 것도 좋다」.
이 task 가 끝나면 할 일 탭 그리드의 「주제 추가」에서 추천 주제를 한 번 눌러 할 일이 채워진 목록을 만들거나, 이름과 아이콘을 골라 직접 만들고,
외출 가방처럼 다시 쓰는 목록은 「모두 체크 해제」로 처음 상태로 돌린다.

## 정한 것

- 주제에 아이콘 칸(`topic.icon`)을 더한다. 직접 만드는 주제는 아이콘 여덟 개 중에서 고른다(기본 폴더)
- 추천 주제 셋 — 누르면 그 이름 · 아이콘으로 주제를 만들고 할 일을 날짜 없이 바로 채운다(사용자가 지우면 된다). 한 번 만들어 두고 고치지 않는다(헌장 8),
  약 · 처치는 넣지 않는다(헌장 5). 이미 같은 이름의 주제가 있으면 추천에서 뺀다
  - 어린이집 준비: 입소 대기 신청 · 상담 날짜 잡기 · 이름 스티커 주문 · 낮잠 이불 · 여벌 옷과 양말 · 기저귀와 물티슈 · 개인 컵과 수저 · 가방
  - 여행 짐: 기저귀와 물티슈 · 여벌 옷 · 분유 · 젖병 · 보온병 · 젖병 세정제와 솔 · 아기수첩 · 휴대용 유모차 · 아기띠 · 쪽쪽이 · 작은 장난감 · 겉싸개나 담요 · 기저귀 담을 비닐봉지
  - 외출 가방: 기저귀와 물티슈 · 여벌 옷 · 분유 · 젖병 · 보온병 · 손수건과 턱받이 · 쪽쪽이 · 작은 장난감 · 겉싸개나 담요 · 기저귀 담을 비닐봉지
- 모두 체크 해제: 직접 만든 주제에서 완료한 할 일(반복 없는 것)을 모두 되돌린다. 사용자가 누른 것이라 완료 기록이 지워져도 헌장 2 와 맞다
- 할 일 탭 입력칸: 직접 만든 주제가 있으면 칸을 누를 때 「내 할 일」과 그 주제들을 칩으로 고를 수 있다. 다른 주제에 넣으면 「어린이집 준비에 추가했어요」를 잠깐
- 직접 만든 주제는 숨길 수 있다(지우지 않는다)

## 확인

- 품질 검사: `npx tsc --noEmit` 0 · `npx expo lint` 0 · `npx expo export --platform web` 성공
- 웹(390px, Playwright):
  - 주제 추가 시트: 추천 주제 셋(어린이집 준비 · 여행 짐 · 외출 가방, 앞의 셋과 「외 N개」), 직접 만들기 이름 칸과 아이콘 여덟
  - 여행 짐 추가 → 할 일 열하나가 채워진 주제 화면으로, 아이콘 비행기. 아기띠 · 쪽쪽이 체크 → 완료 2개 아래 「모두 체크 해제」 → 완료 0개
  - 「이사 준비」 · 집 아이콘으로 직접 만들기 → 그리드에 집 아이콘. 입력칸을 누르면 칩 「내 할 일 · 여행 짐 · 이사 준비」,
    이사 준비를 골라 「전입신고」 → 이사 준비에 날짜 없이, 「이사 준비에 추가했어요」
  - 찾은 것과 고친 것: 웹에서 칩을 누르는 순간 입력칸이 포커스를 잃어 칩이 사라져 누른 것이 무시됐다 — 접는 것을 조금 늦추고, 적는 중 · 주제를 고른 동안에는 칩을 둔다
- 운영 서버 `/v1/entitlements` 가 웹 시험 기기 키로 503 을 돌려준다(키 없이 부르면 401, `/health` 200). 이 task 와 관계없고, 할 일 · 장보기는 서버를 쓰지 않는다
