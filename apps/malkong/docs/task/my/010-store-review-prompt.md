## 목표

Julian(2026-10-22): 「특정 행동이나 기능을 쓰다 보면 스토어 리뷰를 유도하는 팝업을 띄우자. 리뷰가 소중해.」
기분 좋은 순간에 폰의 기본 별점 창을 띄워, 앱을 떠나지 않고 별점을 남기게 한다.

## 정한 것 (권장안)

- **기본 별점 창만** — `expo-store-review` 의 `requestReview()`. 앱이 만든 「마음에 드세요?」 팝업은 두지 않는다.
  App Store 심사 지침 5.6.1 은 주어진 API 만 쓰게 하고, Google Play 리뷰 지침은 창 앞뒤로 의견을 묻는 질문을 막는다(2026-10-22 확인)
- **좋은 순간** — 그날 루틴을 모두 완료한 순간(루틴 탭, 둘 이상일 때), 할 일 · 살 것 완료, 발달 체크 「했어요」
- **때** — 처음 연 지 3일 뒤, 좋은 순간 5번, 한 번 띄우면 120일 쉼. 실제로 보일지는 운영체제가 한 번 더 정한다(아이폰 1년 3번)
- 앱이 뒤에 있을 때(알림 단추로 완료), 개발 빌드 · Expo Go(Expo Go 의 별점 창이 뜨므로) · 웹에서는 띄우지 않는다
- 화면이 새로 생기지 않아 시안은 두지 않았다(운영체제 창)

## 구현
