# 011 첫 실행 — 생일 하나로 1년 치 챙길 일이 채워지는 화면

> 상태: 완료 (2026-10-29)
> 근거: SPEC-MY-10 · SPEC-MY-01 · decisions/035

## 목표

생일을 넣는 순간 앱이 무엇을 해 주는지 눈으로 보여 준다 — 「앞으로 1년, 챙길 일 23개를 채웠어요」와 가까운 일정 일곱 줄이 차례로 나타난다.
스토어 첫 장과 같은 약속: 「생일만 넣으세요. 1년 치 챙길 일은 버디가 채워요」.

## 정한 것

- 온보딩의 단계가 생일 → **1년** → 알림 시각이 된다. 프로필 수정과 초대 코드 참여에는 없다
- 수는 오늘부터 1년 안의 접종 · 검진 묶음(지금 기간인 것 포함)과 기념일 · 사이즈 확인 규칙(`AUTO_RULES`)의 합. 셈은 `src/data/first-year.ts`(순수, 시험)
- 줄은 날짜(「11월 12일」, 지금 기간이면 「이번 달」) · 이름 · 분류 칩(접종 · 검진 · 기념일 · 사이즈). 일곱 줄 뒤에 「외 16개」
- 줄은 0.1초 간격으로 아래에서 떠오른다(Reanimated `FadeInDown`). 다 뜨는 데 1초가 안 걸린다
- 채울 것이 셋보다 적으면(생후 23개월처럼) 건너뛴다
- 문구: 제목 「앞으로 1년,\n챙길 일 23개를 채웠어요」, 설명 한 줄 「생일 하나로 접종 · 검진 · 기념일 · 사이즈 확인 날짜를 잡았어요」, 단추 「다음」
