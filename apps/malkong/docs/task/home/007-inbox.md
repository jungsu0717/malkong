# 007 알림함 — 브리핑이 온 것 · 앱 알림, 새 것 배지

> 상태: 완료 (2026-10-04) — 웹 확인
> 근거: SPEC-HOME-07 · [decisions/017](../../decisions/017-schedule-tab-and-inbox.md)

## 목표

브리핑함을 없애지 않고 알림함으로 넓힌다(Julian). 새 브리핑이 왔다는 배지와 요약, 앱 알림(기록 요청), 나중에 가족 공유 신청.

## 정한 것

1. 저장 — 기기 `inbox_card`(backend 스키마) · 웹은 localStorage. 줄: id · kind(daily · weekly · monthly · nudge) · 제목 · 요약 · 날짜 · 읽은 때
2. 화면 `/inbox`(예전 `/briefings`) — 「브리핑」 · 「알림」 두 칸, 줄마다 요약과 새 것 점, 맨 아래 배너
3. 누르면 읽음 + 그리로 — 브리핑은 일정 탭의 그날, 기록 요청은 그 카드. 대화의 「확인하러 가기」, 일정 탭에서 그날을 보는 것도 읽음
4. 배지 = 읽지 않은 줄의 수(대화 화면 오른쪽 위)

## 완료 조건

- [x] tsc · lint · 웹 확인

## 확인한 것 (웹 390px)

- 처음 연 날 대화 오른쪽 위 알림함 배지 1 → 알림함 「브리핑 1」, 「오늘의 브리핑이 도착했어요 · 챙길 것 3개 · BCG · B형간염 1차 외」
- 줄을 누르면 일정 탭 오늘로, 돌아오면 배지 0
- 카드를 끄고 사흘 지난 상태: 카드는 안 뜨고 「알림」에 기록 요청 한 줄(여러 번 열어도 한 줄) → 누르면 카드가 열림
