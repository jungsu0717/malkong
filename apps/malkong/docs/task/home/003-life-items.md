# 003 「챙길 것」 생활 항목과 접종·검진만 보기

> 상태: 완료 (2026-10-03) — 화면 시험은 첫 출시판 개발을 마친 뒤 몰아서
> 근거: SPEC-HOME-02(생활 항목 · 분량 · 묶음 · 기간 · 완료 알림)

## 목표

접종·검진만 나오던 「챙길 것」에 터미타임·이유식 시작·안전한 잠자리 같은 생활 항목을 넣고, 마이 설정에서
"접종·검진만 보기"로 줄일 수 있게 한다.

## 먼저 정한 것

1. **무엇이 생활 항목인가** — L1 분류 생활·수유·수면·안전. 발달은 「이번 달 발달 포인트」, 대응(위험 신호)은
   물어보기의 몫이라 넣지 않는다
2. **언제 오르는가** — 기간 안(시작 월 ≤ 지금 ≤ 끝 월)이거나 다음 달에 시작할 때. 마감이 있는 일정이 아니라서
   **놓침으로 묻지 않는다**(SPEC-HOME-02 기간)
3. **이름과 단추** — 같은 달·같은 분류는 한 줄로 묶고(SPEC-HOME-02 묶음) 「안전한 잠 5가지」처럼 부른다. 해낸 일이
   아니라 알아 둔 것이라 단추와 기록은 「완료」 대신 「확인」
4. **순서** — 놓침 → 지금 → 다음 달, 같은 상태면 접종·검진이 먼저. 세 줄까지 보이고 나머지는 접힌다(SPEC-HOME-02 분량)

## 완료 조건

- [x] (SPEC-HOME-02 생활 항목) 접종·검진 외 생활 항목도 추천에 포함되고, 설정에서 "접종·검진만 보기"로 줄일 수 있다
- [x] (SPEC-HOME-02 기간) 생활 항목은 기간 안에 놓침으로 보지 않는다
- [x] (SPEC-HOME-02 묶음 · 완료 알림) 생활 항목 줄도 묶이고, 눌러서 항목마다 골라 알릴 수 있으며, 되돌릴 수 있다
- [x] tsc · lint 통과
