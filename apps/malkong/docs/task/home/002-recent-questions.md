# 002 최근 질문 이어보기

> 상태: 완료 (2026-10-03) — 화면 시험은 첫 출시판 개발을 마친 뒤 몰아서
> 근거: SPEC-HOME-04 · SPEC-HOME-03(성장 타임라인으로 가는 길)

## 목표

홈의 「말콩이에게 물어본 것」 카드가 예시 문장 대신 실제로 저장된 최근 질문 1~2개를 보여주고, 누르면
물어보기 타임라인의 그 질문 자리로 스크롤해 이어지게 한다.

## 단계

1. 홈 카드 — 대화(`useChat`)에서 되묻기 답이 아닌 질문만 골라 최근 2개. 없으면 처음 물어보라는 안내
2. 누르면 `/ask?focus=<질문 id>&ft=<누른 시각>` — 물어보기 화면은 그 말풍선 위치로 스크롤하고,
   그동안은 새 답이 와도 맨 끝으로 끌어내리지 않는다(새로 보내면 다시 끝을 따라간다)
3. 「이어서 물어보기 →」는 물어보기 탭으로, 「성장 타임라인에서 전체 흐름 보기 →」는 성장 탭으로 실제로 이동

## 완료 조건

- [x] (SPEC-HOME-03) 발달 포인트 카드에서 성장 타임라인으로 갈 수 있다
