# 026 페르소나 시험에서 나온 버그와 작은 불편 고치기

> 상태: 완료 (2026-10-23)
> 근거: SPEC-TOPIC-02 · 11, SPEC-SHOP-01 · 03, SPEC-MY-01 · 05, 루트 AGENTS 「화면 문구는 최소로」

## 목표

Julian(2026-10-23): 엄마 · 아빠 × 신생아 · 6개월 이후 페르소나로 써 본 결과를 「모두 고쳐 줘」. 이 task 는 그중 할 일 · 장보기 · 아기 일정 · 가족 쪽이다
(공공 지식 보강 · 월령별 추천 · 성장 탭은 다른 task).

## 고친 것

1. **생일이 바뀌면 앱 할 일을 새 생일로** — 프로필 수정이나 가족 참여로 생일이 바뀌면 안 끝낸 앱 할 일(기념일 · 사이즈)을 다시 맞춘다.
   지금 보일 때면 기한만 고치고, 아직 때가 아니거나 한참 지났으면 지운다(때가 되면 다시 생긴다). 끝낸 것 · 직접 적은 것은 그대로.
   생일이 바뀔 때만 맞춘다(마지막으로 맞춘 생일을 설정에 둔다) — 사용자가 고친 기한을 덮지 않게. `reconcileAuto`(auto-todos.ts), 시험 1건
2. **온라인 쇼핑몰은 온라인 묶음으로** — 「쿠팡에서 물티슈」가 매장으로 묶여 「주문 완료 → 배송 중」이 없던 것. 잘 알려진 쇼핑몰 이름은 온라인으로 묶고
   줄 아래에 쇼핑몰 이름을 작게, 주문 시트는 그 이름으로 시작한다. 장보기 묶음 계산을 db 없는 순수 파일 `shop-lists.ts` 로 옮겨 시험 3건
3. **방금 산 물건이 두 군데에** — 오늘 산 것은 「다시 담기」에서 뺀다
4. **지난달 「지남」이 「이번 달」에** — 「이번 달」 위 「지난 일정」으로. 놓친 접종 · 검진은 그 아래 「지난 접종 · 검진 N개 보기」로 접는다
5. **초대받은 가족이 생일부터 입력** — 온보딩에 「초대 코드가 있어요」. 가족 화면이 참여 칸을 열고, 참여해 가족의 아기가 들어오면 첫 화면으로.
   아기가 없어도 가족 화면에 머물 수 있게 첫 화면 문지기를 고쳤다. 만들기 · 참여 전에 「가족에게 보일 이름」을 고른다 — 처음 완료부터 이름이 남게.
   초대 코드 보내기 문구에도 「초대 코드가 있어요」 길을 적었다
6. **뻔한 안내 문장 빼기** — 「추가한 할 일은 할 일 탭 「날짜 없음」에 있어요」, 「완료한 항목만 골라 주세요. 날짜는 입력하지 않아도 돼요」,
   「도착 날짜를 모르면 비워 두세요」(옆에 「모름」 칩). 루틴 만들기의 종류 설명은 무엇을 하는지 알려 주는 글이라 남겼다
