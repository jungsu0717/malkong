## 정한 것

- 메모는 할 일 · 루틴과 같은 길(`/v1/family/sync` 의 items, kind `memo`)로 간다. 서버는 내용을 읽지 않는다
- 옛 서버는 모르는 kind 가 섞이면 요청 전체를 422 로 거절한다. 그래서 서버가 응답에 받는 종류(`itemKinds`)를 싣고,
  앱은 거기에 `memo` 가 있을 때만 메모를 올린다. 배포 전 서버에도 지금 앱이 그대로 맞춰진다
- 발달 체크 메모는 id 를 항목으로 정한다(`mm-<L1 id>`) — 두 폰에서 같은 것을 눌러도 한 줄이고, 지우면 함께 지워진다
- 가족 화면 동의 문구와 개인정보 처리방침(기기 안 · 가족 공유 항목, 민감정보 설명)에 메모를 더했다. 약관 「하는 일」에 발달 정보와 메모
