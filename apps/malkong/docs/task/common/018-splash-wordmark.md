# 018 시작 화면 — 노랑 바탕, 이름과 슬로건이 한 박자 떠오른다

> 상태: 완료 (2026-10-08) — 폰에서 한 박자 확인은 Julian
> 근거: [app-design](../../app-design/README.md) 「시작 화면」(이 task 에서 정의를 고친다) · [decisions/015](../../decisions/015-character-buddy.md)
> 「색」(아이콘 · 시작 화면 바탕은 우주복 노랑) · [product-brief](../../product/product-brief.md) 슬로건(2026-10-01 확정)
> 횡단(common): 앱 시작 흐름

## 목표

Julian(2026-10-08, Expo Go 로 보고): 「시작 화면의 육아버디 글씨가 흰색이라 흰 바탕에 안 보이고, 너무 휑하다. 핵심 슬로건이 같이
있으면 좋겠다」.

확인한 것: 그 흰 글씨는 우리 화면이 아니라 **Expo Go 의 로딩 화면**이다(앱 아이콘 + 앱 이름). Expo 문서: 「Expo Go 는 시작 화면
대신 앱 아이콘을 보인다 — 시작 화면 시험에 Expo Go 나 개발 빌드를 쓰지 말 것」. 우리 시작 화면(흰 바탕에 서 있는 버디)은 글자가
없고, 빌드에서만 보인다. 그래도 「휑하다」는 맞다 — 그림 하나뿐이고, decisions/015 가 정한 노랑 바탕도 흰색으로 들어가 있었다.

## 정한 것

- **바탕은 우주복 노랑 `#FDD686`**(다크 모드는 `#0E0E11` 그대로) — 아이콘과 같은 색이라 아이콘을 누른 뒤 화면이 이어진다.
  app.json 의 expo-splash-screen 과 `Colors.splash` 토큰을 같은 값으로
- **글은 그림에 굽지 않고 코드로 띄운다.** 기기 시작 화면(그림만 가능)이 걷히면 같은 자리의 `AnimatedSplashOverlay` 가
  버디 아래에 「육아버디」(display) 와 슬로건 「육아의 모든 질문,」 「우리 아기 기준으로 버디가 다 챙겨요」(body · textSecondary) 를
  0.35초에 떠올리고 약 1초 머문 뒤 0.6초에 함께 흐려진다. 버디는 기기 시작 화면과 같은 자리(가운데 160×225)에 그대로 서 있다
- 그림에 굽지 않는 이유: Android 12+ 는 시작 그림을 아이콘 크기로 줄여 글이 안 읽히고, 글꼴(IBM Plex Sans KR) · 다크 모드 색을
  코드가 이미 가지고 있다. 코드로 띄우면 Expo Go 에서도 보인다(기기 시작 화면은 못 보지만 이 한 박자는 보인다)
- 늘어나는 시작 시간은 찬 시작 때만 약 1초. 따뜻한 시작(백그라운드에서 돌아옴)에는 시작 화면이 없다
- 슬로건은 product-brief 의 확정 메인 슬로건을 그대로 쓴다 — 스토어와 앱이 같은 말을 한다

## 손댄 파일

```
app.json                          expo-splash-screen backgroundColor #ffffff → #FDD686
src/constants/theme.ts            splash 토큰(light 노랑 · dark 바탕색)
src/components/animated-icon.tsx  이름 · 슬로건 떠올리기 → 머물기 → 함께 흐려지기
docs/app-design/README.md         「시작 화면」 · 「스플래시」 행
```

## 확인

tsc · lint 통과. 웹판은 시작 화면이 없어서(`animated-icon.web.tsx` 가 빈 구현) 확인할 때만 그 파일을 잠시 치우고 내보내
390×844 로 열었다(모델 호출 0). Playwright 화면 캡처가 이날 흰 그림만 내놓아(브라우저 그리기 문제, 앱과 무관) 화면 대신
DOM 치수로 확인했다 — 밝은 모드: 바탕 `rgb(253,214,134)` 전체, 버디 160×225 가 세로 310~535 가운데, 「육아버디」(IBM Plex
Bold 28, 먹색) 가 555 부터, 슬로건 두 줄(15, textSecondary) 이 599~647, 모두 가로 가운데 — 글과 버디 사이 20px, 겹침 · 잘림 없음.
어두운 모드: 바탕 `rgb(14,14,17)`, 글자 밝은 색, 같은 자리. 글은 로드 뒤 약 50ms 에 붙고 전체는 약 2.4초에 걷힌다.
기기 시작 화면(노랑 바탕)은 개발 빌드 · 릴리스 빌드에서만 보인다 — Expo Go 는 자체 로딩 화면을 쓴다. 폰 확인은 Julian.
