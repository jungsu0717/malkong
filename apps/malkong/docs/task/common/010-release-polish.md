## 목표

Julian 요청: "모든 로딩 이미지나 등등 진짜 배포 직전의 완성된 앱 형태". 파랑으로 남은 그림과 템플릿 느낌을 걷어 낸다.

## 한 것

- **런처 아이콘** — 붉은 말 색(#C64536) 바탕에 흰 말콩이 얼굴. adaptive 전경·배경·단색, 웹 favicon(둥근 사각)
- **시작 화면** — 먹색 아기를 태운 붉은 말. 다크 모드 그림을 따로(밝은 선) — 먹색 아기가 검은 바탕에 묻히지 않게.
  `animated-icon.tsx` 도 같은 그림을 골라 이음매가 없다
- **로딩 흐름** — 시작 화면은 글꼴을 다 읽을 때까지 남고(루트 `useFonts`), 기기 저장소를 읽는 동안은 같은 러너가 달리는
  `ScreenLoading`(먹색 아기 · 붉은 말). 답을 기다릴 때는 말콩이 얼굴이 숨 쉬는 처리 현황
- **빈 화면** — 기록 없음 · 브리핑 없음에 말콩이 얼굴 + 한 줄 + 행동 하나(`EmptyState`)
- 배너 자리 표시 · 상태 표시줄(흰 바탕에 검은 글씨, 다크 모드는 흰 글씨) · 쓰지 않는 스켈레톤 부품 지움
- 그림은 headless Chrome 으로 SVG 를 PNG 로 찍어 만들었다(원본 SVG 는 `baby-icons.tsx` 의 경로 그대로)
