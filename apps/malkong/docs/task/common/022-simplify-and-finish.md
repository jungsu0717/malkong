# 022 덜어 내고 끝까지 — 쉬운 앱으로 다듬기

> 상태: 진행 중 (2026-10-19)
> 근거: [decisions/030](../../decisions/030-simplify-and-finish.md) · [main](../../menu-spec/main.md) · [topic](../../menu-spec/topic.md) · [my](../../menu-spec/my.md) · [constitution](../../constitution.md) 2 · 5

## 목표

Julian(2026-10-19): 쓰기 쉽고 직관적으로, 쓸데없는 기능은 빼고, 반쪽짜리 기능은 끝까지. 「알아서」.

## 단계

- [x] 1. 빼기 — 마이 → 기록 · 기록 알림, 육아버디 스토리 만화, 예전 AI 상담 코드(대화 · 질문 · 지식 지도 · 행성 그림). 저장된 기록은 지우지 않는다
- [x] 2. 루틴 채우기 — 「오늘은 건너뛰기」, 요일 반복(재고 확인 「매주 일요일」)
- [x] 3. 할 일 탭 줄이기 — 오늘 · 예정 · 날짜 없음 + 「준비 목록 · 접종 · 검진 일정 · 추천 할 일」 줄. 긴 것은 상세 화면으로
- [ ] 4. 가족 알림 — 배우자가 한 루틴의 알림이 내 폰에서도 사라지게(서버가 알리는 방식). 서버 배포 · 설정은 Julian 승인 뒤
- [ ] 5. 출시 문서 — 약관 · 개인정보 · 자주 묻는 질문을 지금 기능으로 다시 쓰기, 서버 질문 답변 기능 내리기(배포 승인 뒤)
- [ ] 6. 캔버스에 전후 화면

## 정한 것

- 빼면서 남긴 것: 지식(L1) 내려받기(knowledge-update) — 접종 · 검진 일정을 앱 업데이트 없이 고치는 길이라 그대로 둔다.
  광고 면제(entitlements)도 그대로 — 가족 폰은 광고가 안 보인다
- 예전 기록 알림을 걸어 둔 폰이 있어 앱을 열 때 한 번 지운다(`cancelRecordAlerts`)
- 폰에 저장된 대화 · 알림함 · 빠른 기록 표는 지우지 않는다(헌장 2). 새로 설치한 폰에는 그 표를 만들지 않는다
- 가족 공유는 빠른 기록을 더 맞추지 않는다. 그 지운 표시도 올리지 않는다. 동의 문구는 「접종 · 검진 완료 기록」으로 좁혔다
- 「잠자는 중이면 할 일 알림 소리 없이」는 기록이 없어 함께 뺐다
- 마이는 카드 셋(아기 정보 / 알림 · 가족 / 도움말 · 약관)으로 줄였다
- 건너뛰기는 그날 한 줄(`routine_log.skip`)로 남긴다. 한 것으로 세지 않아 N일마다 루틴은 다음 날 다시 할 날이 된다. 건너뛴 루틴은 흐리게 남겨 되돌릴 수 있다.
  건너뛰기는 루틴 편집 · 단계 시트 · 재고 확인 시트에 둔다(버튼을 누르는 동작은 「완료」 하나로 둔다)
- 요일 반복은 「요일 지정」 칩에서 요일을 고른다(하나는 남긴다). 재고 확인 추천은 매주 일요일. 「매주」(7일마다) 칩은 요일 지정과 겹쳐 뺐다 — 7일마다는 숫자 칸으로
- 할 일 탭의 「주제」 그리드와 「준비 목록」 카드는 상세 화면(`/topics` · `/lists`)으로 옮기고, 탭에는 세 줄만 둔다
- 2026-10-15 에 앱이 만든 신청 · 서류 할 일(ref `paper:`) 중 안 끝낸 것을 한 번 지운다(가족 폰에도 지운 표시). 끝낸 것은 남긴다
- 버튼 보기 상태 줄은 두 줄까지(「오후 8:30 · 4단계」가 잘렸다), 다른 날 한 줄은 「금요일 손톱 깎기」 순서로
