# 023 사용자 시점 점검 — 처음 쓰는 부모로 하루 써 보고 고치기

> 상태: 완료 (2026-10-22)
> 근거: SPEC-MAIN-01 · 03, SPEC-SHOP-01, SPEC-MY-01

## 목표

Julian(2026-10-22): 「사용자의 페르소나를 갖고 앱을 좀 써 봐. 불편한 것을 찾아서 배포 직전까지 끌어올리자.」
태어난 지 36일 된 아기를 처음 키우는 부모(잠이 모자라고 한 손으로 폰을 쓴다)로 웹 미리보기(390px)에서
온보딩 → 루틴 → 할 일 · 장보기 · 아기 일정 → 성장 → 마이를 차례로 써 봤다.

## 찾은 것과 고친 것

1. 루틴이 없을 때 추천 하나를 누르면 나머지 추천이 다 사라져, 두 번째부터는 시트를 다시 열어야 했다
   → 루틴이 세 개가 안 되면 아직 안 넣은 추천을 버튼 뒤에 계속 보인다. 마지막 칸은 늘 「추가」(전에는 「직접 추가」였는데 시트 안 이름은 「직접 만들기」라 어긋났다)
2. 오후 3시에 큰 단추가 밤 8시 반 「밤잠 준비」를 권하고, 아직 안 한 터미타임은 뒤로 밀렸다
   → 다음 루틴은 시각이 지났거나 한 시간 안에 올 것 → 시각 없는 것 → 가장 가까운 시각 순
3. 버튼 상태 「오후 8:00 · 2단계」가 좁은 칸에서 「2단 / 계」로 끊겼다 → 점에서 줄을 바꾼다
4. 장보기의 재고 확인 줄이 한 번도 확인하지 않았는데 「지난번엔 모두 충분했어요」라고 했다 → 확인한 적이 없으면 다음 확인 날만
5. 온보딩 생일 칸의 회색 예시 숫자(2026 · 07 · 06)가 이미 적힌 값처럼 보였다 → 예시를 빼고, 처음 시작할 때는 해 칸에 바로 자판이 뜬다
6. 가족 화면의 「위 내용에 동의하면 누를 수 있어요」는 바로 위 체크 칸으로 알 수 있어 뺐다(화면 문구는 최소로)

## 그대로 둔 것

- 성장 · 마이 · 아기 일정은 써 보면서 막히는 곳이 없었다
- 알림 화면의 「이 폰에서는 알림을 받을 수 없어요」는 웹 미리보기에서만 보인다
