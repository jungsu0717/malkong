## 정한 것

- 점검표는 저장소 공통 [docs/governance/korean-copy-check.md](../../../../../docs/governance/korean-copy-check.md) — `epoko77-ai/im-not-ai`(Humanize KR, 별 6,311)의
  10 범주 85 패턴에서 짧은 화면 문구에 해당하는 것만 추렸다. 긴 글(스토어 설명 · 약관)은 그 스킬을 Claude Code 에 설치해 돌린다
- 검사 스크립트 `scripts/check-copy.mjs` — `src/` 의 한국어 문자열을 모아 점검표의 낱말 · 기호(느낌표 · 이모지 · 번역투 · 광고 말)를 찾아 줄 번호와 함께 보여 준다.
  `npm run copy-check`. 사람이 보고 고치는 도구이고, 맞다고 판단한 것은 그대로 둔다
