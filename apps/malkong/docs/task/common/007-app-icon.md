# 007 임시 앱 아이콘 · 시작 화면

> 상태: 완료 (2026-10-03) — 임시판. 최종 아이콘은 디자이너(app-design 「아이콘」 — 런처 아이콘은 브랜드 자산)
> 근거: app-design 「아이콘」 · 「로딩과 모션」(시작 화면)

## 목표

Expo 기본 그림을 걷어 내고 말콩의 그림으로 바꾼다 — 스토어 심사·내부 시험에서 템플릿 앱으로 보이지 않게.

## 한 것

- 런처 아이콘(1024): 포인트 파랑(`accent` #3182F6) 바탕에 흰 「쪽쪽이 문 아기」(`PacifierBabyIcon` 을 키운 것).
  iOS 는 이 PNG 를 쓴다(템플릿의 `expo.icon` 은 지웠다)
- 안드로이드 adaptive: 전경(가운데 안전 영역 안의 흰 아이콘) · 배경(파랑) · 단색(전경과 같은 모양)
- 시작 화면: 흰 바탕(다크 모드는 `#101013`)에 붉은 말을 탄 쪽쪽이 아기(`RidingBabyIcon`). 걷힐 때 같은 그림이 흐려진다
  (`animated-icon.tsx`) — app.json 설정과 그림·바탕색이 같아야 이음매가 없다
- 웹 favicon(48)
- 템플릿 찌꺼기 정리: Expo·React 로고, 시작 화면의 Expo 로고, 쓰지 않던 `web-badge`·`AnimatedIcon`·탭 아이콘 PNG
- 마이의 「구축 현황(임시)」은 개발 빌드에서만 보인다

그림은 headless Chrome 으로 SVG 를 1024 PNG 로 찍어 만들었다(원본 SVG 는 `baby-icons.tsx` 의 경로 그대로).
