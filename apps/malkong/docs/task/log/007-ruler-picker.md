# 007 좌우로 끄는 눈금 — 분유 양, 모유 먹인 시간, 기록의 때, 잔 시간

> 상태: 구현 완료 (2026-11-06) · 폰에서 쓰는 느낌은 TestFlight 빌드 12 에서
> 근거: [log](../../menu-spec/log.md) SPEC-LOG-01
> 시안: https://claude.ai/artifact/4CMt2A8pGPqV1xhaAg3H8x 「분유 — 양과 시간을 좌우로 끌어서 골라요」 · 「잠 — 잠든 때와 잔 시간도 끌어서 골라요」

## 목표

−/+ 단추와 칩 대신 눈금을 좌우로 끌어 값을 고른다. 한 손으로 빨리 맞출 수 있게 한다.

## 정한 것

- 눈금은 가로 ScrollView 로 만든다 — 손을 놓아도 미끄러지다 멈추는 움직임을 폰이 그대로 해 준다. 값은 스크롤 위치에서 계산하고, 칸이 바뀔 때마다 가볍게 진동한다
- 분유 5ml(한 칸 7px, 50ml 마다 숫자), 모유 1분(한 칸 10px, 5분마다 숫자), 잔 시간 5분(한 칸 8px, 1시간마다 숫자), 때는 1분(5분 눈금 8px, 30분마다 시각)
- 때 눈금은 고른 때 앞뒤 하루, 지금 뒤로는 그리지 않는다. 때 글자를 누르면 예전 바퀴(task log/005)가 열린다
- 체온 · 몸무게 · 키는 숫자 칸을 그대로 두고, 때만 눈금으로 바꾼다

## 완료 조건

- [x] (SPEC-LOG-01) 지금 뒤로 눈금 없음, 「지금」 표시, 「30분 전」, 「12:30에 깼어요」
- [x] (SPEC-LOG-01) 때 글자를 누르면 날짜와 시간 바퀴

## 확인

- 웹(390×844): 분유 시트에서 수유량 눈금을 여섯 칸 끌면 120ml → 150ml, 수유 시간 눈금을 30분 끌면 「오늘 13:50」과 「30분 전」, 지금 뒤로 눈금 없음과 「지금」 표시.
  잠 시트는 「지금 잠들었어요」, 잠든 때 「오늘 13:20」, 잔 시간 「1시간」, 「14:20에 깼어요」. 잔 시간은 잠든 때부터 지금까지만 고를 수 있다
- 손가락으로 끌 때의 미끄러짐과 진동, iOS 바퀴는 폰에서 본다
