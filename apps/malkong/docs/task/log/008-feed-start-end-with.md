## 목표

지난 모유를 시작과 끝으로 적고(빌드 12 피드백 3번), 수유 때 같이 먹인 비타민D와 유산균을 고르고, 메모를 남긴다(4번).

## 정한 것

- 모유의 「먹인 시간」 눈금 대신 「끝」 때 눈금. 끝은 시작보다 뒤, 지금보다 앞
- 「같이 먹인 것」은 루틴 완료로 남긴다(그 수유 시각). 없는 이름이면 매일 체크 루틴으로 만든다. 단추 목록은 이 폰에서 고른 적 있는 것과 비타민D, 유산균
- 메모는 기록의 `note`(가족 맞추기에 이미 있음)

## 완료 조건

- [x] (SPEC-LOG-01) 모유 시작과 끝, 「15분 먹였어요」
- [x] (SPEC-LOG-01) 모유 · 분유 시트의 「같이 먹인 것」
- [x] (SPEC-LOG-01) 메모 칸, 기록 화면에 메모

## 확인

- 「먹인 시간」 눈금 대신 「시작」 · 「끝」 두 때 눈금(새 모유는 15분 전 시작, 지금 끝). 끝이 시작보다 앞이면 빨간 글과 저장 꺼짐
- 「같이 먹인 것」은 `logTitle`(routines-context — 같은 이름 루틴이 없으면 매일 체크 루틴을 만든다)로 그 수유 시각에 완료 한 줄. 더한 이름은 설정 `feed.with`
- 메모는 기록의 `note`, 기록 화면 수유 펼침에 보인다
- 웹: 모유 시트 — 시작 14:05, 끝 14:20, 「15분 먹였어요」, 비타민D 고름, 메모 칸
