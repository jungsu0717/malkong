## 목표

Julian 요청(2026-10-04): 오늘의 브리핑과 정보 입력을 나누자. 총 수유량 · 몸무게는 매일 적으면 좋지만 너무 자주 물으면
귀찮다. 직접 적을 수 있게 두고, 2~3일 기록이 없을 때 푸시 알림과 함께 입력 카드가 저절로 뜨게. 카드는 위에 입력 폼,
아래에 건너뛰기와 입력 단추. 건너뛰면 대화 중에 물어봐서 채울 수 있다는 안내. 설정에서 푸시와 카드를 끌 수 있고,
카드에도 「다시 보지 않기」.

## 정한 것

1. **브리핑 = 챙길 것만** — 요약 카드 · 브리핑함 카드에서 하루 기록 묶음을 빼고, 배지도 챙길 것만 센다
2. **우리 아기 탭 「하루 기록」** — 넷의 가장 최근 값과 날짜, 「적기」로 같은 질문 시트(ask-sheet)
3. **언제 묻나** — 하루 기록이 하나도 없이 이틀이 지나 사흘째(마지막 기록 · 마지막으로 물은 때 가운데 늦은 날 + 3일).
   처음 쓰는 사람은 처음 연 날부터 센다. 앱을 열면 카드, 알림은 그날 **저녁 8시** 한 번(아침 브리핑 알림과 겹치지 않게)
4. **카드** — 칸 넷(모두 선택, 숫자는 단위 칸 · 특이사항은 글과 흔한 답 칩) → 「건너뛰면 대화하다 필요할 때 버디가
   물어보고 채워 둘게요」 → 「건너뛰기」 · 「기록할게요」 → 「다시 보지 않기」(카드 · 알림 모두 끔, 마이에서 다시 켬)
5. **알림을 누르면** 앱이 열리고 같은 카드가 뜬다(카드 스위치가 꺼져 있어도 — 사용자가 직접 누른 것이므로)
6. **마이 알림 칸** — 「기록이 비면 알림」(허락을 묻는다) · 「기록이 비면 카드」 두 스위치
7. 알림 글에 아기 정보 없음: 「요 며칠 기록이 비었어요 · 생각나는 것만 적어 주면 버디 답이 더 정확해져요」

## 확인한 것 (웹 390px, headless Chrome — Gemini 호출 없음)

- 대화 요약 · 브리핑함에 하루 기록 없음, 배지 「3개 남음」(챙길 것만). 처음 연 날은 카드가 뜨지 않는다
- 「물은 때」를 나흘 전으로 돌리면 카드가 뜬다 → 780ml · 3시간 칩 · 「많이 보챘어요」 칩 → 「3개 기록할게요」 →
  「3개 기록했어요」가 잠깐 보이고 닫힘. 기록 「10월 3일 하루 수유량 780ml」 외 둘
- 우리 아기 탭 하루 기록: 「780ml · 오늘 적음」, 몸무게 「적기」 → 6.4 → 「6.4kg · 오늘 적음」
- 기록을 닷새 전으로 돌리면 카드에 「지난 기록 5일 전 · 780ml」, 건너뛰기 → 닫히고 다시 열어도 안 뜸
- 다시 보지 않기 → 카드 · 알림 설정 둘 다 off, 사흘이 지나도 안 뜸. 마이에서 카드 스위치를 켜면 다시 뜸
- 웹 콘솔 오류는 예전부터 있던 웹 전용 「button 안의 button」 경고 하나뿐(새 코드에서 생긴 것 아님)
