# 001 리스트 탭 — 살 것과 준비할 것

> 상태: 구현 완료 (2026-10-16) — 웹에서 확인
> 근거: [shop](../../menu-spec/shop.md) SPEC-SHOP-01~05 · [topic](../../menu-spec/topic.md) SPEC-TOPIC-12 · [decisions/028](../../decisions/028-assistant-today-routines.md)

## 목표

Julian(2026-10-16): 「날짜 기준이 아닌 살 것 기준, 행위를 기반으로 살 것들, 준비할 것들도 한 메뉴로.」
이 task 가 끝나면 「리스트」 탭 위의 전환 단추로 살 것(살 곳별)과 준비할 것(외출 가방 · 여행 짐 · 어린이집 준비 같은 체크리스트)을 오간다.

## 정한 것

- 탭 이름 장보기 → 리스트, 화면 파일 `shop.tsx` → `list.tsx`(주소 `/list`)
- 위에 전환 단추 「살 것 N」 · 「준비할 것 N」(N 은 남은 수). 고른 쪽은 기기에 기억해 다음에도 그쪽으로 연다
- 살 것: 지금 장보기 그대로(살 곳별 · 온라인 주문 · 배송 중 · 다시 담기 · 완료). 못 산 것은 체크하지 않으면 그대로 남는다 — 날짜를 붙이지 않으니 다음 날 다시 만들 필요가 없다
- 준비할 것: 직접 만든 주제(kind custom)를 목록 카드로 — 아이콘 · 이름 · 「남은 3개 · 완료 5개」. 누르면 그 목록(주제 화면, 「모두 체크 해제」 있음).
  「새 목록」은 지금의 주제 추가 시트(추천: 어린이집 준비 · 여행 짐 · 외출 가방, 직접 만들기)
- 할 일 탭에서는 직접 만든 주제를 뺀다 — 그리드의 「주제 추가」와 입력칸 주제 칩도 리스트로 옮긴다. 할 일 탭은 날짜 있는 한 번짜리 할 일과 앱이 채우는 주제만
- 품절 표시(「다음에」)는 따로 두지 않는다 — 체크하지 않으면 남고, 살 곳을 바꾸려면 길게 눌러 편집
