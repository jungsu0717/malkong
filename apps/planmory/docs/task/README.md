# task — SPEC 을 코드로 만드는 단위

폴더는 메뉴 코드별(`today/` · `add/` · `topic/` · `notify/`)과 여러 메뉴에 걸친 기반 작업 `common/`(앱 뼈대, 서버, 로그인, 동기화, 출시)이다.
작성 방법은 저장소 공통 [conventions](../../../../docs/governance/conventions.md) 「작업 순서」, 틀은 [task 틀](../../../../docs/_templates/task.md).

## 순서 — 첫 판까지

| 순서 | task | 무엇 | 상태 |
|---|---|---|---|
| 1 | [common/001](common/001-app-skeleton.md) | 앱 뼈대 — 탭 셋, 폰 표, 오늘 탭, 한 줄 적기, 체크 | 시작 전 |
| 2 | common/002 | 서버 · Apple 로그인 · 동기화(Neon 새 프로젝트) | 시작 전 |
| 3 | add/001 | 붙여 넣기와 나누기(규칙 → 모델), 클립보드 제안, 라벨 칩 | 시작 전 |
| 4 | notify/001 | 할 일 알림 | 시작 전 |
| 5 | today/001 | 반복 할 일 | 시작 전 |
| 6 | topic/001 | 주제 만들기, 추천 할 일, 기본 가이드, 보관함 | 시작 전 |
| 7 | common/003 | 링크로 함께 쓰기(여럿이 함께 준비하는 일) | 시작 전 |
| 8 | common/004 | 광고와 하루 한도, 공유 메뉴(개발 빌드), 출시 | 시작 전 |
