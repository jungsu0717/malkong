# 알림

> 위에 있는 것: [constitution](../constitution.md) 6 · [main-design](../architecture/main-design.md) 「알림」

## SPEC

### SPEC-NOTI-01 할 일 알림
```
평시 ▸ 알림 시각이 있는 할 일은 그 시각에 폰이 직접 알림을 울려야 한다. 인터넷 연결과 서버 상태에 상관없이 울려야 한다.
평시 ▸ 할 일을 고치거나 끝내거나 지우면 그 할 일의 알림도 바로 바뀌거나 지워져야 한다.
평시 ▸ 폰을 바꾸거나 앱을 다시 깔고 로그인하면, 받아 온 기록으로 앞으로의 알림을 다시 걸어야 한다.
```

### SPEC-NOTI-02 알림 허락
```
평시 ▸ 알림 허락은 처음 알림 시각을 넣을 때 물어야 한다. 처음 실행에서 묻지 않는다.
조건 위반 ▸ 허락을 거절했거나 폰 설정에서 꺼져 있으면, 알림 시각이 있는 할 일에 「알림 꺼짐」과 「설정 열기」를 보여야 한다.
```

### SPEC-NOTI-03 반복 할 일 알림
```
평시 ▸ 그날 제안할 반복 할 일이 있으면 아침에(기본 오전 8시, 마이에서 바꿀 수 있다) 알림을 한 번 보내야 한다.
```

## HOW

- `expo-notifications` 의 날짜 알림. 할 일 id 를 알림 식별자로 써서 고칠 때 찾아 바꾼다
- iOS 는 앱 하나가 걸어 둘 수 있는 로컬 알림 수에 한도가 있다(64개로 알려져 있음, 붙일 때 다시 확인). 가까운 것부터 걸고, 앱을 열 때마다 다시 채운다
