# Planmory (플랜모리, 코드명 planmory)

상황마다 할 일을 적는 앱. 정리하지 않은 글을 붙여 넣어도 할 일로 나눠 주고, 끝낸 할 일은 쌓아 두었다가
다음에 같은 상황이 오면 먼저 보여 준다.

## 지금 상태 (2026-10-14)

- **백로그**: Julian 이 2026-10-14 에 육아버디와 함께 백로그로 돌렸다. 할 일 앱 시장이 붐비고(투두메이트 평가 10만 8천),
  목적별 목록으로 좁히면 매일 열 이유가 약하다는 판단. 출시 여부는 애플 계정 결제 뒤 다시 정한다
- **설계 시작**: 2026-10-14 Julian 과의 회의에서 컨셉, 기능, 하지 않는 것, 데이터, 수익, 이름을 정했다.
  헌장 · 제품 브리프 · 전체 설계 · 첫 SPEC 넷(today, add, topic, notify) · 결정 기록 셋 · 첫 task 를 썼다
- **코드 없음**: 앱과 서버는 아직 없다. 첫 task 는 헌장과 브리프를 Julian 이 확인한 뒤 시작한다

## 다음 시작점

1. **Julian 확인**: [헌장](docs/constitution.md)과 [제품 브리프](docs/product/product-brief.md)를 읽고 고칠 것을 말한다.
   브리프 「열린 질문」(홈 화면 이름, 번들 ID, 포인트 색, 기본 가이드 목록)도 정할 수 있으면 정한다
2. **[task 순서](docs/task/README.md)** 대로 진행 — 1번 앱 뼈대가 끝나면 Julian 이 아이폰에서 매일 써 본다
3. **Julian 이 할 것(2번 서버 task 전)**: Neon 에 새 프로젝트를 만든다(육아버디와 따로). 연결 주소는 대화에 붙이지 않고 Julian 이 직접
   Cloud Run 비밀값으로 넣는다(방법은 그 task 에 적는다)
